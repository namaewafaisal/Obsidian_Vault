# [[Cloud as a Service]]

## Definition
Delivering computing resources and services over the internet on demand.

---

# Characteristics
- on-demand access
- scalability
- pay-as-you-go
- remote access
- resource pooling

---

# Cloud Service Models

## IaaS (Infrastructure as a Service)
Provider gives:
- servers
- storage
- networking

User manages:
- OS
- applications

# Cloud Types

## Public Cloud
Shared cloud infrastructure.

## Private Cloud
Dedicated cloud for one organization.

## Hybrid Cloud
Combination of public and private cloud.

---

# Cloud and DevOps
Cloud supports:
- automation
- CI/CD
- scalability
- rapid deployment

---

# Advantages
- scalability
- flexibility
- reduced cost
- fast deployment

---

# Challenges
- security risks
- vendor lock-in
- internet dependency

# Important Definitions

## Cloud Computing
Providing computing resources over internet.

## IaaS

## PaaS

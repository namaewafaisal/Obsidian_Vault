# LCD (16×2)

## Pins

| Pin | Function |
|------|------|
| RS | Register Select |
| RW | Read/Write |
| EN | Enable |
| D0–D7 | Data Lines |

---

## RS

```text
0 → Command

1 → Data
```

Command:
- Clear screen
- Cursor control

Data:
- Characters

---

## RW

```text
0 → Write

1 → Read
```

Usually:

```text
RW = 0
```

---

## EN

```text
Enable signal
```

Used to latch data.

---

## Modes

### 8-bit

```text
D0–D7 used
```

- Faster
- More pins

### 4-bit

```text
D4–D7 used
```

- Saves pins
- Most common

Data sent:

```text
Higher nibble
↓
Lower nibble
```

---

## Initialization

```text
38H → 8-bit mode

28H → 4-bit mode

0CH → Display ON

06H → Cursor increment

01H → Clear display
```

---

# Keypad (4×4)

## Structure

```text
4 Rows
4 Columns
```

```text
16 Keys
8 Wires
```

---

## Working

```text
Drive row LOW
↓
Read columns
↓
Detect key
↓
Repeat
```

Called:

```text
Row-Column Scanning
```

---

## Debouncing

Problem:

```text
One press
→ Multiple signals
```

Solution:

```text
Small software delay
```

---

# ADC (ADC0804)

## Purpose

```text
Analog
↓
Digital
```

Examples:
- Temperature
- Light
- Pressure

---

## Read Sequence

```text
WR pulse
↓
Start Conversion
↓
Wait INTR
↓
RD pulse
↓
Read Data
```

Important Flow:

```text
WR
↓
INTR
↓
RD
↓
Read
```

---

# DAC (DAC0808)

## Purpose

```text
Digital
↓
Analog
```

Example:

```text
00000000 → Minimum Output

11111111 → Maximum Output
```

---

## Staircase Waveform

Input:

```text
00
01
02
03
...
FF
```

Output:

```text
Increasing analog voltage
```

Called:

```text
Staircase Waveform
```

---

# Stepper Motor

## Purpose

```text
Electrical Pulses
↓
Rotation
```

Moves in:

```text
Steps
```

---

## Full-Step

Example:

```text
1000
0100
0010
0001
```

- Faster
- Simpler

---

## Half-Step

Example:

```text
1000
1100
0100
0110
0010
0011
0001
1001
```

- Smoother
- Better resolution

---

## ULN2003

Purpose:

```text
Motor Driver
```

Reason:

```text
8051 cannot supply
required current
```

---

# Relay

## Purpose

```text
Switch high-current load
using MCU
```

Examples:
- Fan
- Bulb
- Motor

---

## Driver Circuit

```text
8051
↓
Transistor
↓
Relay
```

Reason:

```text
Relay requires
more current
```

---

## Flyback Diode

Purpose:

```text
Back EMF protection
```

Protects MCU and transistor.

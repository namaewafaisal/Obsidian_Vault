# Timers and Counters

## Overview
- 8051 has:
  - Timer 0
  - Timer 1
- Both are:
```text
16-bit timer/counter
```

Purpose:
- Delay generation
- Time measurement
- Event counting
- UART baud-rate generation

---

# Timer Registers

## Timer 0
```text
TH0
TL0
```

## Timer 1
```text
TH1
TL1
```

Meaning:

```text
TH = High byte
TL = Low byte
```

Example:

```text
TH0 = D8H
TL0 = F0H

Timer Value = D8F0H
```

---

# Important SFRs

| Register | Purpose |
|----------|----------|
| TMOD | Timer mode configuration |
| TCON | Timer control/status |
| TH0/TL0 | Timer0 value |
| TH1/TL1 | Timer1 value |

---

# TMOD Register

Structure:

```text
GATE C/T M1 M0 | GATE C/T M1 M0
     T1              T0
```

Upper nibble:
```text
Timer 1
```

Lower nibble:
```text
Timer 0
```

---

# C/T Bit

## C/T = 0

```text
Timer Mode
```

Counts:

```text
Machine cycles
```

Used for:
- Delays
- Timing

---

## C/T = 1

```text
Counter Mode
```

Counts external pulses.

Pins:

```text
T0 = P3.4
T1 = P3.5
```

Used for:
- Pulse counting
- Event counting
- Object counting

---

# Gate Bit

## GATE = 0

Timer controlled only by:

```text
TR0
TR1
```

Most common.

---

## GATE = 1

Timer runs only when:

```text
TRx = 1
AND
INTx = 1
```

Rarely used.

---

# Timer Modes

## Mode 0

```text
M1 = 0
M0 = 0
```

Features:

```text
13-bit timer
```

Legacy mode.

Rarely used.

---

## Mode 1

```text
M1 = 0
M0 = 1
```

Features:

```text
16-bit timer
```

Range:

```text
0000H → FFFFH
```

Most commonly used for:

```text
Delay generation
```

---

## Mode 2

```text
M1 = 1
M0 = 0
```

Features:

```text
8-bit auto reload
```

Operation:

```text
TL reloads automatically
from TH
```

Used for:

```text
UART baud rate generation
```

---

## Mode 3

```text
M1 = 1
M0 = 1
```

Features:

```text
Timer0 split into
two 8-bit timers
```

Rarely used.

---

# TCON Register

Important Bits:

| Bit | Purpose |
|------|------|
| TF1 | Timer1 overflow flag |
| TR1 | Timer1 run bit |
| TF0 | Timer0 overflow flag |
| TR0 | Timer0 run bit |

---

# TR0 / TR1

Purpose:

```text
Start / Stop timer
```

Start:

```asm
SETB TR0
```

Stop:

```asm
CLR TR0
```

---

# TF0 / TF1

Purpose:

```text
Overflow indication
```

When:

```text
FFFFH
↓
0000H
```

Overflow occurs.

Flag becomes:

```text
1
```

Example:

```asm
JNB TF0,$
```

Meaning:

```text
Wait until overflow
```

---

# Machine Cycle

Important Formula:

```text
1 Machine Cycle
=
12 Oscillator Cycles
```

Classic 8051.

---

# 12 MHz Crystal

Oscillator:

```text
12 MHz
```

Machine Cycle:

```text
1 µs
```

Important Shortcut:

```text
12 MHz
→ Timer increments every 1 µs
```

---

# Delay Formula

## Count

```text
Count
=
Delay / MachineCycle
```

---

## Reload Value

Mode 1:

```text
Reload
=
65536 - Count
```

Combined:

```text
Reload
=
65536
-
(Delay × Clock / 12)
```

# Numerical

## Problem

Generate:

```text
10 ms delay
```

Crystal:

```text
12 MHz
```

---

## Step 1

Machine Cycle:

```text
1 µs
```

---

## Step 2

Delay:

```text
10 ms
=
10000 µs
```

---

## Step 3

Count:

```text
10000
```

---

## Step 4

Reload:

```text
65536 - 10000
=
55536
```

---

## Step 5

Convert to Hex:

```text
55536
=
D8F0H
```

---

## Final Answer

```text
TH0 = D8H
TL0 = F0H
```

# Typical Delay Program

```asm
MOV TMOD,#01H

MOV TH0,#D8H
MOV TL0,#F0H

SETB TR0

WAIT:
JNB TF0,WAIT

CLR TR0
CLR TF0
```

Flow:

```text
Load Timer
↓
Start Timer
↓
Wait Overflow
↓
Stop Timer
↓
Clear Flag
```

# Counter Mode

Enable:

```text
C/T = 1
```

Counts external pulses.

Pins:

```text
T0 → P3.4
T1 → P3.5
```

Example:

```text
1 pulse = 1 bottle

100 pulses
=
100 bottles counted
```

---

# Overflow

Example:

```text
FFFE
FFFF
0000
```

Result:

```text
TFx = 1
```

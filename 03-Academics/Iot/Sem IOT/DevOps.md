# [[DevOps]]

## Definition
Culture and engineering practice integrating development and operations.

---

# Purpose
- faster delivery
- automation
- collaboration
- reliability
- continuous feedback

---

# Problem Before DevOps
Development and operations worked separately.

Result:
- slow deployment
- failures
- poor communication

---

# Core Idea
```text
Dev + Ops = DevOps
```

Shared responsibility for:
- development
- deployment
- monitoring
- maintenance

---

# DevOps Lifecycle

```text
Plan → Code → Build → Test → Release
  ↑                              ↓
Monitor ← Operate ← Deploy ←
```

---

# Stages

## Plan
Requirement planning.

## Code
Write source code.

## Build
Compile/package application.

## Test
Automated testing.

## Release
Prepare stable version.

## Deploy
Release to production.

## Operate
Manage running system.

## Monitor
Track logs and performance.

---

# Automation
Automates:
- testing
- builds
- deployment
- monitoring

---

# CI/CD

## CI (Continuous Integration)

## CD (Continuous Delivery/Deployment)
Automated software release/deployment.

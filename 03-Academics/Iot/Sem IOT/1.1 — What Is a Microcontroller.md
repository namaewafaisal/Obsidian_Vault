# What Is a Microcontroller?

## Processor (Microprocessor)
- CPU only
- Needs external RAM, storage, I/O
- Example: Intel i7, AMD Ryzen
- Analogy: Engine only

## Microcontroller (MCU)
- CPU + RAM + ROM/Flash + Peripherals on one chip
- Self-contained
- Used in embedded systems
- Examples:
  - 8051
  - ATmega328P
  - ESP32
  - STM32
- Analogy: Complete vehicle

## Computer
- Full system
- CPU + RAM + Storage + OS + I/O
- Examples:
  - Laptop
  - Desktop
  - Raspberry Pi

## Embedded System
- Computer system inside a larger product
- Dedicated task
- Examples:
  - Washing machine
  - Microwave
  - Smart watch
  - Air conditioner

## 8051
- Classic 8-bit MCU
- Simple architecture
- Used for learning fundamentals
- Many compatible descendants still used

## 8-Bit MCU
### ALU
- Processes 8 bits at a time

### Registers
- Mostly 8-bit

### Data Bus
- 8-bit wide

### Range
- Unsigned:
  - 00000000 = 0
  - 11111111 = 255

## MCU Main Job

Read Inputs
→ Process Data
→ Control Outputs

Example:
Temperature Sensor
→ MCU
→ Fan ON/OFF

## IoT Relationship

Sensor
→ Microcontroller
→ Internet
→ Cloud/App

Key Idea:
MCU = bridge between physical world and software world.

# Microcontrollers

## Definition
- **Microcontroller (MCU)** = Small, low-cost microcomputer for **embedded systems**.
- Designed for **specific tasks** (not general-purpose computing).
- Example uses:
  - Microwave displays
  - TV remotes
  - Washing machines
  - IoT devices

## 8051 Microcontroller (Intel, 1981)
- Known as **System on Chip (SoC)**.
- Components integrated on a single chip:
  - 8-bit CPU
  - 128 B RAM
  - 4 KB ROM
  - 2 Timers
  - 1 Serial Port
  - 4 × 8-bit I/O Ports

## General Components of a Microcontroller
- CPU / Processor
- RAM
- ROM / EPROM
- I/O Ports
- Timers & Counters
- Serial Communication Ports

## Criteria for Choosing a Microcontroller
- **Speed** → Maximum operating frequency
- **Packaging** → DIP, QFP, etc.
- **Power Consumption** → Important for battery devices
- **RAM Size** → Data storage capacity
- **ROM/Flash Size** → Program storage capacity
- **I/O Pins** → External device connections
- **Timers/Counters** → Timing requirements
- **Cost per Unit** → Product manufacturing cost

# Microcontroller vs Microprocessor

| Microcontroller | Microprocessor |
|---------------|---------------|
| Single dedicated task | Large/general-purpose applications |
| Low cost | High cost |
| Easy replacement | Difficult replacement |
| Low power (CMOS) | High power consumption |
| CPU + RAM + ROM + I/O on chip | Mostly CPU only |
| Compact design | Requires external peripherals |

## 8051 Features
- 4 KB On-chip Program Memory (ROM/EPROM)
- 128 Bytes On-chip RAM
- 4 Register Banks
- 64 KB Program Memory Address Space
- 64 KB External RAM Address Space
- 1 µs Instruction Cycle (@12 MHz)
- 32 Bidirectional I/O Lines
  - Port 0
  - Port 1
  - Port 2
  - Port 3
- UART Serial Communication
- 16-bit Timers/Counters
- Byte Addressable
- Bit Addressable

## Keywords for Revision
- MCU = Embedded System Controller
- 8051 = 8-bit MCU
- SoC = System on Chip
- CPU + RAM + ROM + I/O + Timers

- Dedicated Task
- 32 I/O Pins

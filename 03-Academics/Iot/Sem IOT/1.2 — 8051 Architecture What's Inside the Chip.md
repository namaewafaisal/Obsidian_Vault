# 8051 Architecture

## Core Idea
- 8051 = CPU + Memory + Peripherals on one chip
- 8-bit microcontroller
- Harvard Architecture

---

# CPU Core

## ALU (Arithmetic Logic Unit)
- Performs:
  - Arithmetic
    - ADD
    - SUB
    - MUL
    - DIV
    - INC
    - DEC
  - Logical
    - AND
    - OR
    - XOR
    - NOT
- Does processing only
- Does not store data

## Accumulator (A)
- 8-bit register
- Main working register
- Most ALU operations use A
- Stores arithmetic/logical results

Example:
```asm
MOV A,#5
ADD A,#3
```

Result:
```text
A = 8
```

## B Register
- 8-bit register
- Used by:
  - MUL AB
  - DIV AB
- Can also be used as general storage

Example:
```asm
MOV A,#20
MOV B,#5
DIV AB
```

Result:
```text
A = quotient
B = remainder
```

## Program Counter (PC)
- Holds address of next instruction
- Automatically increments after execution
- Controls instruction sequence
- Acts like pointer to next instruction

## Stack Pointer (SP)
- Holds top-of-stack address
- Used for:
  - Function calls
  - Return addresses
  - Temporary storage
- Reset value:
```text
07H
```
- First PUSH stored at:
```text
08H
```

# Harvard Architecture

## Harvard
- Separate program memory and data memory
- Separate address spaces
- Separate access paths

Advantages:
- Faster instruction fetch
- Simultaneous code/data access
- Better isolation between code and data

## Von Neumann
- Same memory for code and data
- Shared path
- Simpler design
- More bottlenecks

# Memory Organization

## Internal RAM
Address:
```text
00H - 7FH
```

Size:
```text
128 bytes
```

### Register Banks
Address:
```text
00H - 1FH
```

Size:
```text
32 bytes
```

Contains:
- Bank 0
- Bank 1
- Bank 2
- Bank 3

Each bank:
```text
R0-R7
```

### Bit Addressable RAM
Address:
```text
20H - 2FH
```

Size:
```text
16 bytes
```

Features:
- Individual bit addressing
- 128 addressable bits

Used for:
- Flags
- Status indicators
- Control bits

### General Purpose RAM
Address:
```text
30H - 7FH
```

Size:
```text
80 bytes
```

Used for:
- Variables
- Buffers
- Temporary data

# Register Banks

## Bank Layout

### Bank 0
```text
00H - 07H
```

### Bank 1
```text
08H - 0FH
```

### Bank 2
```text
10H - 17H
```

### Bank 3
```text
18H - 1FH
```

Each bank:
```text
R0 R1 R2 R3 R4 R5 R6 R7
```

Only one bank active at a time.

## Bank Selection

Controlled by:
```text
PSW.RS1
PSW.RS0
```

| RS1 | RS0 | Active Bank |
|------|------|------------|
| 0 | 0 | Bank 0 |
| 0 | 1 | Bank 1 |
| 1 | 0 | Bank 2 |
| 1 | 1 | Bank 3 |

Default:
```text
Bank 0
```

Purpose:
- Fast context switching
- Faster interrupt handling
- Avoid saving/restoring registers

# SFR (Special Function Register) Area

Address:
```text
80H - FFH
```

Size:
```text
128 bytes
```

Purpose:
- Hardware control registers

Examples:

| Register | Purpose |
|-----------|----------|
| P0 | Port 0 |
| P1 | Port 1 |
| P2 | Port 2 |
| P3 | Port 3 |
| ACC | Accumulator |
| B | B Register |
| PSW | Status Word |
| SP | Stack Pointer |
| DPL | Data Pointer Low |
| DPH | Data Pointer High |
| TMOD | Timer Mode |
| TCON | Timer Control |
| SCON | Serial Control |
| IE | Interrupt Enable |
| IP | Interrupt Priority |

Key Idea:
- RAM → stores user data
- SFR → controls hardware

---

# PSW (Program Status Word)

Address:
```text
D0H
```

Bit Layout:
```text
CY AC F0 RS1 RS0 OV -- P
```

## CY
- Carry flag
- Set on carry out

## AC
- Auxiliary carry
- Carry between bit3 and bit4
- Used in BCD arithmetic

## F0
- User flag
- General-purpose software flag

## RS1 RS0
- Register bank selection bits

## OV
- Overflow flag
- Signed arithmetic overflow

Example:
```text
127 + 1
```

## P
- Parity flag
- Auto-updated from A register

---

# DPTR (Data Pointer)

## Characteristics
- 16-bit register
- Used for external memory access

Components:
```text
DPTR
 ├─ DPH
 └─ DPL
```

Example:
```text
DPH = 12H
DPL = 34H

DPTR = 1234H
```

Used in:
```asm
MOVX
MOVC
```

Reason:
- External memory can be:
```text
64 KB
```
- Need 16-bit address bus

# Program Memory (ROM)

Internal ROM:
```text
4 KB
```

Address:
```text
0000H - 0FFFH
```

Stores:
- Program instructions
- Constants
- Lookup tables

Not used for temporary variables.

---

# External Memory

## External Program Memory
Maximum:
```text
64 KB
```

## External Data Memory
Maximum:
```text
64 KB
```

Accessed using:
- Address bus
- Data bus
- DPTR

Purpose:
- Expand memory beyond on-chip limits

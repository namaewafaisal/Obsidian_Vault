# 8051 Microcontroller

## Features
- 8-bit Microcontroller
- 4 KB On-chip ROM → Stores program
- 128 B On-chip RAM → Stores temporary data
- Four Register Banks
- 64 KB Program Memory Address Space
- 64 KB External Data Memory Address Space
- 32 I/O Lines (4 × 8-bit Ports)
- UART Serial Communication
- Two 16-bit Timers/Counters
- Byte & Bit Addressable Memory
- 1 μs Machine Cycle (@ 12 MHz)

# Registers

## Register
- Small, high-speed storage inside CPU.
- Stores data, addresses, and intermediate results.

## Accumulator (A)
- Main arithmetic and logic register.
- Used by most ALU operations.

## B Register
- Used with multiplication and division instructions.

## R0-R7
- General-purpose registers.
- Store data and addresses.

## DPTR (Data Pointer)
- 16-bit register.
- Used to store memory addresses.
- Consists of:
  - DPH → High byte
  - DPL → Low byte

## Program Counter (PC)
- 16-bit register.
- Holds address of next instruction.

# Program Status Word (PSW)

## PSW
- 8-bit flag register.
- Stores status of operations.

### Important Flags
- Carry (CY) → Arithmetic carry generated
- Auxiliary Carry (AC) → Carry between lower and upper nibble
- Overflow (OV) → Arithmetic overflow
- Parity (P) → Indicates parity of accumulator

# Stack Pointer (SP)

## Stack
- Temporary storage area.
- Follows LIFO (Last In First Out).

## SP
- 8-bit register.
- Points to top of stack.
- Range: 00H–FFH
- Initial value: 07H

# Ports

## P0, P1, P2, P3
- Four 8-bit ports.
- Total = 32 I/O pins.

### Output
- 1 → HIGH
- 0 → LOW

### Input
- Reads external pin state.

# Serial Data Buffer (SBUF)

## SBUF
- Used for serial communication.

### Transmit Buffer
- Stores outgoing data.

### Receive Buffer
- Stores incoming data.

# Timer Registers

## TH0, TL0
- Timer 0 High & Low registers.

## TH1, TL1
- Timer 1 High & Low registers.

## Timer Size
- 16-bit.

# Control Registers

## IP
- Interrupt Priority Register.

## IE
- Interrupt Enable Register.

## TMOD
- Timer Mode Register.

## TCON
- Timer Control Register.

## SCON
- Serial Control Register.

## PCON
- Power Control Register.

# Timers/Counters

## Timer
- Measures time intervals.

## Counter
- Counts external events.

### 8051 Provides
- Timer/Counter 0
- Timer/Counter 1

### Size
- 16-bit each

# On-Chip Oscillator

## Oscillator
- Generates clock signal for CPU.

## Crystal Frequency
- Typically 12 MHz.

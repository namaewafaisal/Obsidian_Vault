# 8051 Microcontroller

## Definition
- 8-bit Microcontroller introduced by Intel (1981).
- System-on-Chip (SoC):
  - CPU
  - RAM
  - ROM
  - Timers/Counters
  - Serial Port
  - I/O Ports

---

# Features of 8051

- 4 KB On-chip Program Memory (ROM/EPROM)
- 128 B On-chip Data Memory (RAM)
- Four Register Banks
- 64 KB Program Memory Address Space
- 64 KB External Data Memory Address Space
- 32 Bidirectional I/O Lines
- UART Serial Communication
- Two 16-bit Timers/Counters
- Byte Addressable Memory
- Bit Addressable Memory
- 1 μs Machine Cycle (@12 MHz Crystal)

---

# Registers

## Register
- Small high-speed storage inside CPU.
- Stores:
  - Data
  - Addresses
  - Intermediate results

## Types
1. General Purpose Registers
2. Special Purpose Registers

---

## Accumulator (A)

### Purpose
- Main Arithmetic & Logic register.
- Used by ALU operations.

### Used For
- Addition
- Subtraction
- Logic operations
- Data transfer

---

## B Register

### Purpose
- Auxiliary register.
- Works together with Accumulator.

### Used For
- Multiplication
- Division
- Temporary data storage

---

## R0-R7 Registers

### Purpose
- General-purpose registers.
- Used by programmers directly.

### Used For
- Data storage
- Address storage
- Counters
- Temporary values

---

## Register Banks

8051 provides 4 register banks.

### Bank Structure

```text
Bank 0 : R0-R7
Bank 1 : R0-R7
Bank 2 : R0-R7
Bank 3 : R0-R7
```

### Address Range

| Bank | Address |
|--------|----------|
| Bank 0 | 00H-07H |
| Bank 1 | 08H-0FH |
| Bank 2 | 10H-17H |
| Bank 3 | 18H-1FH |

### Selection
- Controlled by PSW bits:
  - RS1
  - RS0

| RS1 | RS0 | Bank |
|------|------|------|
| 0 | 0 | Bank 0 |
| 0 | 1 | Bank 1 |
| 1 | 0 | Bank 2 |
| 1 | 1 | Bank 3 |

### Used For

## Program Counter (PC)

### Definition
- 16-bit register.

### Purpose
- Stores address of next instruction to execute.

### Importance
Without PC:
- CPU cannot know
  - where current instruction is
  - where next instruction is

# Program Status Word (PSW)

## Definition
- 8-bit Flag Register.
- Stores status of arithmetic and logical operations.

### PSW Format

```text
CY AC F0 RS1 RS0 OV -- P
```

| Bit | Symbol | Function |
|------|---------|----------|
| PSW.7 | CY | Carry Flag |
| PSW.6 | AC | Auxiliary Carry Flag |
| PSW.5 | F0 | User Flag |
| PSW.4 | RS1 | Register Bank Select |
| PSW.3 | RS0 | Register Bank Select |
| PSW.2 | OV | Overflow Flag |
| PSW.1 | -- | User Defined |
| PSW.0 | P | Parity Flag |

---

## Carry Flag (CY)

### Set When
- Arithmetic carry occurs.

### Example
```text
255 + 1
```

Produces carry.

---

## Auxiliary Carry (AC)

### Purpose
- Used in BCD arithmetic.
- Indicates carry between lower nibble and upper nibble.

---

## F0 Flag

### Purpose
- General-purpose flag.
- Available to programmer.

---

## RS1 & RS0

### Purpose
- Select active register bank.

---

## Overflow Flag (OV)

### Set When
- Arithmetic result exceeds capacity of register.

---

## Parity Flag (P)

### Purpose
- Indicates parity of Accumulator.

### Usage
- Error detection in communication.

---

# Stack Pointer (SP)

## Stack

### Definition
- Temporary memory area.
- Follows:
  - LIFO (Last In First Out)

### Operations
- PUSH → Store data
- POP → Retrieve data

---

## Stack Pointer

### Definition
- 8-bit register.

### Range
```text
00H - FFH
```

### Initial Value
```text
07H
```

### Purpose
- Points to top of stack.

---

# Bus Control Signals

## PSEN (Program Store Enable)

### Purpose
- Enables external program memory.

### Usage
- Used when code is stored in external memory.

---

## ALE (Address Latch Enable)

### Purpose
- Separates address and data information.

### Usage
- Mainly used with external memory interfacing.

---

## EA (External Access)

### Purpose
- Selects memory source.

### EA = High
- Use internal ROM.

### EA = Low
- Use external memory.

---

## RST (Reset)

### Purpose
- Resets 8051.

### Effect
- Loads registers with default values.
- Starts fresh execution.

---

# On-Chip Oscillator

## Purpose
- Generates clock signal.

## Crystal Frequency

```text
12 MHz
```

## Importance
- Synchronizes all CPU operations.

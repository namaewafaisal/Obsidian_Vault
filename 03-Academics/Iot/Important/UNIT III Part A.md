### 1. List the core characteristics of IoT.

* Connectivity (internet/network connection)
* Sensing capability
* Intelligence and data processing
* Unique identification of devices
* Automation and control
* Scalability
* Interoperability (different devices working together)
* Real-time data exchange

---

### 2. What are Arduino shields?

**Arduino Shields** are add-on circuit boards that can be plugged onto an Arduino board to extend its functionality without modifying the main board.

**Examples:**

* Wi-Fi Shield
* Ethernet Shield
* Motor Driver Shield
* GSM Shield
* GPS Shield

---

### 3. Difference between sensors and actuators

| Sensor                                               | Actuator                                         |
| ---------------------------------------------------- | ------------------------------------------------ |
| Converts physical quantities into electrical signals | Converts electrical signals into physical action |
| Input device                                         | Output device                                    |
| Collects data from the environment                   | Performs actions based on commands               |
| Examples: Temperature sensor, LDR, IR sensor         | Examples: Motor, Relay, LED, Buzzer              |

**Example:**
A temperature sensor detects room temperature, and a fan motor (actuator) turns on when the temperature becomes high.

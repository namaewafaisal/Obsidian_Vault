# 🧠 Decision Levels & Information Systems

## 🧩 Core Idea
Organizations make decisions at different levels, each supported by specific information systems.

---

## ⚙️ Decision Levels

### 🔹 Strategic Level (Top Management)
- Long-term decisions  
- Example: Expansion, new products  

---

### 🔹 Tactical Level (Middle Management)
- Short-term planning  
- Example: Resource allocation, project planning  

---

### 🔹 Operational Level (Lower Level)
- Day-to-day decisions  
- Example: Transactions, routine tasks  

---

## ⚙️ Information Systems

### 🔹 ESS (Executive Support System)
- Supports strategic level  
- Provides summarized data  

---

### 🔹 MIS (Management Information System)
- Supports tactical level  
- Provides reports and analysis  

---

### 🔹 TPS (Transaction Processing System)
- Supports operational level  
- Handles daily transactions  

---

## ⚖️ Mapping

| Level        | Decision Type   | System |
|--------------|----------------|--------|
| Strategic    | Long-term      | ESS    |
| Tactical     | Medium-term    | MIS    |
| Operational  | Daily          | TPS    |

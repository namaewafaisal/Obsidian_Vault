# What Even Is Software Engineering

Software Engineering is the disciplined and systematic approach to building, maintaining, and evolving software systems.

## Core Idea
Programming focuses on writing code.  
Software Engineering focuses on building reliable, scalable, maintainable systems.

## Why SE Exists
Large software systems became difficult to:
- manage
- maintain
- test
- scale
- deliver on time

This led to the **Software Crisis** in the 1960s.

## Software Crisis
Problems faced:
- project failures
- budget overruns
- poor maintainability
- unreliable systems

The term **Software Engineering** became popular during the:
- 1968 NATO Software Engineering Conference

## Software Engineer vs Programmer

| Programmer | Software Engineer |
|---|---|
| Focuses on coding | Focuses on full system lifecycle |
| Small-scale thinking | Large-scale thinking |
| Individual work | Team collaboration |
| Immediate solution | Long-term maintainability |

## Main Goal of Software Engineering
Manage software complexity using:
- processes
- design
- testing
- documentation
- maintenance practices

## Important Authors
- Ian Sommerville
- Roger Pressman

## Key Insight
As software size grows, complexity grows much faster than code size.

Software Engineering exists to control that complexity.

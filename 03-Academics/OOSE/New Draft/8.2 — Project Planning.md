# 8.2 — Project Planning

Project Planning:
> defining how the project will be executed and managed.

Goal:
- organize development
- define timelines
- allocate resources
- manage risks

---

# Main Planning Activities

| Activity | Purpose |
|---|---|
| Scope Planning | Define project boundaries |
| Time Planning | Estimate schedule |
| Resource Planning | Allocate people/tools |
| Cost Planning | Estimate budget |
| Risk Planning | Identify possible issues |
| Quality Planning | Define quality standards |

---

# Scope Planning

Defines:
> what features/work are included

Example:

```text
Chat App Features
- login
- messaging
- notifications
```

Excluded:

```text
video calls
payments
```

Helps prevent:
> scope creep

---

# Work Breakdown Structure (WBS)

Large project divided into smaller tasks.

Example:

```text
Build E-Commerce App
├── Frontend
├── Backend
├── Database
├── Testing
└── Deployment
```

Benefits:
- easier estimation
- task assignment
- progress tracking

---

# Time Planning

Estimates:
- task duration
- milestones
- deadlines

Common tools:
- Gantt Charts
- CPM
- PERT

---

# Milestone

Major project checkpoint.

Example:

```text
MVP completed
```

---

# Resource Planning

Determines:
- developers
- testers
- infrastructure
- tools
- budget needs

---

# Risk Planning

Identifies:
- technical risks
- schedule risks
- dependency risks

Example:

```text
Payment API instability
```

Mitigation:

```text
prepare fallback provider
```

---

# Quality Planning

Defines:
- testing standards
- code review process
- deployment criteria

---

# Task Dependencies

Some tasks depend on others.

Example:

```text
Database Schema
→ Backend APIs
→ Frontend Integration
```

---

# Deliverables

Expected project outputs.

Examples:
- design document
- deployed application
- test report

---

# Common Planning Mistakes

- unrealistic estimation
- ignoring risks
- poor scope definition
- unmanaged scope creep

---

# Important Insight

Project Planning converts:
> project goals into structured executable tasks and schedules

# 8.1 — Software Project Management (SPM)

Software Project Management:
> planning, organizing, monitoring, and controlling software projects.

Goal:
> deliver software within:
- time
- budget
- scope
- quality constraints

---

# Main Responsibilities

- planning
- scheduling
- resource management
- risk management
- progress tracking
- team coordination

---

# Main Project Constraints

```text
Time
Cost
Scope
Quality
```

Changing one constraint often affects others.

Example:
- adding features may increase:
  - cost
  - development time

---

# Project Manager Responsibilities

| Responsibility | Meaning |
|---|---|
| Planning | Define roadmap/goals |
| Scheduling | Assign timelines/tasks |
| Resource Management | Manage people/tools/budget |
| Risk Management | Handle possible issues |
| Monitoring | Track project progress |
| Communication | Coordinate stakeholders |

---

# Software Project Lifecycle

```text
Planning
→ Requirements
→ Design
→ Development
→ Testing
→ Deployment
→ Maintenance
```

Project management exists throughout lifecycle.

---

# Project Planning

Defines:
- goals
- scope
- timeline
- resources
- deliverables

Example:

```text
Food Delivery App
Timeline: 6 months
Team: 5 developers
```

---

# Scope Management

Scope defines:
> what work/features are included

Poor scope control causes:
> scope creep

---

# Scope Creep Example

```text
Initially:
basic chat app

Later added:
video calls
AI assistant
payments
```

Uncontrolled additions increase complexity.

---

# Risk Management

Handles:
- technical risks
- schedule risks
- budget risks
- dependency risks

Example:

```text
key developer leaving project
```

---

# Scheduling

Tasks organized using:
- timelines
- dependencies
- milestones

Common tools:
- Gantt Charts
- CPM
- PERT

---

# Quality Management

Ensures:
- standards maintained
- testing performed
- defects minimized

---

# Common Causes of Project Failure

- unclear requirements
- poor estimation
- weak communication
- unmanaged scope creep
- unrealistic deadlines
- poor risk management

---

# Important Insight

Software Project Management ensures:
> software development proceeds in an organized and controlled manner

# 3.4 — The XP Process Flow

XP follows a continuous iterative loop:

User Stories
→ Release Planning
→ Iteration Planning
→ Coding + Testing
→ Small Release
→ Customer Feedback
→ Repeat

---

# User Stories

Requirement format:

As a [role],
I want [feature],
so that [benefit]

Focus:
- user value
- simple requirements

---

# Release Planning

- choose stories for release
- rough estimation
- prioritization

Release = collection of iterations.

---

# Iteration Planning

Short-term planning:
- usually 1–2 weeks

Select tasks/features for current iteration only.

---

# Coding + Testing

Uses XP practices:
- TDD
- pair programming
- CI
- refactoring

Testing happens continuously.

---

# Small Release

Deliver working software frequently.

---

# Customer Feedback

Customer reviews release and gives feedback for future iterations.

---

# Iteration vs Release

| Iteration | Release |
|---|---|
| Small cycle | Collection of iterations |
| Internal progress | User-facing delivery |

---

# Important Insight

XP focuses on:
- fast feedback
- continuous adaptation
- small iterative delivery

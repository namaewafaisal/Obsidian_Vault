# 1.3 — What Is a Software Process

A software process is:
> A structured sequence of activities used to develop software.

---

# Purpose of a Software Process

Used to:
- organize development
- manage complexity
- improve coordination
- make development predictable

Without a process:
- chaos occurs
- deadlines fail
- maintenance becomes difficult

---

# Common Software Process Flow

Requirements
→ Design
→ Implementation
→ Testing
→ Deployment
→ Maintenance

Output of one stage becomes input for the next.

---

# Process vs Methodology vs Framework

## Process
Defines:
> What activities happen and in what order.

Examples:
- Waterfall
- Incremental

---

## Methodology
Defines:
> How development is performed.

Examples:
- XP (Extreme Programming)

Includes:
- practices
- techniques
- rules

---

## Framework
Provides:
> A reusable workflow structure.

Example:
- Scrum

Includes:
- roles
- meetings
- workflow guidance

---

# Process Model

A process model is:
> A simplified representation of a software process.

Used to:
- understand workflow
- organize development
- manage projects

---

# Key Insight

Different projects require different process models.

Examples:
- Waterfall → fixed requirements
- Agile → changing requirements
- RAD → rapid development

---

# Main Goal

Make software development:
- systematic
- manageable
- measurable
- repeatable

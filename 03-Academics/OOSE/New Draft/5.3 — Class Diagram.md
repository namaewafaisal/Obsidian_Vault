# 5.3 — Class Diagram

Class Diagram:
> structural blueprint of the system.

Shows:
- classes
- attributes
- methods
- relationships

Focus:
> what objects/classes exist internally.

---

# Basic Structure

```mermaid
classDiagram
    class User {
        +String name
        -String password
        +login()
    }
```

---

# Explanation

| Part | Meaning |
|---|---|
| User | Class |
| name, password | Attributes |
| login() | Method |
| + | Public |
| - | Private |

---

# Main Relationships

---

# Association

Simple interaction relationship.

```mermaid
classDiagram
    Student --> Book
```

Student interacts with Book.

---

# Inheritance (Generalization)

```mermaid
classDiagram
    User <|-- Admin
```

Admin:
> IS-A User

Equivalent Java:
```java
class Admin extends User
```

---

# Aggregation

Weak ownership.

```mermaid
classDiagram
    Department o-- Teacher
```

Teacher can exist independently.

---

# Composition

Strong ownership.

```mermaid
classDiagram
    House *-- Room
```

Room depends on House.

---

# Aggregation vs Composition

| Aggregation | Composition |
|---|---|
| Weak ownership | Strong ownership |
| Child independent | Child dependent |
| o-- | *-- |

---

# Dependency

Temporary usage relationship.

```mermaid
classDiagram
    PaymentService ..> PaymentGateway
```

---

# Multiplicity

Shows object count relationship.

```mermaid
classDiagram
    Customer "1" --> "*" Order
```

One customer can have many orders.

---

# Common Multiplicity

| Symbol | Meaning |
|---|---|
| 1 | Exactly one |
| * | Many |
| 0..1 | Optional |
| 1..* | One or more |

---

# Full Example

```mermaid
classDiagram
    class User {
        +login()
    }

    class Admin {
        +manageUsers()
    }

    class Order {
        +placeOrder()
    }

    User <|-- Admin
    User --> Order
```

---

# Important Insight

Class Diagram models:
> internal structure of the system.

Unlike Use Case Diagram,
it focuses on:
- architecture
- OOP relationships
- system design

Not:
- workflows
- runtime execution
- algorithms

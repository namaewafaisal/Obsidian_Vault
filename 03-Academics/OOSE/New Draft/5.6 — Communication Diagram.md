# 5.6 — Communication Diagram

Communication Diagram:
> models how objects/components communicate with each other.

Focus:
- object collaboration
- message exchange
- interaction relationships

Not focused mainly on:
- workflow logic
- algorithms
- timeline visualization

---

# Main Components

| Component | Meaning |
|---|---|
| Object | Interaction participant |
| Link | Communication connection |
| Message | Interaction |
| Sequence Number | Message order |

---

# Basic Example

```text
+-----------+        1: checkout()       +------+
| Customer  | -------------------------> | App  |
+-----------+                            +------+
                                              |
                                              | 2: processPayment()
                                              v
                                      +------------------+
                                      | PaymentService   |
                                      +------------------+
                                              |
                                              | 3: verifyTransaction()
                                              v
                                         +--------+
                                         | Bank   |
                                         +--------+
```

---

# Explanation

Focus is on:
> which objects communicate.

Numbers preserve execution order because:
- there is no vertical timeline.

---

# Sequence vs Communication

| Sequence Diagram | Communication Diagram |
|---|---|
| Timeline-focused | Relationship-focused |
| Easier flow tracing | Easier interaction overview |
| Vertical order | Network-like structure |

---

# Communication vs Activity

| Communication Diagram | Activity Diagram |
|---|---|
| Object interaction | Workflow/process |
| Message passing | Control flow |
| "Who communicates?" | "What happens next?" |

---

# Example Difference

## Communication Diagram Thinking

```text
Customer → App → PaymentService → Bank
```

Focus:
- participant interaction

---

## Activity Diagram Thinking

```text
Place Order
→ Process Payment
→ Payment Success?
```

Focus:
- workflow steps

---

# Important Insight

Communication Diagram and Sequence Diagram often model:
> the same runtime interaction

Difference:
- Sequence → time/order emphasis
- Communication → relationship emphasis

---

# When To Use

Best for:
- interaction overview
- service/object collaboration
- compact interaction modelling

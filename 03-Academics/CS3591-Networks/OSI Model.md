# OSI Model

**What it is**  
The **OSI (Open Systems Interconnection) model** is a **7-layer conceptual framework** defined by ISO to standardize how network communication is structured.

**Why it exists**  
To manage complexity by separating communication into layers for:
- Design
- Learning
- Troubleshooting

**Layers (Top → Bottom)**  
1. Application – User-facing network services  
2. Presentation – Encoding, encryption, compression  
3. Session – Session control, checkpoints  
4. Transport – End-to-end delivery  
5. Network – Logical addressing & routing  
6. Data Link – Framing, MAC addressing  
7. Physical – Bits on the wire

**Key point**  
OSI is **theoretical** and used mainly for **education and analysis**, not direct implementation.

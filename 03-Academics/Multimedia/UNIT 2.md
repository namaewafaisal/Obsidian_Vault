## Group 1 – Images and Color Models

### Pixel

* Smallest unit of a digital image
* Resolution = Width × Height

Examples:

* 1920 × 1080 → Full HD
* 3840 × 2160 → 4K

---

### Color Models

A color model defines how colors are represented digitally.

#### RGB (Additive)

* Red, Green, Blue
* Used in screens
* Starts with black

Examples:

* White → (255,255,255)
* Black → (0,0,0)

#### CMYK (Subtractive)

* Cyan, Magenta, Yellow, Black
* Used in printing
* Starts with white paper

### Memory Hook

```text
RGB → Screens Glow

CMYK → Printers Throw Ink
```

---

### Image Formats

| Format | Compression | Transparency | Animation | Best For          |
| ------ | ----------- | ------------ | --------- | ----------------- |
| JPEG   | Lossy       | ❌            | ❌         | Photos            |
| PNG    | Lossless    | ✅            | ❌         | Logos, UI         |
| GIF    | Lossless    | ✅            | ✅         | Simple animations |
| TIFF   | Lossless    | ✅            | ❌         | Printing          |

### Memory Hook

```text
Photos → JPEG

Logos → PNG

Animations → GIF

Printing → TIFF
```

## Group 2 – Compression

### Definition

Compression reduces multimedia file size by removing redundancy.

### Types

#### Lossless Compression

* No quality loss
* Reversible

Examples:

* PNG
* FLAC
* ZIP

#### Lossy Compression

* Some quality loss
* Irreversible

Examples:

* JPEG
* MP3
* MPEG

### Memory Hook

```text
Lossless → Less Loss

Lossy → Lose Some Data
```

### Audio Digitization

```text

```

### Key Terms

* Sampling Rate → 44.1 kHz (CD quality)
* Bit Depth → 16-bit, 24-bit

---

### Audio Formats

| Format | Compression | Quality         | Best For         |
| ------ | ----------- | --------------- | ---------------- |
| WAV    | None        | Excellent       | Editing          |
| MP3    | Lossy       | Good            | Streaming        |
| AAC    | Lossy       | Better than MP3 | Modern streaming |
| FLAC   | Lossless    | Excellent       | Archiving        |

### Memory Hook

```text

```

## Group 4 – Video Formats and Standards

### Video Components

* Frames
* Audio
* Metadata

### Key Terms

* FPS → Frames per second
* Resolution → HD, FHD, 4K
* Bitrate → Data per second

---

### MPEG

Moving Picture Experts Group

| Standard | Application |
| -------- | ----------- |
| MPEG-1   | VCD         |
| MPEG-2   | DVD, TV     |
| MPEG-4   | Streaming   |

---

### Codec vs Container

```text
Codec → Compresses

Container → Carries
```

Examples:

* Codecs → H.264, H.265
* Containers → MP4, AVI, MOV, MKV

---

### Video Formats

| MOV    | Apple ecosystem |

### Memory Hook

MP4 → Streaming

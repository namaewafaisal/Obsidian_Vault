## Group 1 – Authoring Fundamentals

> Big Question:
>
> How are multimedia applications created?

### Multimedia Authoring

Multimedia authoring is the process of integrating text, images, audio, video, animation, and interactivity to create multimedia applications.

Examples:

* E-learning modules
* Interactive websites
* Games
* Presentations

---

### Authoring Metaphor

An authoring metaphor defines how multimedia elements are organized and controlled.

Types:

* Card/Page-based
* Icon-based
* Time-based

---

## Group 2 – Authoring Metaphors and Tools

### 1. Card/Page-Based Authoring

Information is organized as pages or cards.

Users navigate between cards using buttons or hyperlinks.

Examples:

* HyperCard
* PowerPoint

Best for:

* E-learning
* Digital books
* Presentations

---

### 2. Icon-Based Authoring

Application flow is represented using icons connected by links.

Each icon performs a specific action.

Examples:

* Authorware

Best for:

* Training systems
* Tutorials

---

### 3. Time-Based Authoring

Media elements are synchronized along a timeline.

Examples:

* Adobe Animate
* Adobe Premiere Pro

Best for:

* Videos
* Animations
* Presentations

---

## Comparison of Authoring Metaphors

| Feature    | Card-Based | Icon-Based | Time-Based    |
| ---------- | ---------- | ---------- | ------------- |
| Structure  | Pages      | Flowchart  | Timeline      |
| Navigation | Hyperlinks | Icons      | Time sequence |
| Best For   | E-learning | Tutorials  | Animation     |
| Complexity | Low        | Medium     | High          |

---

### Cross-Platform Authoring Tools

Create applications that run on multiple operating systems.

Examples:

* Unity
* Adobe Animate
* HTML5

Advantages:

* Reusable content
* Reduced development cost
* Wider compatibility

## Group 3 – Multimedia Editing Tools

> Big Question:
>
> How is multimedia content created and modified?

### Image Editing Tools

Used to create and modify images.

Examples:

* Adobe Photoshop
* GIMP

Functions:

* Cropping
* Resizing
* Color correction

---

### Audio Editing Tools

Used to record and edit audio.

Examples:

* Audacity
* Adobe Audition

Functions:

* Noise reduction
* Mixing
* Trimming

---

### Video Editing Tools

Used to edit video content.

Examples:

* Adobe Premiere Pro
* DaVinci Resolve

Functions:

* Cutting
* Transitions
* Effects

---

### Interactive Multimedia Presentations

Combine:

* Text
* Images
* Audio
* Video
* Animation

Examples:

* PowerPoint
* Prezi

Features:

* User interaction
* Non-linear navigation
* Multimedia integration

## Group 4 – 3D Modelling and Animation

> Big Question:
>
> How are virtual objects created?

### 3D Modelling

3D modelling is the process of creating three-dimensional digital objects.

Dimensions:

* Width
* Height
* Depth

Examples:

* Game characters
* Buildings
* Product designs

Tools:

* Blender
* Maya
* 3ds Max

---

### Animation Tools

Used to create movement in digital objects.

Examples:

* Blender
* Adobe Animate

Applications:

* Films
* Games
* Simulations

## Group 5 – Simulation and Virtual Learning

> Big Question:
>
> How does multimedia create immersive experiences?

### Simulation

Simulation is the imitation of real-world processes in a virtual environment.

Examples:

* Flight simulators
* Driving simulators
* Medical training

Advantages:

* Safe learning environment
* Cost-effective
* Repeatable practice

---

### Virtual Learning

Virtual learning uses multimedia technologies to create interactive educational environments.

Features:

* Self-paced learning
* Interactive content
* Remote access
* Assessments

Examples:

* Virtual classrooms
* Online laboratories
* E-learning platforms

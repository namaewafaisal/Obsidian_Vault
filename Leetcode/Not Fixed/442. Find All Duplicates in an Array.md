## LC 442. Find All Duplicates in an Array

### Problem (Statement)

Given an integer array `nums` of length `n` where:
- `1 ≤ nums[i] ≤ n`
- Each integer appears **once or twice**

Return all elements that appear **exactly twice**.

Constraints:
- Must run in `O(n)` time
- Must use **constant extra space** (excluding output)

---

### Key Observation

> The value range `1..n` allows the array itself to be used as a **frequency marker**.

Each value can be mapped directly to an index:
```
value v → index v - 1
```

This removes the need for external data structures.

---

### Core Idea (In-Place Marking Invariant)

Use the **sign of elements** to mark visits:

Invariant:
- `nums[v - 1] > 0` → value `v` has **not been seen**
- `nums[v - 1] < 0` → value `v` has been **seen before**

A duplicate is detected when an index is encountered whose value is already negative.

---

### Why This Works

- Each number maps to a **unique index**
- Negating does not destroy identity (magnitude preserved)
- Each index is modified at most once
- Second encounter reliably signals duplication

This simulates a hash set **without extra space**.

---

### Algorithm Overview

1. Traverse the array
2. For each value:
   - Compute mapped index using absolute value
   - If value at index is negative → duplicate found
   - Otherwise, negate value at index
3. Collect duplicates and return

Time: `O(n)`  
Space: `O(1)` extra (output excluded)

---

### Final Code (Java)

```java
class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        List<Integer> lst = new ArrayList<>();

        for (int i : nums) {
            int ind = Math.abs(i) - 1;

            if (nums[ind] < 0) {
                lst.add(Math.abs(i));
            }

            nums[ind] = -nums[ind];
        }
        return lst;
    }
}
```

---

### Common Mistakes

- Using `HashSet` instead of in-place marking
- Forgetting to use `Math.abs`
- Modifying the array without preserving value identity
- Applying this pattern when values are **not bounded by n**

> Use index `value - 1` as a marker and flip its sign; encountering a negative value signals a duplicate.

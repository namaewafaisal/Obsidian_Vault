### Problem (summary)

Given a string `s`, find the length of the **longest substring** without repeating characters.

---

### Example

Input: `s = "abcabcbb"`

Output: `3`

Explanation: The answer is `"abc"`, with the length of 3.

---

### Pattern Classification

* Sliding Window (Variable Size)
* Two Pointers
* Frequency Map / Hash Table
* String Manipulation

---

### Key Invariant

* A window  is **valid** if every character within it has a frequency of exactly 1.
* If any character's frequency exceeds 1, the window is **invalid**, and we must shrink it from the left.

---

### Thinking Log (Evolution of the Solution)

* **Initial Thought:** Generate all possible substrings and check each for uniqueness.
* *Correction:* This is **O(n³)** or **O(n²)**, which is too slow for large strings.
* **Early Confusion:** Should I use a `Set` or a `Map`?
* *Correction:* A `Map` is useful to track frequencies, but a `Set` or a frequency array can also work since we only care if a character is "seen."
* **Rejected Idea:** Jumping the `left` pointer directly to a stored index.
* *Correction:* While optimized, the standard "shrink-while-invalid" approach is more robust and easier to debug for variable window problems.
* **Key Insight:** The "Shrinking Rule" is triggered specifically by the character at the `right` pointer. If `freq.get(s.charAt(right)) > 1`, the window must contract until that specific character is back to a frequency of 1.

---

### Implementation Strategy

1. Initialize `left` and `right` pointers at the start of the string.
2. Use a `HashMap` to track the frequency of characters in the current window.
3. **Expand:** Move the `right` pointer and increment the frequency of `s[right]`.
4. **Shrink:** While `freq.get(s[right]) > 1`, decrement the frequency of `s[left]` and increment `left`.
5. **Update:** After ensuring the window is valid, calculate `len = max(len, right - left + 1)`.

---

### Code

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> freq = new HashMap<>();
        int right = 0, left = 0;
        int len = 0;
        int size = s.length();
        
        while(right < size) {
            char r = s.charAt(right);
            freq.put(r, freq.getOrDefault(r, 0) + 1);
            
            // Shrinking Rule: If a duplicate appears, shrink from the left
            while(freq.get(r) > 1) {
                char l = s.charAt(left++);
                freq.put(l, freq.get(l) - 1);
                if(freq.get(l) == 0) {
                    freq.remove(l);
                }
            }
            
            // Window is now valid; update global max
            len = Math.max(len, right + 1 - left);
            right++;
        }
        return len;
    }
}

```

### Complexity Analysis

| Metric | Complexity | Note |
| --- | --- | --- |
| **Time** | O(n) | Each character is visited at most twice (left/right). |
| **Space** | O(k) | Where k is the size of the character set (e.g., 26 or 128). |

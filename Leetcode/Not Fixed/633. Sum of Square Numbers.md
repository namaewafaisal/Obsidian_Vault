## LC 633. Sum of Square Numbers

### Problem (Statement)

Given a non-negative integer `c`, determine whether there exist **two integers** `a` and `b` such that:

```
a² + b² = c
```

Constraints:
- `0 ≤ c ≤ 2³¹ − 1`
- `a` and `b` can be `0`

---

### Key Observation

> The square function is **monotonically increasing** for non-negative integers.

This allows the problem to be reframed from:
- checking all pairs `(a, b)`  
to:
- **searching in a monotonic space**

---

### Core Idea (Two-Pointer Invariant)

Let:
- `left = 0`
- `right = floor(sqrt(c))`

Invariant:
- If `left² + right²` is too large → decrease `right`
- If it is too small → increase `left`

This works because:
- Increasing `left` increases the sum
- Decreasing `right` decreases the sum

---

### Why Brute Force Fails

- Trying all `(a, b)` pairs is `O(n²)`
- Upper bound is too large
- No pruning without monotonic reasoning

Two pointers reduce it to `O(sqrt(c))`.

---

### Algorithm Overview

1. Initialize `left = 0`, `right = floor(sqrt(c))`
2. While `left ≤ right`:
   - Compute `sum = left² + right²`
   - Adjust pointers based on comparison with `c`
3. Return true if match found, else false

Time: `O(sqrt(c))`  
Space: `O(1)`

---

### Final Code (Java)

```java
class Solution {
    public boolean judgeSquareSum(int c) {
        long left = 0;
        long right = (long) Math.sqrt(c);

        while (left <= right) {
            long sum = left * left + right * right;

            if (sum == c) {
                return true;
            } else if (sum < c) {
                left++;
            } else {
                right--;
            }
        }
        return false;
    }
}
```

---

### Common Mistakes

- Using `int` instead of `long` (overflow)
- Trying nested loops
- Forgetting `0` is a valid value
- Using binary search unnecessarily

---

### Pattern Connection

- Two pointers on monotonic space
- Similar to:
  - pair sum in sorted array
  - square / cube sum problems

### One-Sentence Recall

> Use two pointers on squared values because increasing one pointer always increases the sum.

## LC 2460. Apply Operations to an Array

### Problem (Statement)

Given an integer array `nums`, apply the following operations **in order**:

1. Traverse the array from left to right  
2. If `nums[i] == nums[i + 1]`:
   - Set `nums[i] = nums[i] * 2`
   - Set `nums[i + 1] = 0`
3. After completing all such operations, **move all zeros to the end** of the array  
   - Preserve the relative order of non-zero elements

Return the modified array.

---

### Key Observation

> This is not a single transformation problem, but **two independent phases**:
>
> 1. **Local merging** based on adjacency  
> 2. **Global zero compaction**

Trying to mix these two steps leads to incorrect behavior.

---

### Core Idea (Two-Phase Invariant)

#### Phase 1 — Apply merge rules
- Traverse once
- Only compare `i` and `i + 1`
- Do **not** skip indices after merging
- Zero is intentionally introduced and handled later

Invariant:
> All valid merges are completed before any shifting happens.

---

#### Phase 2 — Move zeros to the end
- Use two pointers:
  - `right` scans the array
  - `left` tracks the position to place the next non-zero
- Swap when a non-zero is found at `right`

Invariant:
> Elements before `left` are non-zero and in correct order.

---

### Why Order Matters

- Shifting zeros **before** all merges are done can:
  - break adjacency
  - cause missed merges
- Separating merge and compaction ensures correctness

---

### Algorithm Overview

1. Iterate once to apply merge rules
2. Use two pointers to compact non-zero elements
3. Return the modified array

Time: `O(n)`  
Space: `O(1)`

---

### Final Code (Java)

```java
class Solution {
    public int[] applyOperations(int[] nums) {
        // Phase 1: apply merge operations
        for (int i = 0; i < nums.length - 1; i++) {
            if (nums[i] == nums[i + 1]) {
                nums[i] = nums[i] * 2;
                nums[i + 1] = 0;
            }
        }

        // Phase 2: move zeros to the end
        int left = 0;
        int right = 0;

        while (right < nums.length) {
            if (nums[right] != 0) {
                int temp = nums[right];
                nums[right] = nums[left];
                nums[left] = temp;
                left++;
            }
            right++;
        }
        return nums;
    }
}
```

### Common Mistakes

- Trying to merge and shift zeros in the same pass
- Skipping index after a merge
- Using extra arrays unnecessarily
- Forgetting to preserve order of non-zero elements

## LC 283. Move Zeroes

### Problem (Statement)

Given an integer array `nums`, move all `0`s to the **end of the array** while maintaining the **relative order of non-zero elements**.

Constraints:
- Must be done **in-place**
- Minimize operations
- Preserve order of non-zero elements

---

### Key Observation

> This is not about “finding zeros”, but about **maintaining the next correct position for a non-zero element**.

Once this is seen, the problem becomes a **stable partition** problem.

---

### Core Idea (Slow–Fast Pointer Invariant)

Maintain two pointers:

- `right` → scans every element
- `left` → points to the position where the **next non-zero** should go

Invariant:
> All indices `< left` contain **non-zero elements in correct order**.

Whenever `nums[right]` is non-zero:
- Swap it into position `left`
- Increment `left`

### Thinking Log (Mandatory)

#### My first draft (your words, summarized)

> I used two pointers `left` and `right`.  
>  
> I tried to:
> - Move `right` until it finds a non-zero  
> - Move `left` until it finds a zero  
> - Swap them  
>  
> I added conditions to stop when both were zero.  
>  
> The logic became nested, and I had to add a return to avoid infinite loops.

First draft code (conceptually):
- Nested `while` loops
- Manual zero/non-zero searching
- Extra termination condition

---

#### Why this approach was flawed (correction)

- You were **searching** for positions instead of **maintaining an invariant**
- Nested loops made pointer movement hard to reason about
- Special-case termination (`if both zero then return`) is a red flag
- Pointer crossing and equality cases were fragile

This approach works by luck, not by guarantee.

---

#### Corrected mental model

> Let `right` visit every element exactly once.  
> Let `left` only advance when a valid non-zero is placed.

No searching.  
No nested loops.  
No special termination.

Just:
- **scan**
- **place**
- **advance**

---

### Algorithm Overview

1. Initialize `left = 0`
2. Iterate `right` from `0` to `n - 1`
3. If `nums[right] != 0`:
   - Swap `nums[left]` and `nums[right]`
   - Increment `left`
4. End result:
   - All non-zeros in original order at front
   - All zeros pushed to the back

Time: `O(n)`  
Space: `O(1)`

---

### Final Code (Java)

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int left = 0;
        int right = 0;

        while (right < nums.length) {
            if (nums[right] != 0) {
                int temp = nums[right];
                nums[right] = nums[left];
                nums[left] = temp;
                left++;
            }
            right++;
        }
    }
}
```

---

### Why This Version Is Correct and Cleaner

- Each pointer has **one responsibility**
- Every index is visited **once**
- No special-case exits
- Invariant is easy to explain in an interview

This is the **canonical solution**.

- Forgetting that order must be preserved

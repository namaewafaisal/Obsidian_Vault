## LC 503. Next Greater Element II

### Problem (Statement)

Given a **circular integer array** `nums`, return an array `result` where:

```
result[i] = the first greater element to the right of nums[i]
```

If no such element exists, return `-1` for that index.

Circular means:
- After the last index, search continues from the beginning

---

### Key Observation

> The problem is identical to **Next Greater Element**, except the array is **circular**.

So:
- Each element may need to look **past the end**
- But we still want the **first greater element to the right**

---

### Core Idea (Monotonic Stack Invariant)

Maintain a **monotonic decreasing stack** (values):

Invariant:
- Stack stores candidates that are **greater than current element**
- Top of stack is always the **nearest greater element** seen so far

When a new element arrives:
- Pop all elements `≤ current` (they can never be answers)
- The remaining top (if any) is the next greater element

---

### Circular Handling (Critical Trick)

> Simulate circularity by traversing the array **twice**.

Instead of modifying the array:
- Iterate from `2n - 1` down to `0`
- Use:
```
index = i % n
```

This allows:
- First pass → populate the stack
- Second pass → compute answers

---

### Why Reverse Traversal Is Used

We want **next greater to the right**, so:
- Traverse from **right → left**
- Stack always represents elements to the right of current index

This is the same logic as standard NGE, applied twice.

---

### Algorithm Overview

1. Initialize result array with `-1`
2. Use a monotonic decreasing stack
3. Traverse indices from `2n - 1` → `0`
4. For each index:
   - Pop smaller or equal elements from stack
   - If `i < n`, record the answer
   - Push current element to stack
5. Return result

Time: `O(n)`  
Space: `O(n)`

---

### Final Code (Java)

```java
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        Stack<Integer> stack = new Stack<>();
        int n = nums.length;
        int[] result = new int[n];

        Arrays.fill(result, -1);

        for (int i = 2 * n - 1; i >= 0; i--) {
            int index = i % n;

            while (!stack.isEmpty() && stack.peek() <= nums[index]) {
                stack.pop();
            }

            if (i < n) {
                result[index] = stack.isEmpty() ? -1 : stack.peek();
            }

            stack.push(nums[index]);
        }
        return result;
    }
}
```

---

### Why This Works

- Each element is pushed and popped at most once → `O(n)`
- Stack always holds **valid future candidates**
- Modulo indexing simulates circular array without extra space

---

### Common Mistakes

- Forgetting circularity (single pass only)
- Traversing left → right
- Using indices in stack unnecessarily (values are sufficient here)
- Recording results during both passes

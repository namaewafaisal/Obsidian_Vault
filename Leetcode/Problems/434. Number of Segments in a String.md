# 434. Number of Segments in a String

## Problem (LeetCode Statement)

**Input:**
- `String s` — a string of characters

**Output:**
- Number of segments (words) in the string

**Task:**
Count the number of non-empty segments separated by spaces.

---

## Constraints

- `0 <= s.length <= 300`
- Segments are separated by one or more spaces

---

## Examples
```
Input:  s = "Hello, my name is John"
Output: 5
```
```
Input:  s = "   fly me   to   the moon  "
Output: 5
```

---

## What Actually Matters

- Multiple consecutive spaces between words — trim and split alone may produce empty strings
- `split(" ")` without trim can produce empty tokens at start/end
- Filter out empty segments after splitting

---

## Core Insight

> Trim the string, split by one or more spaces, then count only non-empty tokens.

---

## Invariant / Mental Model

> After trim and split, any token with length > 0 and first char != space is a valid segment.

---

## Algorithm (High Level)

1. Trim the string
2. Split by `" +"` (one or more spaces)
3. Count tokens where `length > 0`

---

## Code (Reference Only)
```java
class Solution {
    public int countSegments(String s) {
        if (s.trim().isEmpty()) return 0;
        String[] parts = s.trim().split(" +");
        int count = 0;
        for (String part : parts) {
            if (part.length() > 0) count++;
        }
        return count;
    }
}
```

---

## Edge Cases to Recall

- All spaces → trim produces empty string → return 0
- Leading/trailing spaces → trim handles it
- Multiple spaces between words → `split(" +")` collapses them

---

## One-Line Recall

> Trim, split by one or more spaces, count non-empty tokens.

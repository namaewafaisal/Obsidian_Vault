## LC 75. Sort Colors

---

### Problem (summary)

Sort an array containing `0`s, `1`s, and `2`s in-place. You must use constant extra space and ideally solve it in a single pass without using built-in sort functions.

---

### Key Invariant

* **Low Pointer:** Everything to the left of `low` is a `0`.
* **High Pointer:** Everything to the right of `high` is a `2`.
* **Mid Pointer:** Acts as the "scanning eye." Everything between `low` and `mid-1` is a `1`.
* The goal is to process the "unexamined" elements between `mid` and `high`.

---

### Thinking Log (Evolution of the Solution)

* **User Question:** Is this one-pass sorting a concept I need to learn or can I create it on my own?
* **AI Insight:** It's the Dutch National Flag problem. You can derive it by thinking about "territories" for each color.
* **User Confusion:** How do the pointers manage the boundaries? What happens when we swap?
* **AI Logic:** If you see a `0`, swap to the front and move both pointers. If you see a `2`, swap to the back but *don't* move the eye (`mid`) yet because the new element hasn't been inspected.
* **User Concern:** Wait, if I swap elements inside a helper method, aren't those changes local to that method?
* **AI Correction:** In Java, arrays are objects. Passing the array passes a reference, so the `swap` happens on the actual memory, not a copy.
* **Final Step:** Decided to memorize the logic and implement it manually to ensure the pattern is internalized.

---

### Implementation Strategy

1. Use `low` for the next `0`, `high` for the next `2`, and `mid` to scan.
2. **Case 0:** Swap `nums[mid]` with `nums[low]`. Increment both.
3. **Case 1:** It's already in the middle zone. Just increment `mid`.
4. **Case 2:** Swap `nums[mid]` with `nums[high]`. Decrement `high`. **Crucially**, do not increment `mid` because the element swapped from the back is unknown and needs inspection.

---

### Final Code (Java)

```java
class Solution {
    public void sortColors(int[] nums) {
        int low = 0;
        int high = nums.length - 1;
        int mid = 0;

        while (mid <= high) {
            if (nums[mid] == 0) {
                // Swap current element with the low pointer position
                int temp = nums[mid];
                nums[mid] = nums[low];
                nums[low] = temp;

                low++;
                mid++;
            }   
            else if (nums[mid] == 1) {
                // 1s stay in the middle, just move the scan pointer
                mid++;
            }
            else { // nums[mid] == 2
                // Swap current element with the high pointer position
                int temp = nums[mid];
                nums[mid] = nums[high];
                nums[high] = temp;
                
                // Shrink the high boundary, but stay at mid to check the new value
                high--;
            }
        }
    }
}

```

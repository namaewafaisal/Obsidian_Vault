## LC 121. Best Time to Buy and Sell Stock

| **Metric** | **Value** |
| --- | --- |
| **Date** | December 25, 2025 |
| **Time Taken** | 18 minutes |
| **Difficulty** | Easy |
| **Pattern** | Prefix Minimum + Running Optimization |

---

### Problem (summary)

You are given an array `prices` where `prices[i]` is the stock price on day `i`. You are allowed to buy **once** and sell **once**, but you **must buy before you sell**. Return the **maximum profit** possible. If no profit is possible, return `0`.

---

### Example

Input: `prices = [7, 1, 5, 3, 6, 4]`

Output: `5`

Explanation: Buy at price `1` (day 2), sell at price `6` (day 5). Profit = `6 - 1 = 5`.

---

### Pattern Classification

* Prefix Optimization
* One-Pass Array Scan
* Order-Constrained Optimization (Buy must precede Sell)

---

### Key Invariant

* At any index `i`, if we decide to **sell today**, the best possible profit is `prices[i] - min(prices[0...i-1])`.
* By maintaining the **minimum price seen so far** as we iterate, we can calculate the potential profit at every step in constant time.

---

### Thinking Log (Evolution of the Solution)

* **Initial Thought:** This feels like it needs prefix and suffix arrays. Find the minimum on the left and the maximum on the right.
* *Correction:* A suffix array (maximum on the right) tells you what the best *future* sell is. But since we are iterating through the array, the current element **is** our sell candidate. We don't need to know the future; we just need to know the cheapest past.
* **Brute Force Realization:** Checking every pair  where  results in , which is too slow.
* **Optimization Step:** For each potential sell day, only the single cheapest day prior to it matters. All other prior days are "dominated" by the minimum.
* **Final Understanding:** We can evaluate "is today a good sell?" by looking only at the prefix minimum.

---

### Implementation Strategy

1. Initialize `minLeft` to a very large value (`Integer.MAX_VALUE`).
2. Initialize `profit` to `0`.
3. Iterate through the `prices` array:
* **Update Profit:** Calculate the difference between current price and `minLeft`. If it's higher than our current `profit`, update it.
* **Update Minimum:** If the current price is lower than `minLeft`, update `minLeft`.


4. Return the final `profit`.

---

### Code

```java
class Solution {
    public int maxProfit(int[] prices) {
        int minLeft = Integer.MAX_VALUE;
        int profit = 0;
        
        for(int i = 0; i < prices.length; i++){
            // Decision: If I sell today, is the profit better than my previous best?
            profit = Math.max(profit, prices[i] - minLeft);
            
            // Update the cheapest price seen so far for future sell days
            minLeft = Math.min(minLeft, prices[i]);
        }
        
        return profit;
    }
}

```

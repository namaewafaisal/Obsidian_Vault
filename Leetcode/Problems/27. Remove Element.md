# 27. Remove Element

## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`  
- Integer `val`

**Output:**  
- Return `k`, the number of elements not equal to `val`

**Task:**  
Remove all occurrences of `val` in-place and return the number of remaining elements.  
Order of elements does **not** matter.

---

## Constraints

- `0 ≤ nums.length ≤ 100`
- `0 ≤ nums[i] ≤ 50`
- `0 ≤ val ≤ 100`
- Must modify array in-place
- No extra array allowed

---

## Examples

```
Input:  nums = [3,2,2,3], val = 3
Output: 2
```

```
Input:  nums = [0,1,2,2,3,0,4,2], val = 2
Output: 5
```

---

## What Actually Matters

- Order does NOT matter
- In-place modification required
- Must be O(n)
- Only first `k` elements matter

---

## Core Insight

> Since order does not matter, we can swap unwanted elements with the end.

This avoids shifting elements repeatedly.

---

## Invariant / Mental Model

> Everything after `right` is already removed or irrelevant.

- `left` scans forward
- `right` shrinks the valid boundary

---

## Thinking Log (Evolution of the Solution)

### Initial Understanding (your words)

> “If I see the value, I can replace it with something from the end.”

Correct — because order does not matter.

---

### Core Logic (your words)

> “If nums[left] == val, swap with nums[right] and reduce right.”

Correct — but do **not** move left in this case.

---

### Important Detail

After swapping:
- Do NOT increment `left`
- Because the swapped value must be checked

If not equal:
- Move `left++`

---

## Algorithm (High Level)

1. Initialize:
   - `left = 0`
   - `right = n - 1`
2. While `left <= right`:
   - If `nums[left] == val`:
     - Swap with `nums[right]`
     - `right--`
   - Else:
     - `left++`
3. Return `right + 1`

---

## Code (Reference Only)

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int right = nums.length - 1;
        int left = 0;

        while (left <= right) {
            if (nums[left] == val) {
                int temp = nums[left];
                nums[left] = nums[right];
                nums[right] = temp;
                right--;
            } else {
                left++;
            }
        }
        return right + 1;
    }
}
```

## One-Line Recall

> Swap unwanted elements with the end and shrink the boundary; order does not matter.

# 13. Roman to Integer

## Problem (LeetCode Statement)

**Input:**  
- Roman numeral string `s`

**Output:**  
- Integer value represented by `s`

**Task:**  
Convert a Roman numeral into its corresponding integer.

---

## Constraints

- `1 ≤ s.length ≤ 15`
- `s` contains only `I, V, X, L, C, D, M`
- Input is guaranteed to be a valid Roman numeral

---

## Examples

```
Input:  "III"
Output: 3
```

```
Input:  "MCMIV"
Output: 1904
```

---

## What Actually Matters

- Roman numerals use **subtractive notation**
- Decision depends only on **current and next character**
- No need to hard-code subtractive pairs

---

## Core Insight

> Each symbol contributes either positively or negatively depending on its right neighbor.

---

## Invariant / Mental Model

> At index `i`, compare `s[i]` with `s[i+1]`: subtract if smaller, otherwise add.

---

## Thinking Log (Evolution of the Solution)

- **Initial Thought:**  
  Roman numerals sometimes work in pairs (`IV`, `IX`, `CM`), so consume both characters together.

- **Issue:**  
  This required index jumping, stopping at `length - 1`, and a special case for the last character.

- **Correction:**  
  Pairing is not required. Subtractive logic is a **local decision**, not a grouping rule.

- **Final Realization:**  
  Instead of consuming pairs, subtract the smaller value and let the larger value be added naturally later.

---

## Algorithm (High Level)

1. Traverse the string from left to right
2. Compare current value with next value
3. Subtract if current is smaller, otherwise add
4. Sum all contributions

---

## Code (Reference Only)

```java
class Solution {
    public int romanToInt(String s) {
        Map<Character, Integer> map = new HashMap<>();
        map.put('I',1);
        map.put('V',5);
        map.put('X',10);
        map.put('L',50);
        map.put('C',100);
        map.put('D',500);
        map.put('M',1000);

        int result = 0;
        int i = 0;

        while (i < s.length() - 1) {
            char cr = s.charAt(i);
            char nx = s.charAt(i + 1);
            int cv = map.get(cr);
            int nv = map.get(nx);

            if (nv > cv) {
                result += nv - cv;
                i += 2;
            } else {
                result += cv;
                i++;
            }
        }

        if (i == s.length() - 1) {
            result += map.get(s.charAt(i));
        }

        return result;
    }
}
```

## Edge Cases to Recall

- Single character string
- Entirely additive numerals
- Subtractive numerals at multiple positions

---

## One-Line Recall

> Compare each symbol with the next and subtract when the next is larger.

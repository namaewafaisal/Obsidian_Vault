## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`
- Integer `target`

**Output:**  
- Indices of two numbers whose sum equals `target`

**Task:**  
Return indices `i, j` such that `nums[i] + nums[j] == target`.  
Each input has exactly one solution, and the same element cannot be used twice.

---

## Constraints

- `2 ≤ nums.length ≤ 10^4`
- `-10^9 ≤ nums[i] ≤ 10^9`
- Exactly one valid answer exists

---

## Examples

```
Input:  nums = [2,7,11,15], target = 9
Output: [0,1]
```

---

## What Actually Matters

- Indices must be returned, not values
- Sorting breaks index positions
- Brute force `O(n²)` is too slow

---

## Core Insight

> If we know what value we need to complete the target, we only need to check if it has appeared before.

---

## Invariant / Mental Model

> At index `i`, the map contains all values from indices `< i` mapped to their indices.

---

## Thinking Log (Evolution of the Solution)

- **Initial Thought:**  
  Check every pair using two loops.

- **Correction:**  
  This is `O(n²)` and inefficient.

- **Early Confusion:**  
  Can we sort the array first?

- **Correction:**  
  Sorting destroys original indices, which are required in the output.

- **Rejected Idea:**  
  Store all elements first, then loop again.

- **Correction:**  
  A one-pass approach is cleaner.  
  By checking before inserting, we also avoid using the same element twice.

- **Final Insight:**  
  Store `{value → index}` so the complement’s index can be retrieved instantly.

---

## Algorithm (High Level)

1. Initialize an empty hash map
2. Traverse the array
3. For each value, compute its complement
4. If complement exists in the map, return indices
5. Otherwise, store the current value and index

---

## Code (Reference Only)

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];

            if (map.containsKey(complement)) {
                return new int[]{map.get(complement), i};
            }
            map.put(nums[i], i);
        }
        return null;
    }
}
```

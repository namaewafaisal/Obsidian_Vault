### Problem (summary)

Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`. Each input has exactly one solution, and you may not use the same element twice.

---

### Example

Input: `nums = [2,7,11,15], target = 9`

Output: `[0,1]`

Explanation: Because `nums[0] + nums[1] == 9`, we return `[0, 1]`.

### Thinking Log (Evolution of the Solution)

* **Initial Thought:** Use two nested loops to check every pair .
* *Correction:* This is **O(n²)**, which is inefficient for large arrays.
* **Early Confusion:** Can I sort the array first?
* *Correction:* Sorting would take **O(n log n)** and, more importantly, would scramble the original indices required for the output.
* **Rejected Idea:** Storing all numbers in the map first, then looping again.
* *Correction:* A two-pass approach works, but a one-pass approach is cleaner. By checking the map *before* adding the current number, we automatically handle the "cannot use the same element twice" constraint.
* **Critical Insight:** The Map should store the **Value** as the Key and the **Index** as the Value, because we need to look up the complement's index by its value.

---

### Implementation Strategy

1. Initialize an empty `HashMap` to store `{Value: Index}`.
2. Iterate through the array.
3. For each element `nums[i]`, calculate its `complement = target - nums[i]`.
4. **Check:** If `complement` exists in the map, return the index stored in the map and the current index `i`.
5. **Update:** Otherwise, put `nums[i]` into the map.

---

### Code

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // Key: Number value, Value: Index of that number
        Map<Integer, Integer> map = new HashMap<>();

        for(int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            
            // Check if the required complement has already been seen
            if(map.containsKey(complement)){
                return new int[]{map.get(complement), i};
            }
            else {
                // Store the current number and its index for future lookups
                map.put(nums[i], i);
            }
        }
        return null;
    }
}

```

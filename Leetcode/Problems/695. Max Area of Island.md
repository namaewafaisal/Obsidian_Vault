# 695. Max Area of Island

## Problem (LeetCode Statement)

**Input:**  
- 2D grid `grid` of `0`s and `1`s

**Output:**  
- Integer representing the **maximum area of an island**

**Task:**  
Find the largest connected group of `1`s (4-directionally connected)

---

## Constraints

- Grid size up to large → must be O(n * m)
- In-place modification allowed

---

## Examples

```
Input: grid = [
 [0,0,1,0],
 [1,1,1,0],
 [0,1,0,0]
]

Output: 5
```

---

## What Actually Matters

- Connectivity is **4-directional only**
- Each `1` must be counted **once**
- Must avoid revisiting → marking visited is essential
- Brute force (recounting islands) leads to repeated work

---

## Core Insight

> Treat each `1` as part of a connected component and compute its size using DFS

---

## Invariant / Mental Model

> Every cell is visited **at most once** by marking it `0` immediately

---

## Thinking Log (Evolution of the Solution)

- Initial Thought:  
  Traverse grid and count islands manually

- Issue:  
  Without marking visited → infinite loops / repeated counting

- Correction:  
  Use DFS to explore full island before moving on

- Final Realization:  
  Each DFS traversal = one island → count size and track max

---

## Algorithm (High Level)

1. Iterate through each cell
2. If cell == 1:
   - Start DFS using stack
   - Mark visited (`grid[i][j] = 0`)
   - Count connected cells
3. Update max area
4. Continue scanning grid

---

## Code (Reference Only)

```java
class Solution {
    public int maxAreaOfIsland(int[][] grid) {
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
        int max = 0;
        Stack<int[]> stack = new Stack<>();

        for(int i = 0; i < grid.length; i++){
            for(int j = 0; j < grid[i].length; j++){

                if(grid[i][j] == 1){

                    stack.push(new int[]{i,j});
                    grid[i][j] = 0;

                    int count = 0;

                    while(!stack.isEmpty()){
                        count++;

                        int[] curr = stack.pop();
                        int r = curr[0];
                        int c = curr[1];

                        for(int[] dir : dirs){
                            int nr = r + dir[0];
                            int nc = c + dir[1];

                            if(0 <= nr && nr < grid.length &&
                               0 <= nc && nc < grid[0].length &&
                               grid[nr][nc] == 1){

                                grid[nr][nc] = 0;
                                stack.push(new int[]{nr,nc});
                            }
                        }
                    }

                    max = Math.max(count, max);
                }
            }
        }
        return max;
    }
}
```

---

## Edge Cases to Recall

- Grid with all `0`s → answer = 0
- Single cell island → answer = 1
- Entire grid is `1`s → answer = n * m

---

## One-Line Recall

> Traverse grid, run DFS for each `1`, count component size, track max

## LC 424. Longest Repeating Character Replacement

### Problem (summary)

You are given a string `s` and an integer `k`. You can choose any character of the string and change it to any other uppercase English character. You can perform this operation at most `k` times. Return the length of the longest substring containing the same letter you can get after performing the above operations.

---

### Example

Input: `s = "AABABBA"`, `k = 1`

Output: `4`

Explanation: Replace one 'A' with 'B' in the substring "ABBA" to get "BBBB".

---

### Pattern Classification

* Sliding Window (Variable Size)
* Frequency Map (Hash Table or Array)
* Optimization with "Stale" Maximums

---

### Key Invariant

* A window is **valid** if: `(Window Size) - (Frequency of Most Frequent Character) <= k`.
* This means the number of characters we need to "replace" to make the whole window uniform is within our budget `k`.

---

### Thinking Log (Evolution of the Solution)

* **Initial Thought:** Try every possible substring and check if it can be converted.
* *Correction:* Too slow. We need a sliding window since we are looking for a contiguous range.
* **Early Confusion:** Do I need to re-scan the frequency map to find the new `maxFreq` every time I move the `left` pointer?
* *Correction:* No. This is a common point of confusion. We only care when `maxFreq` increases because only a larger `maxFreq` can lead to a longer valid window.
* **Key Insight:** The `maxFreq` variable is allowed to stay "stale" (outdated) when the window shrinks. A smaller `maxFreq` would only make the window *less* valid, so it doesn't help us find a new maximum length.

---

### Implementation Strategy

1. Maintain a frequency map of characters in the current window.
2. Maintain `maxFreq`, which is the maximum frequency of *any* character encountered in *any* window so far.
3. **Expand:** Move `right` pointer, update frequency, and update `maxFreq`.
4. **Shrink:** If `(right - left + 1) - maxFreq > k`, the window is invalid. Move `left` pointer and decrement the frequency of the character leaving the window.
5. **Update:** `len = max(len, right - left + 1)`.

---

### Code

```java
import java.util.Map;
import java.util.HashMap;

class Solution {
    public int characterReplacement(String s, int k) {
        int right = 0, left = 0;
        int len = 0;
        int size = s.length();
        Map<Character, Integer> map = new HashMap<>();

        int maxFreq = 0;
        while(right < size) {
            char r = s.charAt(right);
            map.put(r, map.getOrDefault(r, 0) + 1);
            
            // Only update maxFreq when it increases
            maxFreq = Math.max(map.get(r), maxFreq);

            // If replacements needed > k, shrink window
            while(right + 1 - left > maxFreq + k) {
                char l = s.charAt(left++);
                map.put(l, map.get(l) - 1);
                // Note: maxFreq is NOT updated here even if map.get(l) was the maxFreq
            }
            
            len = Math.max(len, right + 1 - left);
            right++;
        }
        return len;
    }
}

```

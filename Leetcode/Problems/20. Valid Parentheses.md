# 20. Valid Parentheses

## Problem (LeetCode Statement)

**Input:**  
- String `s` containing only `()[]{}`

**Output:**  
- `true` if the string is valid, otherwise `false`

**Task:**  
Check whether brackets are correctly opened and closed in proper order.

---

## Constraints

- `1 ≤ s.length ≤ 10^4`
- Only bracket characters appear

---

## Examples

```
Input:  "()[]{}"
Output: true
```

```
Input:  "(]"
Output: false
```

---

## What Actually Matters

- Order matters
- Types must match
- Most recent opening must close first

---

## Core Insight

> Nested structures follow LIFO behavior.

---

## Invariant / Mental Model

> The top of the stack always holds the most recent unmatched opening bracket.

---

## Thinking Log (Evolution of the Solution)

### Initial Understanding (your words)

> “I know that stack is used for this.”

Correct, because:

- The problem is about nesting
- Nesting maps directly to stack behavior

---

### Core Logic (your words)

> “Whenever it’s an opening bracket I push it.  
> Whenever it’s a closing bracket then I check if the top of the stack is the matching opening bracket and if so then pop.”

This fully captures the algorithm.

---

### Failure Conditions Identified (your words)

> “When the string ends and stack not empty or closing and the opening in the top don’t match then it’s false else true.”

Correct failure cases:

- Closing bracket with empty stack
- Mismatched type
- Stack not empty at end

---

### Clarification (Character vs char)

- `stack.peek()` returns `Character`
- Compared with primitive `char`
- Java safely auto-unboxes
- No reference comparison issue

---

## Algorithm (High Level)

1. Traverse characters
2. Push opening brackets
3. On closing:
   - Check stack not empty
   - Check top matches
   - Pop
4. At end, stack must be empty

---

## Code (Reference Only)

```java
class Solution {
    public boolean isValid(String s) {
        Stack<Character> stack = new Stack<>();

        for (char c : s.toCharArray()) {
            if (c == '{' || c == '(' || c == '[') {
                stack.push(c);
            }
            else if (!stack.isEmpty() &&
                    ((c == '}' && stack.peek() == '{') ||
                     (c == ')' && stack.peek() == '(') ||
                     (c == ']' && stack.peek() == '['))) {
                stack.pop();
            }
            else {
                return false;
            }
        }
        return stack.isEmpty();
    }
}
```

---

## Edge Cases to Recall

- Closing bracket first
- Odd-length string
- Remaining openings at end

---

## One-Line Recall

> Use a stack: push openings, pop only if the latest opening matches the closing bracket.

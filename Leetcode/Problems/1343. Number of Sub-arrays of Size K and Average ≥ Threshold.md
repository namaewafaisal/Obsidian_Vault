### Problem (summary)

Given an array of integers `arr` and two integers `k` and `threshold`, return the number of sub-arrays of size `k` and average greater than or equal to `threshold`.

---

### Example

Input: `arr = [2,2,2,2,5,5,5,8], k = 3, threshold = 4`

Output: `3`

Explanation: Sub-arrays [2,5,5], [5,5,5] and [5,5,8] have averages 4, 5 and 6 respectively. All other sub-arrays of size 3 have averages less than 4.

---

### Pattern Classification

* Sliding Window (Fixed Size)
* Predicate Counting
* Algebraic Optimization (Thresholding)

---

### Key Invariant

* The window must maintain a length of exactly `k`.
* The condition `sum / k >= threshold` is mathematically equivalent to `sum >= k * threshold`. Using the latter avoids floating-point division errors and is slightly more performant.

---

### Thinking Log (Evolution of the Solution)

* **Initial Thought:** Calculate the average of every subarray of length `k` using a nested loop.
* *Correction:* Recomputing the sum for every window is . A sliding window reduces this to .
* **Early Confusion:** Should I use `double` for the average comparison?
* *Correction:* While `(double)currSum / k >= threshold` works, it introduces potential precision issues. Comparing `currSum >= threshold * k` is cleaner and uses integer math.
* **Key Insight:** The "Fixed Window" template is consistent—expand until size is `k`, process/count, then immediately shrink the tail to prepare for the next expansion.

---

### Implementation Strategy

1. Initialize `currSum`, `left`, `right`, and `count`.
2. **Expand:** Add `arr[right]` to `currSum`.
3. **Window Hit:** Once `right - left + 1 == k`:
* Check if `currSum >= threshold * k`.
* If true, increment `count`.
* **Slide:** Subtract `arr[left]` from `currSum` and move `left` forward.


4. Return the final `count`.

---

### Code

```java
class Solution {
    public int numOfSubarrays(int[] arr, int k, int threshold) {
        int left = 0, right = 0;
        int currSum = 0;
        int count = 0;
        
        // Target sum to avoid division
        int targetSum = k * threshold;

        while (right < arr.length) {
            currSum += arr[right];

            // When window reaches size k
            if (right - left + 1 == k) {
                // Optimization: Use multiplication instead of division
                if (currSum >= targetSum) {
                    count++;
                }
                
                // Prepare for next window by removing the leftmost element
                currSum -= arr[left++];
            }
            right++;
        }
        return count;
    }
}

```

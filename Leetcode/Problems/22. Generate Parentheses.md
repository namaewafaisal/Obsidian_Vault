# 22. Generate Parentheses

## Problem (LeetCode Statement)

**Input:**  
- Integer `n`

**Output:**  
- All combinations of well-formed parentheses using `n` pairs

**Task:**  
Generate all valid parentheses strings of length `2n`.

---

## Constraints

- `1 ≤ n ≤ 8`
- Output order does not matter

---

## Examples

```
Input:  n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"]
```

---

## What Actually Matters

- Parentheses must be balanced
- Invalid prefixes must never be generated
- This is a **state problem**, not a string problem

---

## Core Insight

> Valid parentheses are defined by constraints on counts, not by placement.

---

## Invariant / Mental Model

```
0 ≤ close ≤ open ≤ n
```

Any state violating this is invalid and must be pruned.

---

## Thinking Log (Evolution of the Solution)

### Initial Thought (your words)

> I can generate all combinations of '(' and ')' of length `2n` and then check validity.

---

### Why This Thinking Breaks

- Total combinations = `2^(2n)`
- Most strings are invalid
- Validation happens **after** generation, wasting work

---

### Corrected Mental Model

> Each recursive call represents a **partial valid prefix**.

- Only valid prefixes are extended
- Invalid states are never generated

This is why backtracking is efficient here.

---

## Algorithm (High Level)

1. Start with empty string
2. Track `open` and `close` counts
3. Add `'('` only if `open < n`
4. Add `')'` only if `close < open`
5. Add to result when both reach `n`

---

## Code (Reference Only)

```java
class Solution {
    List<String> result;

    public List<String> generateParenthesis(int n) {
        result = new ArrayList<>();
        backtrack("", 0, 0, n);
        return result;
    }

    private void backtrack(String cur, int open, int close, int n) {
        if (open == n && close == n) {
            result.add(cur);
            return;
        }

        if (open < n) {
            backtrack(cur + "(", open + 1, close, n);
        }

        if (close < open) {
            backtrack(cur + ")", open, close + 1, n);
        }
    }
}
```

---

## Edge Cases to Recall

- `n = 1`
- Deep recursion
- Forgetting close ≤ open constraint

---

## One-Line Recall

> Generate parentheses by recursion while enforcing `close ≤ open ≤ n`.

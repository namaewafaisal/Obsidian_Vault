# LC 225. Implement Stack using Queues

## Problem (LeetCode Statement)

**Input:**  
Operations on a stack implemented using queues:

- `push(x)`
- `pop()`
- `top()`
- `empty()`

**Output:**  
Each operation must behave exactly like a stack.

**Task:**  
Implement a **LIFO stack** using only **queue operations** (`offer`, `poll`, `peek`, `isEmpty`).

---

## Constraints

- Only standard queue operations allowed
- At most `100` operations
- `1 ≤ x ≤ 9`

---

## Examples

```
push(1)
push(2)
top() -> 2
pop() -> 2
empty() -> false
```

---

## What Actually Matters

- Queue is **FIFO**
- Stack is **LIFO**
- We must manipulate queue order to simulate stack behavior

---

## Core Insight

> After every push, the newest element must move to the **front of the active queue**.

This ensures that `poll()` behaves like `pop()`.

---

## Invariant / Mental Model

> `st2` always stores elements in **stack order**, meaning the front of the queue is the stack top.

---

## Thinking Log (Evolution of the Solution)

### Initial Thought (your words)

> The queue I push must be empty so the pushed value becomes the top of the stack (the side where we poll).

This insight identifies the key constraint:  
the new element must become the **first element returned by poll()**.

---

### Your Strategy (your words)

> Then the arranged values are again pushed from another queue to this single element queue.

Meaning:

1. Insert the new element
2. Move all old elements **behind it**
3. Swap queues

This effectively **rotates the queue order**.

---

### Why This Works

Suppose the stack is:

```
top -> 3 2 1
```

The queue internally must look like:

```
[3,2,1]
```

When pushing `4`:

```
push 4 → [4]
move old elements → [4,3,2,1]
```

Now `poll()` returns `4`, which matches stack behavior.

---

## Algorithm (High Level)

1. Push element into empty queue
2. Move all previous elements behind it
3. Swap the queues
4. `pop()` = `poll()` from active queue
5. `top()` = `peek()` from active queue

---

## Code (Reference Only)

```java
class MyStack {
    Queue<Integer> st1;
    Queue<Integer> st2;

    public MyStack() {
        st1 = new ArrayDeque<>();
        st2 = new ArrayDeque<>();
    }

    public void push(int x) {
        st1.offer(x);

        while(!st2.isEmpty()){
            st1.offer(st2.poll());
        }

        Queue temp = st2;
        st2 = st1;
        st1 = temp;
    }
    
    public int pop() {
        return st2.poll();
    }
    
    public int top() {
        return st2.peek();
    }
    
    public boolean empty() {
        return st2.isEmpty();
    }
}
```

## One-Line Recall

> Simulate stack behavior by rotating the queue so the newest element always becomes the front.

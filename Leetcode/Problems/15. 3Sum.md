# 15. 3Sum
## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`

**Output:**  
- List of unique triplets `[a, b, c]` such that `a + b + c = 0`

**Task:**  
Find all unique triplets whose sum is zero. Triplets must not be duplicated.

---

## Constraints

- `3 ≤ nums.length ≤ 3000`
- `-10^5 ≤ nums[i] ≤ 10^5`
- Result must not contain duplicate triplets

---

## Examples

```
Input:  [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
```

---

## What Actually Matters

- Order of elements inside triplets does not matter
- Sorting enables monotonic pointer movement
- Duplicate handling is required at **multiple levels**

---

## Core Insight

> Fix one element and reduce the problem to 2Sum on the suffix.

---

## Invariant / Mental Model

> After sorting, moving pointers inward monotonically explores all valid sums without missing any solution.

---

## Thinking Log (Evolution of the Solution)

- **Initial Insight:**  
  Indices are not required, so sorting is allowed.

- **Key Reasoning:**  
  Fixing one element reduces the problem to a 2Sum search on the remaining suffix.

- **Issue Discovered:**  
  Duplicate triplets appear if identical values are reused.

- **Correction:**  
  Skip duplicates at the anchor index and after finding a valid triplet.

- **Final Realization:**  
  Deduplication is part of the invariant, not a post-processing step.

---

## Algorithm (High Level)

1. Sort the array
2. Iterate an anchor index `i`
3. Apply two pointers on the suffix
4. Adjust pointers based on sum
5. Skip duplicates at all levels

---

## Code (Reference Only)

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {

        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();

        for(int i = 0; i < nums.length - 2; i++) {
            if(i > 0 && nums[i] == nums[i-1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;

            while(left < right) {
                int sum = nums[i] + nums[left] + nums[right];

                if(sum > 0) {
                    right--;
                }
                else if(sum < 0) {
                    left++;
                }
                else {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));

                    int leftVal = nums[left];
                    while(left < right && nums[left] == leftVal) {
                        left++;
                    }

                    int rightVal = nums[right];
                    while(left < right && nums[right] == rightVal) {
                        right--;
                    }
                }
            }
        }
        return result;
    }
}
```

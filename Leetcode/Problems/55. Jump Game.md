# 55. Jump Game

## Problem (LeetCode Statement)

**Input:**
- `int[] nums` — array where `nums[i]` is the maximum jump length from index `i`

**Output:**
- `true` if you can reach the last index, `false` otherwise

**Task:**
Starting at index 0, determine if you can reach the last index given each element's maximum jump length.

---

## Constraints

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^5`

---

## Examples
```
Input:  nums = [2, 3, 1, 1, 4]
Output: true
```
```
Input:  nums = [3, 2, 1, 0, 4]
Output: false  (always land on index 3 which has 0)
```

---

## What Actually Matters

- You don't need to track which path you took — only how far you can reach
- BFS and recursion both work but are overkill — this is purely greedy
- A position is unreachable if every index before it couldn't jump far enough to get there
- You never need to look back — one left-to-right pass is enough

---

## Core Insight

> Track the maximum reachable index as you walk forward. If you ever reach an index beyond your current max reach, you're stranded — return false. Otherwise finish the loop and return true.

---

## Invariant / Mental Model

> `maxReach` always holds the farthest index reachable from any position seen so far. If `i > maxReach` at any point, no previous position could reach `i`.

---

## Thinking Log (Evolution of the Solution)

- **Initial Thought:** At each index try all reachable positions — felt like recursion or BFS with a queue
- **Issue:** BFS and recursion both work but are O(n²) or require extra space — overkill
- **Realization:** You don't need to simulate movement. Just track the farthest you can reach at each step
- **Key Observation:** Every position is reachable as long as no previous value creates a wall — a wall happens when `maxReach` gets stuck and current index surpasses it
- **Correction:** Condition isn't "maxReach equals current index" — it's "current index exceeds maxReach", meaning you're stranded
- **Final Realization:** One pass, one variable, update `maxReach = max(maxReach, i + nums[i])` at each step, bail early if `i > maxReach`

---

## Algorithm (High Level)

1. Track `maxReach = 0`
2. For each index `i`, if `i > maxReach` return false — position is unreachable
3. Update `maxReach = max(maxReach, i + nums[i])`
4. If loop completes, return true

---

## Code (Reference Only)
```java
class Solution {
    public boolean canJump(int[] nums) {
        int maxPos = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > maxPos) {
                return false;
            }
            maxPos = Math.max(maxPos, i + nums[i]);
        }
        return true;
    }
}
```

---

## Edge Cases to Recall

- Single element array → loop runs once, never fails, returns true
- First element is 0 and length > 1 → `maxReach` stays 0, index 1 > 0 → return false immediately
- Large jumps early → `maxReach` shoots past the end, loop finishes naturally

---

## One-Line Recall

> Walk forward tracking max reachable index — if current index ever exceeds it, return false, otherwise return true.

### Problem (summary)

Given an array `nums` of size , return the majority element. The majority element is the element that appears more than  times. You may assume that the majority element **always exists** in the array.

---

### Key Observation

* If an element appears more than  times, all other elements combined appear less than  times.
* **The "Cancellation" Principle:** If we pair up the majority element with any other different element and "cancel" them out, the majority element will be the only one left standing at the end.

---

### Thinking Log (Evolution of the Solution)

* **Initial Thought:** Use a `HashMap` to store frequencies.
* *Critique:* This works in  time but uses  space. It ignores the specific "majority" guarantee.


* **Constraint Realization:** Since the majority element is guaranteed to exist and occupies more than half the array, we don't need exact frequency counts.
* **Mental Model Shift:** Instead of counting, think in terms of **dominance**.
* Same elements reinforce a candidate.
* Different elements challenge and "cancel" a candidate.


* **Critical Insight:** If the current `count` drops to , it means all previous elements have neutralized each other. It is safe to pick the next element as a new candidate.
* **Final Conclusion:** Because the majority exists (), it physically cannot be eliminated by the remaining elements ().

---

### Implementation Strategy

1. Initialize `candidate` and `count = 0`.
2. Iterate through the array:
* If `count == 0`, set the current element as the new `candidate`.
* If `current == candidate`, increment `count`.
* If `current != candidate`, decrement `count`.


3. Return the `candidate`.

---

### Code (Java)

```java
class Solution {
    public int majorityElement(int[] nums) {
        int element = 0;
        int count = 0;

        for (int i = 0; i < nums.length; i++) {
            // If current count is 0, we pick a new potential candidate
            if (count == 0) {
                element = nums[i];
                count++;
            } 
            // If we see the same element, dominance increases
            else if (nums[i] == element) {
                count++;
            } 
            // If we see a different element, they cancel each other out
            else {
                count--;
            }
        }
        
        return element;
    }
}

```

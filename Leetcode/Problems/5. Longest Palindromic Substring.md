# 5. Longest Palindromic Substring

## Problem (LeetCode Statement)

**Input:**  
- String `s`

**Output:**  
- The **longest palindromic substring**

**Task:**  
Find the longest substring that reads the same forward and backward

---

## Constraints

- Brute force O(n³) too slow
- Need O(n²) or better

---

## Examples

```
Input: s = "babad"
Output: "bab" (or "aba")
```

```
Input: s = "cbbd"
Output: "bb"
```

---

## What Actually Matters

- Palindromes expand symmetrically
- Every palindrome has a **center**
- Two types:
  - Odd length → center at a character
  - Even length → center between characters
- Brute force checking all substrings is wasteful

---

## Core Insight

> Instead of generating substrings, expand from each possible center

---

## Invariant / Mental Model

> While expanding, `s[left] == s[right]` must always hold

---

## Thinking Log (Evolution of the Solution)

- Initial Thought:  
  Generate all substrings and check palindrome

- Issue:  
  Too slow → O(n³)

- Correction:  
  A palindrome grows outward → check from center

- Key Realization:  
  Need to handle both **odd and even centers**

- Final Understanding:  
  Expand from each index and track max length

---

## Algorithm (High Level)

1. Iterate each index `i`
2. Expand:
   - Odd center → (i, i)
   - Even center → (i, i+1)
3. Get max length from both
4. Update starting index using:
   ```
   start = i - (len - 1) / 2
   ```
5. Return substring

---

## Code (Reference Only)

```java
class Solution {
    public String longestPalindrome(String s) {
        int start = 0;
        int maxLen = 0;

        for(int i = 0; i < s.length(); i++){
            int odd = expand(i, i, s);
            int even = expand(i, i+1, s);

            int len = Math.max(odd, even);

            if(len > maxLen){
                maxLen = len;
                start = i - (len - 1) / 2; 
            }
        }

        return s.substring(start, start + maxLen);
    }

    public int expand(int left, int right, String s){
        while(left >= 0 && right < s.length() &&
              s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        return right - left - 1;
    }
}
```

---

## Edge Cases to Recall

- Single character string → itself
- All same characters → entire string
- No repeating characters → length = 1
- Even-length palindrome (must check separately)

---

## One-Line Recall

> Try every center and expand outward while characters match

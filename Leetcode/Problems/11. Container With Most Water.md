### Problem (summary)

You are given an integer array `height` of length . There are  vertical lines drawn such that the two endpoints of the  line are  and . Find two lines that, together with the x-axis, form a container, such that the container contains the most water. Return the maximum amount of water a container can store.

---

### Key Invariant

* **The Bottleneck Rule:** The volume of water is constrained by the **shorter** of the two lines: .
* **The Greedy Choice:** Since moving any pointer inward reduces the width, the only way to potentially increase the area is to find a taller line to replace the current **shorter** line. Moving the taller line is guaranteed to never increase the area.

---

### Thinking Log (Evolution of the Solution)

* **Initial Observation:** The area depends on distance (width) and the shorter of two heights. Brute force  is the starting point but won't scale.
* **Key Insight:** Start with the **maximum possible width** (pointers at index  and ). This gives us a baseline.
* **Bottleneck Realization:** Because the shorter line limits the area, keeping the shorter line while decreasing width (moving pointers inward) will **always** result in a smaller area.
* **Invariant Established:** Moving the taller line cannot increase area because the width is shrinking and the height limit (the shorter line) hasn't changed. Therefore, moving the shorter pointer is the **only rational choice**.
* **Area Tracking:** Compute the area at each step, update the global maximum, and move the bottleneck pointer until the pointers meet.
* **Termination Reasoning:** Pointers move monotonically inward. Once they meet, every potential "maximal" container has been accounted for or logically dismissed via the greedy invariant.

---

### Implementation Strategy

1. Initialize `left = 0`, `right = height.length - 1`, and `maxArea = 0`.
2. While `left < right`:
* Calculate current area: `Math.min(height[left], height[right]) * (right - left)`.
* Update `maxArea` if the current area is larger.
* Compare `height[left]` and `height[right]`.
* Increment `left` if it is the shorter line; otherwise, decrement `right`.


3. Return `maxArea`.

---

### Code (Java)

```java
class Solution {
    public int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxArea = 0;

        while (left < right) {
            // Area is limited by the shorter height and the current width
            int currentArea = Math.min(height[left], height[right]) * (right - left);
            maxArea = Math.max(maxArea, currentArea);

            // Move the pointer pointing to the shorter line
            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }
        return maxArea;
    }
}

```

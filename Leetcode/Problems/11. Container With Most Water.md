# 11. Container With Most Water

## Problem (LeetCode Statement)

**Input:**  
- Integer array `height`

**Output:**  
- Maximum amount of water the container can store

**Task:**  
Choose two vertical lines that together with the x-axis form a container holding the maximum water.

---

## Constraints

- `2 ≤ height.length ≤ 10^5`
- `0 ≤ height[i] ≤ 10^4`
- Must run in linear time

---

## Examples

```
Input:  [1,8,6,2,5,4,8,3,7]
Output: 49
```

---

## What Actually Matters

- Area is limited by the **shorter** line
- Width decreases monotonically
- Brute force `O(n²)` is too slow

---

## Core Insight

> Since width always decreases, the only way to increase area is to move the pointer at the shorter height.

---

## Invariant / Mental Model

> At every step, the current area is limited by the shorter line; moving the taller line cannot improve the result.

---

## Thinking Log (Evolution of the Solution)

- **Initial Observation:**  
  Area depends on width and minimum of the two heights.

- **Issue:**  
  Trying all pairs is `O(n²)`.

- **Key Insight:**  
  Start with the maximum width by placing pointers at both ends.

- **Bottleneck Realization:**  
  The shorter line limits the area, so keeping it while reducing width can never help.

- **Final Reasoning:**  
  Moving the taller pointer is pointless; only replacing the bottleneck can possibly increase area.

---

## Algorithm (High Level)

1. Place pointers at both ends
2. Compute area and update maximum
3. Move the pointer at the shorter height inward
4. Stop when pointers meet

---

## Code (Reference Only)

```java
class Solution {
    public int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxArea = 0;

        while (left < right) {
            int area = Math.min(height[left], height[right]) * (right - left);
            maxArea = Math.max(maxArea, area);

            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }
        return maxArea;
    }
}
```

---

## Edge Cases to Recall

- Strictly increasing heights
- Strictly decreasing heights
- Multiple equal-height lines

---

## One-Line Recall

> Start wide and move the pointer at the shorter line because it is the limiting factor.

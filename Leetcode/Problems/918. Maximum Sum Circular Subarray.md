## LC 918. Maximum Sum Circular Subarray

### Problem (Statement)

Given a **circular integer array** `nums`, return the **maximum possible sum of a non-empty subarray**.

A subarray:
- must be contiguous
- may wrap from the end of the array to the beginning
- cannot reuse elements

---

### Key Insight

> **Any circular subarray is equivalent to taking the whole array and removing one contiguous subarray from the middle.**

So the problem reduces to choosing:
- either a **normal maximum subarray**
- or a **circular maximum**, computed as  
  `totalSum − minimumSubarraySum`

---

### Two Competing Candidates

1. **Normal max subarray**  
   → Standard Kadane’s algorithm (LC 53)

2. **Circular max subarray**  
   → `totalSum − minSubarraySum`

Final answer:
```
max(normalMax, circularMax)
```

---

### Critical Edge Case ⚠️

If **all numbers are negative**:
- minimum subarray = entire array
- `totalSum − minSubarray = 0` (invalid, empty subarray)

So in this case:
> **Return the normal Kadane result (largest element).**

---

### Correct Mental Model

- Use Kadane once to find the **maximum subarray**
- Use Kadane again (inverted logic) to find the **minimum subarray**
- Track `totalSum`
- If `normalMax > 0`, circular case is valid
- Otherwise, ignore circular logic

---

### Final Code (Java)

```java
class Solution {
    public int maxSubarraySumCircular(int[] nums) {
        int curMin = 0;
        int curMax = 0;

        int minSubarray = Integer.MAX_VALUE;   // renamed for clarity
        int normalMax = Integer.MIN_VALUE;
        int totalSum = 0;

        for (int i = 0; i < nums.length; i++) {
            totalSum += nums[i];

            // Minimum subarray Kadane
            curMin = Math.min(nums[i], curMin + nums[i]);
            minSubarray = Math.min(minSubarray, curMin);

            // Maximum subarray Kadane
            curMax = Math.max(nums[i], curMax + nums[i]);
            normalMax = Math.max(normalMax, curMax);
        }

        // If all values are negative, circular case is invalid
        if (normalMax > 0) {
            return Math.max(normalMax, totalSum - minSubarray);
        }

        return normalMax;
    }
}
```

---

### Why This Works

- Normal Kadane handles non-wrapping subarrays
- Circular case removes the worst contiguous block
- Edge case prevents selecting an empty subarray
- Time complexity: `O(n)`
- Space complexity: `O(1)`

---

### Common Mistakes

- Trying to simulate wrapping manually
- Duplicating the array
- Forgetting the all-negative edge case
- Adding max and min subarrays instead of subtracting

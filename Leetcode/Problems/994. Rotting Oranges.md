## LC 994. Rotting Oranges

### Problem (Statement)

Given a grid where:
- `0` = empty cell
- `1` = fresh orange
- `2` = rotten orange  

Every minute:
- A rotten orange turns all **adjacent (up/down/left/right)** fresh oranges rotten.

Return the **minimum number of minutes** required to rot all oranges,  
or `-1` if it is impossible.

---

### Key Invariant

> **This is multi-source BFS where each BFS level represents exactly one minute.**

Time increases **per layer**, not per node.

---

### Mental Model

- Grid = graph
- Cell = node
- Adjacency = 4 directions
- All initial rotten oranges are **starting points**
- BFS simulates the spread of rot like a wave

---

### Why `queue.size()` Controls Time

At the start of each minute:
- All oranges currently in the queue rot neighbors **simultaneously**
- Newly rotten oranges are processed in the **next minute**

So:
- `queue.size()` = number of oranges acting in the *current minute*
- Processing exactly that many keeps time accurate

---

### Why `fresh > 0` Is Required

- Time should advance **only if work remains**
- If no fresh oranges are left:
  - stop immediately
  - avoid adding an extra minute

---

### Stopping Conditions

- If BFS finishes and `fresh > 0` → return `-1`
- If all fresh oranges rot → return minutes elapsed

---

### Final Correct Code (Java)

```java
class Solution {
    public int orangesRotting(int[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;

        Queue<int[]> queue = new LinkedList<>();
        int fresh = 0;

        // Initialize queue with all rotten oranges
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (grid[i][j] == 2) {
                    queue.offer(new int[]{i, j});
                } else if (grid[i][j] == 1) {
                    fresh++;
                }
            }
        }

        int minutes = 0;
        int[][] dirs = {{1,0}, {-1,0}, {0,1}, {0,-1}};

        // Multi-source BFS
        while (!queue.isEmpty() && fresh > 0) {
            int size = queue.size();
            minutes++;

            for (int i = 0; i < size; i++) {
                int[] cur = queue.poll();
                int r = cur[0];
                int c = cur[1];

                for (int[] d : dirs) {
                    int nr = r + d[0];
                    int nc = c + d[1];

                    if (nr >= 0 && nr < rows &&
                        nc >= 0 && nc < cols &&
                        grid[nr][nc] == 1) {

                        grid[nr][nc] = 2;
                        fresh--;
                        queue.offer(new int[]{nr, nc});
                    }
                }
            }
        }

        return fresh == 0 ? minutes : -1;
    }
}
```

### Common Mistakes

- Incrementing time per node instead of per level
- Forgetting multi-source initialization
- Missing the `fresh > 0` condition
- Using DFS instead of BFS

---

### One-Sentence Recall

> LC 994 works because multi-source BFS spreads rot level by level, and each level corresponds to one minute.

# 21. Merge Two Sorted Lists

## Problem (LeetCode Statement)

**Input:**  
- Heads of two sorted singly linked lists `list1` and `list2`

**Output:**  
- Head of one merged sorted linked list

**Task:**  
Merge two sorted linked lists by **reusing existing nodes**, without creating new ones.

---

## Constraints

- Lists may be empty
- Nodes are already sorted
- Must run in linear time

---

## Examples

```
Input:
list1 = [1,2,4]
list2 = [1,3,4]

Output:
[1,1,2,3,4,4]
```

---

## What Actually Matters

- Nodes must be **linked**, not reassigned
- No new nodes should be created
- Order must remain sorted

---

## Core Insight

> Linked lists grow only through `next` pointers, not variable reassignment.

---

## Invariant / Mental Model

> `tail` always points to the **last node of the merged list**, and the merged list grows only via `tail.next`.

---

## Thinking Log (Evolution of the Solution)

### Initial Thought (your words)

> “I don’t create a new list. I just rearrange the links.”

This was the **correct high-level approach**.

---

### Confusion About `tail` (your words)

> “What is tail here? If I don’t create a node, is tail the lesser value?”

Clarification:

- `tail` is **not a new node**
- It is a pointer to the **last node already placed in the merged list**
- The merged list consists entirely of existing nodes

---

### Major Mistake #1 — Reassigning Instead of Linking

Buggy idea:

```java
tail = list1;
```

Why it fails:

- This only moves the pointer
- It does **not** attach the node to the merged list
- The list structure remains unchanged

Correction:

```java
tail.next = list1;
tail = tail.next;
```

---

### Major Mistake #2 — Incorrect Remainder Handling

Buggy logic:

```java
while (list1 != null) {
    tail = list1;
    list1 = list1.next;
}
```

Why it fails:

- No `.next` assignment
- Nodes are never connected

Correction:

- Remaining nodes are already sorted
- Attach them in **one operation**

```java
tail.next = list1; // or list2
```

---

### Final Realization (your words)

> “I actually had the correct solution structure but was far away.”

Correction:

- You were **not far away**
- The issue was **pointer discipline**, not logic
- The algorithm was already correct conceptually

---

## Algorithm (High Level)

1. Handle null list cases
2. Choose smaller head as merged head
3. Maintain `tail` pointer
4. Attach smaller node at each step using `tail.next`
5. Attach remaining list at the end

---

## Code (Reference Only)

```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        if (list1 == null) return list2;
        if (list2 == null) return list1;

        ListNode head;
        if (list1.val <= list2.val) {
            head = list1;
            list1 = list1.next;
        } else {
            head = list2;
            list2 = list2.next;
        }

        ListNode tail = head;

        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val) {
                tail.next = list1;
                list1 = list1.next;
            } else {
                tail.next = list2;
                list2 = list2.next;
            }
            tail = tail.next;
        }

        tail.next = (list1 != null) ? list1 : list2;
        return head;
    }
}
```

---

## Edge Cases to Recall

- One list empty
- Both lists empty
- Lists of different lengths

---

## One-Line Recall

> A merged linked list grows only by assigning `tail.next`, never by reassigning `tail`.

## LC 54. Spiral Matrix

### Problem (Statement)

Given an `m x n` matrix, return all elements of the matrix in **spiral order**:
right → down → left → up, shrinking inward after each direction.

---

### Input / Output

**Input**
```
[
  [1,  2,  3],
  [4,  5,  6],
  [7,  8,  9]
]
```

**Output**
```
[1, 2, 3, 6, 9, 8, 7, 4, 5]
```

---

### Key Invariant

> **Spiral traversal is controlled by shrinking boundaries, not by counters or index resets.**

Boundaries:
- `top`, `bottom`, `left`, `right` define the current unvisited rectangle.

Traversal continues **only while**:
```
top <= bottom && left <= right
```

---

### Thinking Log (Actual Evolution, Mistakes Included)

#### Initial Idea (Correct Direction, Wrong Control)

> *“Outer while loop with 4 inner loops, one for each direction.”*

This part was correct.

---

#### ❌ Mistake #1 — Using element count (`i < m*n`) to control the loop

> *“I’ll stop when I’ve added all elements.”*

Why this failed:
- Direction loops were executed **unconditionally**
- Even if a loop didn’t run, the boundary update **still happened**
- This caused skipped elements or invalid boundaries

**Correction:**  
Control the traversal with **boundary validity**, not element count.

---

#### ❌ Mistake #2 — Comparing against `rows` / `cols`

> *“Use `row < rows`, `col < cols`.”*

Why this failed:
- `rows` and `cols` are constants
- Spiral traversal needs a **shrinking region**
- This caused the outer layer to be traversed repeatedly

**Correction:**  
Use **moving boundaries** (`top`, `bottom`, `left`, `right`).

---

#### ❌ Mistake #3 — Shared `row` / `col` across loops

> *“Reset `row` and `col` before each direction.”*

Why this failed:
- Shared state leaked between loops
- Skipped loops left stale values
- Boundary updates acted on incorrect assumptions

**Correction:**  
Make `row` / `col` **local to each loop**.
Only boundaries persist.

---

#### ❌ Mistake #4 — Updating boundaries even when loops didn’t run

> *“Even if the loop doesn’t execute, I still do `right--`, `bottom--`…”*

Why this failed:
- Boundaries shrank without traversal
- Led to incorrect state

**Correction:**  
Guard left/up traversals with boundary checks:
```
if (top <= bottom)
if (left <= right)
```

---

#### Final Realization

> *“Boundaries carry state. Loop variables are disposable.”*

Once this clicked, the solution became mechanical.

---

### Correct Mental Model

At any moment:
- **One index moves**
- **The other index is fixed by a boundary**

Directions:
- Right  → fixed `top`, move `col`
- Down   → fixed `right`, move `row`
- Left   → fixed `bottom`, move `col`
- Up     → fixed `left`, move `row`

After each direction, shrink exactly **one boundary**.

---

### Final Correct Code (Java)

```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> result = new ArrayList<>();

        int top = 0;
        int bottom = matrix.length - 1;
        int left = 0;
        int right = matrix[0].length - 1;

        while (top <= bottom && left <= right) {

            // move right
            for (int col = left; col <= right; col++) {
                result.add(matrix[top][col]);
            }
            top++;

            // move down
            for (int row = top; row <= bottom; row++) {
                result.add(matrix[row][right]);
            }
            right--;

            // move left
            if (top <= bottom) {
                for (int col = right; col >= left; col--) {
                    result.add(matrix[bottom][col]);
                }
                bottom--;
            }

            // move up
            if (left <= right) {
                for (int row = bottom; row >= top; row--) {
                    result.add(matrix[row][left]);
                }
                left++;
            }
        }
        return result;
    }
}
```

---

### Complexity Analysis

- **Time:** `O(m * n)`
- **Space:** `O(1)` (excluding output)

---

### Final Lock-In Lessons

- Boundaries decide **whether** a direction runs
- Never control spiral traversal with counters
- Never share `row` / `col` across loops
- Shrink exactly one boundary per direction

---

### One-Sentence Recall

> Spiral traversal works by shrinking a rectangle inward; indices are temporary, boundaries are the truth.

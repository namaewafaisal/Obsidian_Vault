# 647. Palindromic Substrings

## Problem (LeetCode Statement)

**Input:**  
- String `s`

**Output:**  
- Integer → total number of palindromic substrings

**Task:**  
Count all substrings that are palindromes

---

## Constraints

- Must consider all substrings → naive O(n³) too slow
- Expected O(n²)

---

## Examples

```
Input: "abc"
Output: 3
```

```
Input: "aaa"
Output: 6
```

---

## What Actually Matters

- Every palindrome has a center
- Same expansion logic as LC 5
- Difference: count **all valid expansions**, not just max
- Each successful expansion = one palindrome

---

## Core Insight

> Every time expansion succeeds, you found a new palindrome

---

## Invariant / Mental Model

> While expanding, each valid `(left, right)` pair is a palindrome

---

## Thinking Log (Evolution of the Solution)

- Initial Thought:  
  This looks similar to longest palindrome

- Realization:  
  Instead of tracking max → count all

- Key Shift:  
  Expansion itself produces answers, not just candidates

- Final Understanding:  
  Each expansion step = +1 result

---

## Algorithm (High Level)

1. Iterate each index `i`
2. Expand:
   - Odd center → (i, i)
   - Even center → (i, i+1)
3. Count all valid expansions
4. Sum results

---

## Code (Reference Only)

```java
class Solution {
    public int countSubstrings(String s) {
        int count = 0;

        for(int i = 0; i < s.length(); i++){
            int odd = expand(i, i, s);
            int even = expand(i, i+1, s);
            count = count + odd + even;
        }

        return count;
    }

    public int expand(int left, int right, String s){
        int count = 0;

        while(left >= 0 && right < s.length() &&
              s.charAt(left) == s.charAt(right)) {
            count++;
            left--;
            right++;
        }

        return count;
    }
}
```

---

## Edge Cases to Recall

- Single character → always palindrome
- All same characters → maximum count
- No repeating characters → count = n

---

## One-Line Recall

> Expand from every center and count each valid expansion as a palindrome

### Problem (summary)

Given an array `nums` and an integer `k`, find a contiguous subarray whose length is equal to `k` that has the maximum average value and return this value.

---

### Example

Input: `nums = [1,12,-5,-6,50,3], k = 4`

Output: `12.75`

Explanation: Maximum average is `(12 - 5 - 6 + 50) / 4 = 51 / 4 = 12.75`.

---

### Pattern Classification

* Sliding Window (Fixed Size)
* Running Sum Accumulation

---

### Key Invariant

* The window size  must be **exactly `k**` at the moment we calculate the average.
* Only one element enters and one element leaves the window at each step after the initial setup.

---

### Thinking Log (Evolution of the Solution)

* **Initial Thought:** Calculate the sum of every possible subarray of size `k`.
* *Correction:* This involves redundant additions. For example, when moving from the first window to the second,  elements are the same.
* **Early Confusion:** Should I compare averages or sums?
* *Correction:* Since  is constant and positive, maximizing the sum is equivalent to maximizing the average (). It’s safer to track the max sum as an integer to avoid floating-point precision issues until the final division.
* **Key Insight:** `Double.MIN_VALUE` in Java is the smallest *positive* value (closest to 0). To represent the smallest possible negative double, use `-Double.MAX_VALUE`.

---

### Implementation Strategy

1. Maintain a `currSum` variable to track the sum of elements in the current window.
2. **Expand:** Move the `right` pointer and add `nums[right]` to `currSum`.
3. **Check Size:** Once `right - left + 1 == k`:
* Update the global `maxAvg`.
* **Slide (Shrink):** Subtract `nums[left]` from `currSum` and increment `left`.


4. Return the maximum average found.

---

### Code

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        int left = 0, right = 0;
        // Note: Double.MIN_VALUE is positive; use -Double.MAX_VALUE for negative infinity
        double maxAvg = -Double.MAX_VALUE; 
        int currSum = 0;

        while (right < nums.length) {
            currSum += nums[right];

            // Window is now at size k
            if (right - left + 1 == k) {
                maxAvg = Math.max(maxAvg, (double) currSum / k);
                
                // Slide the window: remove the leftmost element
                currSum -= nums[left++];
            }
            right++;
        }    
        return maxAvg;
    }
}

```

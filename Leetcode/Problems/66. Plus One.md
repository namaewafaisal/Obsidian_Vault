# 66. Plus One

## Problem (LeetCode Statement)

**Input:**  
- Integer array `digits`  
  - `digits[i]` represents the ith digit  
  - Most significant digit is at index 0  
  - No leading zeros

**Output:**  
- Return the array representing the integer incremented by one

**Task:**  
Simulate adding `1` to a large integer stored as an array of digits.

---

## Constraints

- `1 ≤ digits.length ≤ 100`
- `0 ≤ digits[i] ≤ 9`
- No leading zeros

---

## Examples

```
Input:  digits = [1,2,3]
Output: [1,2,4]
```

```
Input:  digits = [4,3,2,1]
Output: [4,3,2,2]
```

```
Input:  digits = [9]
Output: [1,0]
```

```
Input:  digits = [9,9,9]
Output: [1,0,0,0]
```

---

## What Actually Matters

- Addition must be done from **right to left**
- Carry propagates only if digit becomes 10
- If carry disappears early → stop immediately
- Only special case: all digits are 9

---

## Core Insight

> This is simple grade-school addition with carry.

But with one important optimization:

> If a digit becomes less than 10 after increment, we can return immediately.

This short-circuit makes the solution clean.

---

## Invariant / Mental Model

- We move from least significant digit to most significant.
- If a digit is not 9:
  - Increment it
  - Stop
- If digit is 9:
  - Turn it to 0
  - Carry continues

If all digits were 9:
- We need a new array of size `n + 1`
- Set first element to `1`
- Rest remain `0`

---

## Thinking Log (Evolution of the Solution)

### Initial Idea (your words)

> “Use a carry and add from right to left.”

Correct — that matches integer addition logic.

---

### Improvement

> “If carry becomes 0, we can stop.”

This is the key optimization.

We don’t need a separate carry variable —  
Increment and check directly.

---

### Edge Case Identified

> “If carry remains at the end, create a new array with 1 at the front.”

This happens only when original digits are all 9.

---

## Algorithm (High Level)

1. Traverse from end to start.
2. Increment current digit.
3. If digit < 10 → return array.
4. Otherwise set digit to 0 and continue.
5. If loop finishes → create new array with leading 1.

Time: `O(n)`  
Space: `O(1)` normally, `O(n)` worst case

---

## Code (Reference Only)

```java
class Solution {
    public int[] plusOne(int[] digits) {
        for (int i = digits.length - 1; i >= 0; i--) {
            digits[i]++;
            if (digits[i] < 10) {
                return digits;
            }
            digits[i] = 0;
        }

        int[] result = new int[digits.length + 1];
        result[0] = 1;
        return result;
    }
}
```

---

## Edge Cases to Recall

- Single element `[9]`
- All digits are 9
- No carry needed (e.g., `[1,2,3]`)
- Large array of 9s

---

## One-Line Recall

> Add 1 from the end; stop when no carry remains; if all digits were 9, prepend 1.

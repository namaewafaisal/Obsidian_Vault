## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`

**Output:**  
- `true` if there exist indices `i < j < k` such that  
  `nums[i] < nums[j] < nums[k]`, otherwise `false`

**Task:**  
Determine whether any strictly increasing subsequence of length 3 exists.

---

## Constraints

- `1 ≤ nums.length ≤ 5 * 10^5`
- `-2^31 ≤ nums[i] ≤ 2^31 - 1`
- Must run in `O(n)` time and `O(1)` space

---

## Examples

```
Input:  [1,2,3,4,5]
Output: true
```

```
Input:  [5,4,3,2,1]
Output: false
```

```
Input:  [2,1,5,0,4,6]
Output: true
```

---

## What Actually Matters

- Subsequence is **not contiguous**
- Only existence matters, not the actual values
- DP or LIS construction is unnecessary

---

## Core Insight

> We only need to know whether an increasing triplet is **possible**, not what it is.

---

## Invariant / Mental Model

> `first` is the smallest value seen so far.  
> `second` guarantees that some valid increasing pair existed earlier.

---

## Thinking Log (Evolution of the Solution)

- **Initial Thought:**  
  Count how many times values increase and return true if count reaches 3.

- **Correction:**  
  This fails because subsequences are not required to be contiguous.

- **Second Idea:**  
  Use a stack or LIS-style DP.

- **Correction:**  
  These approaches track too much information and are unnecessary.

- **Key Confusion:**  
  Updating the smallest value seems to break the ordering for the second value.

- **Final Realization:**  
  `second` represents a historical guarantee that an increasing pair existed.  
  If a value exceeds `second`, a triplet must exist — even if `first` was updated later.

---

## Algorithm (High Level)

1. Initialize `first` and `second` to very large values
2. Traverse the array once
3. Update `first` if current value is smaller
4. Else update `second` if it fits between
5. Else return `true`

---

## Code (Reference Only)

```java
class Solution {
    public boolean increasingTriplet(int[] nums) {
        int first = Integer.MAX_VALUE;
        int second = Integer.MAX_VALUE;

        for (int i : nums) {
            if (i <= first) {
                first = i;
            } else if (i <= second) {
                second = i;
            } else {
                return true;
            }
        }
        return false;
    }
}
```

---

## Edge Cases to Recall

- Duplicate values
- Strictly decreasing arrays
- Arrays with fewer than 3 elements

---

## One-Line Recall

> Track the smallest possible first and second values; a number greater than both confirms a triplet.

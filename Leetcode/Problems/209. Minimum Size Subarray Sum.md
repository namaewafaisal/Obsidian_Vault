## LC 209. Minimum Size Subarray Sum

| **Metric** | **Value** |
| --- | --- |

### Problem (summary)

Given an array of positive integers `nums` and a target sum `target`, find the **minimum length** of a contiguous subarray whose sum is greater than or equal to the target. If no such subarray exists, return 0.

---

### Example

Input: `target = 7, nums = [2,3,1,2,4,3]`

Output: `2`

Explanation: The subarray `[4,3]` has the minimal length under the problem constraint.

---

### Pattern Classification

* Sliding Window (Variable Size)
* Two Pointers
* Greedy Shrinking

---

### Key Invariant

* A window is considered **valid** if `windowSum >= target`.
* Because all elements are positive, expanding `right` always increases the sum, and shrinking `left` always decreases it.

---

### Thinking Log (Evolution of the Solution)

* **Initial Thought:** Use a nested loop to check every possible subarray sum.
* *Correction:* This is **O(n²)**. Since all numbers are positive, we can use a linear sliding window.
* **Early Confusion:** How to handle the case where no subarray meets the target?
* *Correction:* Initialize `len` to a value larger than the array size (like `n + 1`) and check if it was updated at the end.
* **Rejected Idea:** Using a fixed window size and binary searching for the answer.
* *Correction:* While possible (), the two-pointer sliding window is more efficient at **O(n)**.
* **Crucial Insight:** Unlike "Max Window" problems where you update the result *after* the while loop, in "Min Window" problems, you update the result **inside** the while loop as you attempt to break the validity.

---

### Implementation Strategy

1. Initialize `left` and `right` at 0, `sum` at 0, and `len` at `Integer.MAX_VALUE`.
2. **Expand:** Add `nums[right]` to `sum`.
3. **Shrink (The "Minimize" Phase):** While `sum >= target`:
* Update `len` with the current window size `right - left + 1`.
* Subtract `nums[left]` from `sum` and increment `left`.


4. **Repeat:** Move `right` forward until the end of the array.

---

### Code

```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int right = 0, left = 0;
        int len = nums.length + 1; // Sentinel value
        int sum = 0;

        while (right < nums.length) {
            sum += nums[right];

            // While window is valid, record length and try to shrink
            while (sum >= target) {
                len = Math.min(len, right - left + 1);
                sum -= nums[left++];
            }
            right++;
        }
        
        return (len > nums.length) ? 0 : len;
    }
}

```

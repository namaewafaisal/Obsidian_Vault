# LC 1295. Find Numbers with Even Number of Digits

## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`

**Output:**  
- Return the number of integers that contain an **even number of digits**

**Task:**  
Count how many numbers in the array have **even digit length**.

---

## Constraints

- `1 ≤ nums.length ≤ 500`
- `1 ≤ nums[i] ≤ 10^5`

---

## Examples

```
Input: nums = [12,345,2,6,7896]
Output: 2
```

```
Input: nums = [555,901,482,1771]
Output: 1
```

---

## What Actually Matters

- We only care about **digit count**, not the value itself
- Digit count can be computed **mathematically**
- Converting to string is unnecessary overhead

---

## Core Insight

> The number of digits of a number `n` is `⌊log10(n)⌋ + 1`.

Example:

```
log10(345) ≈ 2.53
⌊2.53⌋ + 1 = 3 digits
```

---

## Invariant / Mental Model

For each number:

```
digits = floor(log10(n)) + 1
```

If:

```
digits % 2 == 0
```

Then increment the count.

---

## Algorithm (High Level)

1. Initialize counter
2. Traverse the array
3. Compute digit count using `log10`
4. If digit count is even → increment counter
5. Return counter

---

## Code (Reference Only)

```java
class Solution {
    public int findNumbers(int[] nums) {
        int count = 0;

        for(int i : nums){
            if((int)(Math.log10(i) + 1) % 2 == 0){
                count++;
            }
        }

        return count;
    }
}
```

---

## Edge Cases to Recall

- Single digit numbers → always odd
- `10` → 2 digits
- `100000` → 6 digits

---

## One-Line Recall

> Digit count of `n` is `⌊log10(n)⌋ + 1`, so check if it’s even.

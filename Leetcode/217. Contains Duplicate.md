## LC 217. Contains Duplicate

### Problem (Statement)

Given an integer array `nums`, return `true` if any value appears **at least twice** in the array.

Otherwise, return `false`.

---

### Key Observation

> The problem is not about counting — it is about **early detection**.

The moment a duplicate is found, the answer is known.

---

### Core Idea (Set Invariant)

Maintain a `HashSet`:
- Each new element is checked before insertion
- If it already exists → duplicate found

Invariant:
> The set always contains **unique elements seen so far**.

---

### Why Sorting Is Suboptimal

- Sorting costs `O(n log n)`
- Does unnecessary work
- Hashing solves it in linear time

---

### Algorithm Overview

1. Create an empty `HashSet`
2. Traverse array:
   - If element exists in set → return true
   - Else add to set
3. If traversal completes → return false

Time: `O(n)`  
Space: `O(n)`

---

### Final Code (Java)

```java
class Solution {
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> set = new HashSet<>();

        for (int x : nums) {
            if (set.contains(x)) {
                return true;
            }
            set.add(x);
        }
        return false;
    }
}
```

### Common Mistakes

- Sorting instead of hashing
- Counting frequencies unnecessarily
- Forgetting early return
- Using nested loops

# Stack vs Queue — Behavioral Discipline

## Stack

- LIFO
- Access from one end only
- Used for recursion, DFS, undo

## Queue

- FIFO
- Insert at rear
- Remove from front
- Used for BFS, scheduling

---

## Structural Difference

Stack:
- Single pointer sufficient

Queue:
- Requires front and rear pointers

---

## Mental Model

Stack → Vertical structure  
Queue → Horizontal pipeline

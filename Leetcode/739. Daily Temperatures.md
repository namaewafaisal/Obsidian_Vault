# 739. Daily Temperatures

## Problem (LeetCode Statement)

**Input:**  
- Integer array `temperatures`

**Output:**  
- Array where each index `i` stores number of days until a warmer temperature  
- If none exists → `0`

**Task:**  
For each day, find the next day with a higher temperature

---

## Constraints

- Must be O(n)
- Brute force O(n²) is too slow

---

## Examples

```
Input: [73,74,75,71,69,72,76,73]
Output: [1,1,4,2,1,1,0,0]
```

---

## What Actually Matters

- You are searching for the **next greater element to the right**
- Brute force checks every future day → inefficient
- Once a future day is useless, it should never be considered again

---

## Core Insight

> Use a stack to keep only **useful future candidates**

---

## Invariant / Mental Model

> Stack stores indices of days with **strictly increasing temperatures from top to bottom**

Top of stack always represents:
- the **nearest future warmer day**

---

## Thinking Log (Evolution of the Solution)

- Initial Thought:  
  For each day, scan forward → O(n²)

- Issue:  
  Repeated comparisons → wasteful

- Correction:  
  Remove useless future days

- Key Realization:  
  If a future day is ≤ current temperature, it will **never be useful** again

- Final Understanding:  
  Maintain a monotonic decreasing stack and process from right to left

---

## Algorithm (High Level)

1. Traverse from right → left
2. While stack not empty and top ≤ current:
   - pop (useless candidate)
3. If stack empty → answer = 0
4. Else → answer = index difference
5. Push current index

---

## Code (Reference Only)

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int[] result = new int[temperatures.length];
        Stack<Integer> stack = new Stack<>();

        for(int i = temperatures.length - 1; i >= 0; i--){
            while(!stack.isEmpty() && temperatures[stack.peek()] <= temperatures[i]){
                stack.pop();
            }

            result[i] = stack.isEmpty() ? 0 : stack.peek() - i;
            stack.push(i);
        }

        return result;
    }
}
```

---

## Edge Cases to Recall

- Strictly decreasing array → all 0
- Strictly increasing → all 1 except last
- Single element → 0

---

## One-Line Recall

> Traverse right to left, maintain a monotonic stack, and discard useless future days

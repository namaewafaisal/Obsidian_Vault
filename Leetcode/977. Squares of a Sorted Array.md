## LC 977. Squares of a Sorted Array

### Problem (Statement)

Given a sorted integer array `nums` (non-decreasing order), return a new array containing the **squares of each number**, also sorted in non-decreasing order.

Constraints:
- Input array is sorted
- Values can be negative
- Output must be sorted
- No in-place requirement

---

### Key Observation

> Squaring breaks the original order because negative values can produce larger squares than positive values.

However:

> The **largest square** always comes from one of the **ends** of the array.

This allows linear-time construction.

---

### Core Idea (Two-Pointer Invariant)

Use two pointers:
- `left` at the start
- `right` at the end

Build the result array **from the back**.

Invariant:
> All indices **greater than `index`** in the result array already contain the **largest squares in correct sorted order**.

---

### Thinking Log (Mandatory)

#### My initial thinking (your words)

> I thought of squaring all values and sorting the array again.  
> That works but costs `O(n log n)`.  
>  
> I then thought of finding the value closest to zero using binary search and merging outward from there.  
> This would work in `O(n)` but felt complex.

---

#### Correction / refinement

- Finding the smallest square first is unnecessary
- The problem becomes simpler if we instead place the **largest square first**
- Because the array is sorted, the largest absolute value must be at either end
- Filling the result array **from right to left** avoids extra comparisons and special cases

This removes the need for binary search entirely.

---

### Algorithm Overview

1. Create a result array of the same size
2. Initialize:
   - `left = 0`
   - `right = n - 1`
   - `index = n - 1`
3. While `left <= right`:
   - Compare `abs(nums[left])` and `abs(nums[right])`
   - Place the larger square at `result[index]`
   - Move the corresponding pointer
   - Decrement `index`
4. Return result

Time: `O(n)`  
Space: `O(n)`

---

### Final Code (Java)

```java
class Solution {
    public int[] sortedSquares(int[] nums) {
        int[] result = new int[nums.length];
        int left = 0;
        int right = nums.length - 1;
        int index = right;

        while (left <= right) {
            if (Math.abs(nums[right]) > Math.abs(nums[left])) {
                result[index--] = nums[right] * nums[right];
                right--;
            } else {
                result[index--] = nums[left] * nums[left];
                left++;
            }
        }
        return result;
    }
}
```

### Common Mistakes

- Squaring first and then sorting
- Trying to merge from the smallest square outward
- Forgetting that the largest square belongs at the end
- Incorrect loop condition (`left < right` without handling middle element)

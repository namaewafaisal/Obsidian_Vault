# 572. Subtree of Another Tree

## Problem (LeetCode Statement)

**Input:**
- `TreeNode root` — root of the main tree
- `TreeNode subRoot` — root of the candidate subtree

**Output:**
- `true` if some subtree of `root` has the same structure and values as `subRoot`

**Task:**
Check if any subtree of the main tree is identical to the given subRoot tree.

---

## Constraints

- `1 <= number of nodes in root <= 2000`
- `1 <= number of nodes in subRoot <= 1000`
- `-10^4 <= Node.val <= 10^4`

---

## Examples
```
Input:  root = [3,4,5,1,2], subRoot = [4,1,2]
Output: true
```
```
Input:  root = [3,4,5,1,2,null,null,null,null,0], subRoot = [4,1,2]
Output: false
```

---

## What Actually Matters

- Directly reuses Same Tree logic — this problem is Same Tree + DFS search
- Same value can appear multiple times — don't stop searching if `isSameTree` returns false at a match
- `root == null` means nothing left to search → false, not true
- Recursion on left and right handles depth automatically — no manual depth tracking needed

---

## Core Insight

> Search every node in `root` for a match with `subRoot`. At each node, if values match AND `isSameTree` returns true → found it. Otherwise keep searching left and right subtrees.

---

## Invariant / Mental Model

> `isSubtree` searches. `isSameTree` verifies. Keep them separate — `isSubtree` recurses the main tree, `isSameTree` compares two trees node by node.

---

## Thinking Log (Evolution of the Solution)

- **Initial Thought:** Find the node in root matching subRoot's value, then run isSameTree from there
- **Issue 1:** `root == null → return true` — wrong, null means search failed, should return false
- **Issue 2:** `if(root.val == subRoot.val) return isSameTree(root, subRoot)` — stops searching if isSameTree returns false, but same value can appear elsewhere in the tree
- **Fix:** `if(root.val == subRoot.val && isSameTree(root, subRoot)) return true` — only return true on confirmed match, otherwise fall through to left/right recursion
- **Final Realization:** Separate methods are the right call — isSameTree is a clean reusable helper, isSubtree handles the search

---

## Algorithm (High Level)

1. If `root == null` → return false (search exhausted)
2. If `root.val == subRoot.val` AND `isSameTree(root, subRoot)` → return true
3. Otherwise recurse: `isSubtree(left, subRoot) || isSubtree(right, subRoot)`

---

## Code (Reference Only)
```java
class Solution {
    public boolean isSubtree(TreeNode root, TreeNode subRoot) {
        if (root == null) return false;
        if (root.val == subRoot.val && isSameTree(root, subRoot)) return true;
        return isSubtree(root.left, subRoot) || isSubtree(root.right, subRoot);
    }

    public boolean isSameTree(TreeNode p, TreeNode q) {
        if (p == null && q == null) return true;
        if (p == null || q == null) return false;
        if (p.val != q.val) return false;
        return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
    }
}
```

---

## Edge Cases to Recall

- Same value appears multiple times in root → must fall through to left/right if isSameTree fails
- subRoot is the entire root tree → isSameTree catches it at the first call
- root is null → return false immediately, nothing to search

---

## One-Line Recall

> Search root with DFS — at each value match run isSameTree, if false keep searching left and right.

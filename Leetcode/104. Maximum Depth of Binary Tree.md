# 104. Maximum Depth of Binary Tree

## Problem (LeetCode Statement)

**Input:**
- `TreeNode root` — root of a binary tree

**Output:**
- Maximum depth — number of nodes along the longest path from root to farthest leaf

**Task:**
Find the length of the longest root-to-leaf path in a binary tree.

---

## Constraints

- `0 <= number of nodes <= 10^4`
- `-100 <= Node.val <= 100`

---

## Examples
```
Input:  [3,9,20,null,null,15,7]
Output: 3
```
```
Input:  [1,null,2]
Output: 2
```

---

## What Actually Matters

- Depth = number of levels, not edges — each level processed in BFS increments depth by 1
- `q.size()` must be snapshotted before the inner loop — it changes as you poll and offer mid-loop
- `depth++` goes after the inner loop — you increment after completing a full level, not before starting it
- Null root → return 0 immediately

---

## Core Insight

> Process the tree level by level using BFS. Each completed level increments depth by 1. Snapshot `q.size()` before each level to know exactly how many nodes belong to the current level.

---

## Invariant / Mental Model

> At the start of each while iteration, the queue contains exactly all nodes of the current level. After processing all of them, depth increments by 1 and the queue now holds the next level.

---

## Thinking Log (Evolution of the Solution)

- **Initial Thought:** BFS level order — process level by level, increment depth per level
- **Bug:** Used `q.size()` directly in the for loop condition — size changes as nodes are polled and children are offered, causing incorrect iteration count
- **Fix:** Snapshot `int size = q.size()` before the inner loop — process exactly that many nodes per level
- **Correction:** `depth++` moved to after the inner loop — semantically correct, increment after completing a level not before starting it

---

## Algorithm (High Level)

1. Handle null root → return 0
2. Offer root to queue, set `depth = 0`
3. While queue is not empty: snapshot `size`, poll exactly `size` nodes, offer their non-null children, then `depth++`
4. Return `depth`

---

## Code (Reference Only)
```java
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        int depth = 0;
        Queue<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        while (!q.isEmpty()) {
            int size = q.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = q.poll();
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
            depth++;
        }
        return depth;
    }
}
```

---

## Edge Cases to Recall

- `root == null` → return 0
- Single node → queue processes one node, no children offered, depth becomes 1
- Skewed tree (like a linked list) → every level has exactly one node, depth equals total node count

---

## One-Line Recall

> BFS level order — snapshot queue size before each level, process that many nodes, increment depth after each level completes.

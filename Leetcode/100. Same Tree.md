# 100. Same Tree

## Problem (LeetCode Statement)

**Input:**
- `TreeNode p` — root of first binary tree
- `TreeNode q` — root of second binary tree

**Output:**
- `true` if both trees are structurally identical with same node values, `false` otherwise

**Task:**
Check if two binary trees are exactly the same in both structure and values.

---

## Constraints

- `0 <= number of nodes <= 100`
- `-10^4 <= Node.val <= 10^4`

---

## Examples
```
Input:  p = [1,2,3], q = [1,2,3]
Output: true
```
```
Input:  p = [1,2], q = [1,null,2]
Output: false  (different structure)
```
```
Input:  p = [1,2,1], q = [1,1,2]
Output: false  (same structure, different values)
```

---

## What Actually Matters

- Structure mismatch and value mismatch are two separate failure conditions
- BFS works but adds unnecessary complexity — recursive DFS is the natural fit for tree comparison
- Both null means both subtrees ended together — that's a match, not a failure
- One null and one not null means structure diverged — immediate false

---

## Core Insight

> Two trees are the same if their roots match AND their left subtrees match AND their right subtrees match. Recursion expresses this directly in 4 lines.

---

## Invariant / Mental Model

> At every node, check the current values first, then delegate the rest to recursion. If any node pair fails, the false propagates all the way back up.

---

## Thinking Log (Evolution of the Solution)

- **Initial Thought:** BFS with two queues, poll simultaneously, check values and structure at each level
- **Issue:** BFS is valid but verbose — null handling, size checks, and queue management add noise
- **Realization:** Tree comparison is naturally recursive — the definition of "same tree" is itself recursive
- **Final Realization:** 4 cases cover everything: both null (true), one null (false), values differ (false), recurse on children

---

## Algorithm (High Level)

1. If both null → return true
2. If one null → return false
3. If values differ → return false
4. Recurse: return `isSameTree(left, left) && isSameTree(right, right)`

---

## Code (Reference Only)
```java
class Solution {
    public boolean isSameTree(TreeNode p, TreeNode q) {
        if (p == null && q == null) return true;
        if (p == null || q == null) return false;
        if (p.val != q.val) return false;
        return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
    }
}
```

---

## Edge Cases to Recall

- Both empty trees → both null at root → return true
- One empty one not → immediate false at root
- Same structure different values → caught by `p.val != q.val`

---

## One-Line Recall

> Both null = true, one null = false, values differ = false, else recurse on both children.

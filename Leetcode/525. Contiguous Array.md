## LC 525. Contiguous Array

### Problem (Statement)

Given a binary array `nums` containing only `0` and `1`, return the **maximum length of a contiguous subarray** with **equal number of 0s and 1s**.

---

### Key Reframing (Critical Insight)

> “Equal number of 0s and 1s” is equivalent to **net balance = 0**.

Transform the problem by mapping:
```
1 → +1
0 → -1
```

After transformation:
> The task becomes finding the **longest subarray with sum = 0**.

This reframing is the core breakthrough.

---

### Core Idea (Prefix Sum Invariant)

Let:
```
prefixSum[i] = sum of values from index 0 to i
```

Invariant:
> If the **same prefix sum appears at two different indices**,  
> then the subarray between them has sum `0`.

Why:
```
prefix[j] − prefix[i] = 0
```

So the problem reduces to:
> **Find the maximum distance between two equal prefix sums.**

---

### Why HashMap Is Needed

We store:
```
prefixSum → earliest index where it occurred
```

Why earliest?
- Earlier index gives **longer subarray** later
- Later occurrences should not overwrite earlier ones

---

### Mandatory Initialization (Easy to Miss)

Before traversal:
```
map.put(0, -1)
```

Why this is required:
- Handles subarrays starting from index `0`
- If prefix sum becomes `0` at index `i`, length = `i − (−1) = i + 1`

This is **not optional**.

---

### Thinking Log (Actual Reasoning Path)

#### Initial intuition (your words)

> I need equal 0s and 1s, so maybe I can count them in subarrays.

#### Why brute force fails

- Checking all subarrays is `O(n²)`
- Counting repeatedly is wasteful

#### Breakthrough realization

> If I treat 0 as −1, then equal 0s and 1s cancel out.

From here, the prefix-sum logic becomes obvious.

---

### Algorithm Overview

1. Initialize:
   - `sum = 0`
   - `longest = 0`
   - HashMap with `{0 → -1}`
2. Traverse array:
   - Add `+1` for `1`, `-1` for `0`
3. If current sum was seen before:
   - Update longest length
4. Else:
   - Store sum with current index
5. Return longest

Time: `O(n)`  
Space: `O(n)`

---

### Final Code (Java — Your Version)

```java
class Solution {
    public int findMaxLength(int[] nums) {
        Map<Integer, Integer> map = new HashMap<>();
        int sum = 0;
        int longest = 0;

        map.put(0, -1);

        for (int i = 0; i < nums.length; i++) {
            sum += nums[i] == 1 ? 1 : -1;

            if (map.containsKey(sum)) {
                longest = Math.max(longest, i - map.get(sum));
            } else {
                map.put(sum, i);
            }
        }
        return longest;
    }
}
```

### Common Mistakes

- Forgetting to convert `0 → -1`
- Forgetting `map.put(0, -1)`
- Overwriting an existing prefix sum index
- Thinking this is a sliding window problem (it is not)

# 73. Set Matrix Zeroes

## Problem (LeetCode Statement)

**Input:**  
- 2D integer matrix `matrix`

**Output:**  
- Modify matrix in-place such that if an element is `0`, its entire row and column become `0`

**Task:**  
For every `0` in the matrix, set its full row and column to `0` in-place

---

## Constraints

- Must modify matrix **in-place**
- O(m * n) time required
- Optimal space: O(1)

---

## Examples

```
Input:  [[1,1,1],[1,0,1],[1,1,1]]
Output: [[1,0,1],[0,0,0],[1,0,1]]
```

```
Input:  [[0,1],[1,1]]
Output: [[0,0],[0,1]]
```

---

## What Actually Matters

- A single `0` invalidates its **entire row and column**
- Cannot modify while scanning → corrupts future decisions
- Storing all `(i, j)` positions is unnecessary
- Only rows and columns matter, not individual cells

---

## Core Insight

> Use the **first row and first column as markers** to store which rows and columns must become zero

---

## Invariant / Mental Model

> `matrix[i][0] == 0` → row `i` must be zero  
> `matrix[0][j] == 0` → column `j` must be zero  

Special case:
> `matrix[0][0]` cannot represent both row 0 and column 0 → use separate flag

---

## Thinking Log (Evolution of the Solution)

- Initial Thought:  
  Store all `(i, j)` where value is `0`, then apply changes

- Issue:  
  Extra space + unnecessary tracking of positions

- Correction:  
  Only rows and columns matter → use sets

- Further Optimization:  
  Avoid extra space by reusing matrix itself

- Key Realization:  
  First row and column can act as markers

- Final Issue:  
  `(0,0)` conflict → cannot track both row 0 and column 0

- Final Fix:  
  Use separate variable `col0` to track column 0

---

## Algorithm (High Level)

1. Traverse matrix:
   - Mark rows via `matrix[i][0]`
   - Mark columns via `matrix[0][j]`
   - Track column 0 separately

2. Traverse matrix in reverse:
   - Apply zero based on markers

3. Handle column 0 using `col0`

---

## Code (Reference Only)

```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int m = matrix.length;
        int n = matrix[0].length;

        boolean col0 = false;

        // Step 1: mark rows & columns
        for (int i = 0; i < m; i++) {
            if (matrix[i][0] == 0) col0 = true;

            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        // Step 2: apply markers (reverse traversal)
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 1; j--) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }

            if (col0) {
                matrix[i][0] = 0;
            }
        }
    }
}
```

---

## Edge Cases to Recall

- First row contains zero
- First column contains zero
- Single row / single column
- Entire matrix is zero

---

## One-Line Recall

> Use first row and column as markers, handle column 0 separately, and apply changes in reverse

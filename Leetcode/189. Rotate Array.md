## LC 189. Rotate Array

### Problem (Statement)

Given an integer array `nums`, rotate the array to the **right by `k` steps**, where `k` is non-negative.

Constraints:
- Rotation must be done **in-place**
- Order of elements **must be preserved after rotation**
- `k` can be greater than the array size

---

### Key Observation

> Rotating an array is not about swapping individual elements — it is about **rearranging contiguous segments**.

Right rotation by `k` means:
```
[A | B]  →  [B | A]
```
where:
- `A` = first `n - k` elements
- `B` = last `k` elements

---

### Core Idea (Segment Reversal Invariant)

Reversal is an **in-place operation** that preserves relative order when applied twice.

Invariant:
> After each reversal, a **whole segment** of the array is placed in its final relative order.

Using this, rotation can be achieved safely without tracking cycles.

---

#### Why that thinking was flawed (correction)

- Rotation is a **cyclic permutation**, not a local swap problem
- Swapping individual elements causes:
  - overwriting values still needed later
  - broken invariants
- If an approach cannot express a clean invariant, it is structurally invalid

This is not a bug-fixing problem — it is a **wrong abstraction** problem.

---

#### Corrected mental model

> Treat the array as **two segments**, not individual elements.  
> Use reversal to reposition entire segments safely.

---

### Algorithm Overview (Reverse Trick)

1. Normalize `k`:
   ```
   k = k % n
   ```
2. Reverse the entire array
3. Reverse the first `k` elements
4. Reverse the remaining `n - k` elements

Each step is in-place and linear.

Time: `O(n)`  
Space: `O(1)`

---

### Final Code (Java)

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n;

        if (k == 0 || n == 1) return;

        reverse(nums, 0, n - 1);
        reverse(nums, 0, k - 1);
        reverse(nums, k, n - 1);
    }

    private void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}
```

# RSS Live Folder URL Validation Vulnerability

RSS feeds are XML files that contain updates/posts from websites.

Flow:

```txt
Subscribe to RSS feed
    ↓
Browser/RSS reader downloads XML
    ↓
XML contains new post items
    ↓
Each item has a URL/link
    ↓
Browser creates tabs or entries from those URLs
```

The vulnerability in Zen Browser happened because the browser validated only the main RSS feed URL, but not the URLs of individual RSS items/posts.

Safe item URLs should only be:

```txt
http://
https://
```

But malicious feeds could provide:

```txt
javascript:
file:
data:
about:
chrome:
```

This is dangerous because untrusted internet data was allowed to influence trusted browser tab creation.

Core issue:

```txt
Missing validation of RSS item URLs
```

Concept:

```txt
Input Validation Failure
```

## What is a Data Structure?

A data structure is a way of organizing data in memory so that it can be accessed and modified efficiently. The choice of data structure directly impacts the time and space complexity of algorithms that operate on it.

- Concerned with: **storage layout, access patterns, memory**
- Key metrics: **access time, insertion time, deletion time, space used**
- Types: Linear, Non-Linear, Hash-Based, Heap-Based, Graph-Based

## What is an Algorithm?

An algorithm is a finite set of well-defined instructions to solve a problem or perform a computation. Algorithms operate *on* data structures.

- Concerned with: **correctness, efficiency, termination**
- Key metrics: **Time Complexity (Big-O), Space Complexity, Best/Worst/Average case**
- Categories: Sorting, Searching, Graph, Dynamic Programming, Greedy, Backtracking, etc.

## Complexity Quick Reference

| Notation | Name | Example |
|---|---|---|
| O(1) | Constant | Array index access |
| O(log n) | Logarithmic | Binary search |
| O(n) | Linear | Linear scan |
| O(n log n) | Linearithmic | Merge sort |
| O(n²) | Quadratic | Bubble sort |
| O(2ⁿ) | Exponential | Recursive subset enumeration |
| O(n!) | Factorial | Permutation generation |

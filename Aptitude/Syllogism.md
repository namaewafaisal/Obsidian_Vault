# 🧠 Syllogism — Learn Once, Score Always

---

## 🔴 BASIC IDEA

Syllogism questions test **logical certainty**,  
not real-world truth.

We use **Venn Diagrams** to check conclusions.

---

## 🔴 STANDARD STATEMENTS (ONLY THESE MATTER)

1. **All A are B**
2. **No A are B**
3. **Some A are B**
4. **Some A are not B**

Words like *all, some, no* are critical.

---

## 🔴 VENN DIAGRAM RULES (MUST FOLLOW)

### Rule 1: “All A are B”
- Draw A **inside** B

---

### Rule 2: “No A are B”
- Draw A and B **separate**

---

### Rule 3: “Some A are B”
- Draw **overlap**
- Place an **×** in overlap

---

### Rule 4: “Some A are not B”
- Draw an × in A **outside** B

---

## 🔴 GOLDEN RULES (VERY IMPORTANT)

1. **Some ≠ All**
2. **All does NOT mean some**
3. **Some statements never convert**
4. Conclusion must be **100% guaranteed**

If even **1 case fails**, reject the conclusion.

---

## 🟠 CONVERSION RULES (EXAM TRAP)

| Statement | Conversion Valid? |
|---------|------------------|
| All A are B | ❌ No |
| No A are B | ✅ Yes |
| Some A are B | ✅ Yes |
| Some A are not B | ❌ No |

---

## 🟠 COMMON CONCLUSION TYPES

- All A are C ❌ (usually false)
- Some A are C ✅ (often true)
- Some C are A ✅ (conversion)
- No A are C ❌

---

## 🟡 SHORTCUT ELIMINATION

- If conclusion has **“All”** → check strictly
- If conclusion has **“Some”** → easier to satisfy
- Extreme words = risky

---

## ❌ NEVER USE REAL-LIFE LOGIC

“Dogs can’t be cats” ❌  
Only diagram logic matters.

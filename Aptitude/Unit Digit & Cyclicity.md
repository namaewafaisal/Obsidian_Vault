# 🔢 Number System — Unit Digit / Cyclicity (Formula Sheet)

---

## 🔴 CORE IDEA

Unit digits repeat in **cycles of 1, 2, or 4**

---

## 🔴 CYCLES (MUST MEMORIZE)

| Number | Cycle |
|------|------|
| 0 | 0 |
| 1 | 1 |
| 2 | 2,4,8,6 |
| 3 | 3,9,7,1 |
| 4 | 4,6 |
| 5 | 5 |
| 6 | 6 |
| 7 | 7,9,3,1 |
| 8 | 8,4,2,6 |
| 9 | 9,1 |

---

## 🔴 METHOD

1. Find cycle length  
2. Power mod cycle length  
3. Pick digit  

---

## 🟠 SPECIAL FACTS

- Unit digit of $n!$ for $n \ge 5$ = **0**
- Unit digit of $1! + 2! + \dots + n!$ ($n\ge4$) = **3**

---

## 🟡 QUICK NOTES

- Reduce exponent using modulo
- Use cycle tables, not calculation
- Combine digits separately in expressions

---

## ❌ DO NOT WRITE

- Brute-force powers  
- Trial multiplication

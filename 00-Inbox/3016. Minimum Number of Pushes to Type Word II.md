# 3016. Minimum Number of Pushes to Type Word II

## Problem

**Input:**
- String `word`

**Output:**
- Minimum number of key presses needed to type the word.

> *(This solution assumes the characters are already optimally ordered by frequency, so only the position cost is calculated.)*

---

## Pattern

**Greedy + Counting**

---

## Core Idea

- A keyboard has **8 characters per push level**.
- First 8 characters cost **1 push** each.
- Next 8 characters cost **2 pushes** each.
- Next 8 cost **3 pushes**, and so on.
- For the `i`-th assigned character (0-based), its cost is:

```
(i / 8) + 1
```

---

## Dry Run

### Case 1

```
word = "abcdefgh"

Length = 8

All characters are in the first group.

Cost:
1 × 8 = 8

Answer = 8
```

---

### Case 2

```
word length = 10

Indices:
0..7  -> cost 1
8..9  -> cost 2

Total:
8 × 1 + 2 × 2
= 8 + 4
= 12
```

---

### Case 3

```
word length = 20

0..7   -> 8 × 1 = 8
8..15  -> 8 × 2 = 16
16..19 -> 4 × 3 = 12

Total = 36
```

---

## Code

```java
class Solution {
    public int minimumPushes(String word) {
        int n = word.length();
        if(n <= 8) return n;

        int ans = 0;
        int s = 0;

        while(s < n) {
            ans += (s / 8) + 1;
            s++;
        }

        return ans;
    }
}
```

---

## Things to Remember

- Every block of **8 assigned characters** increases the push cost by **1**.
- The formula `(index / 8) + 1` directly gives the cost of the current character.
- **Note:** The full LeetCode problem requires assigning **more frequent characters to lower-cost positions** (usually by counting frequencies and sorting). This solution computes only the cost based on the assigned order.

---

## One-Line Recall

> Every 8 assigned characters move to the next push level, so each character costs `(index / 8) + 1` presses.

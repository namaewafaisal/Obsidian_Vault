# Interrupts

## Definition

```text
Event that interrupts
normal program execution
```

CPU:

```text
Save state
↓
Execute ISR
↓
RETI
↓
Resume
```

ISR:

```text
Interrupt Service Routine
```

---

# Why Interrupts

Polling:

```text
Continuous checking
```

Interrupts:

```text
Event-driven
```

Less CPU waste.

---

# Interrupt Sources

| Interrupt | Source |
|------------|------------|
| INT0 | External Interrupt 0 |
| Timer0 | Timer0 Overflow |
| INT1 | External Interrupt 1 |
| Timer1 | Timer1 Overflow |
| Serial | RI/TI |

Pins:

```text
INT0 = P3.2
INT1 = P3.3
```

---

# IE Register

```text
EA - ES ET1 EX1 ET0 EX0
```

| Bit | Function |
|------|------|
| EA | Global Enable |
| ES | Serial |
| ET1 | Timer1 |
| EX1 | External1 |
| ET0 | Timer0 |
| EX0 | External0 |

Example:

```asm
MOV IE,#82H
```

```text
EA = 1
ET0 = 1
```

Enable Timer0 interrupt.

---

# IP Register

```text
Interrupt Priority Register
```

Rule:

```text
1 → High Priority
0 → Low Priority
```

---

# Priority Rules

```text
High priority ISR
can interrupt
low priority ISR
```

```text
Same priority
cannot interrupt
each other
```

---

# Vector Addresses

| Interrupt | Address |
|------------|------------|
| INT0 | 0003H |
| Timer0 | 000BH |
| INT1 | 0013H |
| Timer1 | 001BH |
| Serial | 0023H |

---

# RETI

```asm
RETI
```

```text
Return From Interrupt
```

Ends ISR.

---

# Interrupt Latency

```text
≥ 3 machine cycles
```

---

# Interrupt Flow

```text
Interrupt
↓
Save PC
↓
Jump to Vector
↓
ISR
↓
RETI
↓
Resume
```

---

# Timer0 ISR Example

```asm
ORG 000BH

CPL P1.0

RETI
```

```text
Toggle P1.0
on every overflow
```

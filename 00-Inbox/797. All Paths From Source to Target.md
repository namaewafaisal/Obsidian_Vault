# 797. All Paths From Source to Target

## Problem

Given a directed acyclic graph (DAG), return all possible paths from node `0` to node `n - 1`.

**Example:**

```
Input:
graph = [[1,2],[3],[3],[]]

Output:
[[0,1,3],[0,2,3]]
```

---

## Pattern

**DFS + Backtracking**

## Core Idea

- Start DFS from node `0`.
- Add the current node to the path.
- If the current node is the target (`n - 1`), save a **copy** of the path.
- Otherwise, recursively explore every unvisited neighbor.
- After exploring, undo the current choice:
  - Mark the node unvisited.
  - Remove it from the path.

**Why backtrack?**

Each possible path must be explored independently. Removing the current node allows DFS to explore other paths without carrying over nodes from the previous path.

---

## Dry Run

```
graph = [[1,2],[3],[3],[]]
```

### Path 1: `0 → 1 → 3`

1. Visit `0`: `temp = [0]`
2. Visit `1`: `temp = [0,1]`
3. Visit `3`: target reached.
4. Save a copy: `res = [[0,1,3]]`
5. Backtrack: remove `3`, then `1`.

### Path 2: `0 → 2 → 3`

1. Visit `2`: `temp = [0,2]`
2. Visit `3`: target reached.
3. Save a copy: `res = [[0,1,3],[0,2,3]]`
4. Backtrack until the path is empty.

**Answer:**

```
[[0,1,3],[0,2,3]]
```

---

## Code

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();

    public List<List<Integer>> allPathsSourceTarget(int[][] graph) {
        boolean[] vis = new boolean[graph.length];
        List<Integer> temp = new ArrayList<>();

        dfs(graph, 0, temp, vis);

        return res;
    }

    public void dfs(int[][] graph, int node, List<Integer> temp, boolean[] vis) {
        temp.add(node);
        vis[node] = true;

        if(node == graph.length - 1) {
            res.add(new ArrayList<>(temp));
        }
        else {
            for(int nei : graph[node]) {
                if(!vis[nei]) {
                    dfs(graph, nei, temp, vis);
                }
            }
        }

        vis[node] = false;
        temp.remove(temp.size() - 1);
    }
}
```

---

## Things to Remember

- `temp` stores the current path.
- `res.add(new ArrayList<>(temp))` saves a **copy**; adding `temp` directly would cause all results to share the same mutable list.
- Backtracking restores the state after each recursive call.
- `vis` tracks nodes in the current path, not nodes visited globally. Different paths can share the same node.
- Since the graph is a DAG, cycles are absent; the `vis` array is still used to prevent revisiting a node within the current path.
- Time complexity can be exponential because the number of possible paths can be exponential. The work is proportional to the total size of all returned paths.
- Auxiliary space: \(O(V)\) for the recursion stack, current path, and visited array, excluding the output.

## One-Line Recall

> DFS explores every route from source to target; backtracking removes each choice so alternative paths can be explored independently.

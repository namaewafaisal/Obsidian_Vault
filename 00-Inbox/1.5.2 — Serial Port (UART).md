# UART

## Basics
- UART = Universal Asynchronous Receiver Transmitter
- Serial communication
- Full duplex

## Pins
- RXD = P3.0
- TXD = P3.1

---

# Registers

## SBUF
- Transmit data
- Receive data

```asm
MOV SBUF,#'A'
MOV A,SBUF
```

## SCON

```text
SM0 SM1 SM2 REN TB8 RB8 TI RI
```

- REN → receive enable
- TI → transmit complete
- RI → receive complete

---

# Modes

| Mode | Description |
|--------|--------|
| 0 | Shift register |
| 1 | 8-bit UART, variable baud |
| 2 | 9-bit UART, fixed baud |
| 3 | 9-bit UART, variable baud |

Most used:

```text
Mode 1
```

---

# Transmit

```asm
MOV SBUF,#'A'
JNB TI,$
CLR TI
```

Flow:

```text
Write
→ Send
→ TI=1
→ Clear TI
```

---

# Receive

```asm
SETB REN
JNB RI,$
MOV A,SBUF
CLR RI
```

Flow:

```text
Receive
→ RI=1
→ Read SBUF
→ Clear RI
```

# Baud Rate

Generated using:

```text
Timer1 Mode2
```

## Formula

```text
Baud
=
(2^SMOD × Clock)
/
(384 × (256−TH1))
```

- SMOD in PCON
- SMOD=1 → baud ×2

---

# Numerical

Given:

```text
12 MHz
9600 baud
```

```text
TH1
=
256
-
(12000000/(384×9600))
≈ FDH
```

Answer:

```text
TH1 = FDH
```

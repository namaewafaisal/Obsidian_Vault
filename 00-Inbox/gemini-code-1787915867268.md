## 1. Computer Networks (CN)

### Routers vs Switches vs Hubs
| Feature | Hub | Switch | Router |
| :--- | :--- | :--- | :--- |
| **OSI Layer** | Layer 1 (Physical) | Layer 2 (Data Link) | Layer 3 (Network) |
| **Operation** | Broadcasts incoming frames to **all** connected ports. | Forwards data frames selectively to destination using **MAC tables**. | Routes data packets between **different networks** using **IP addresses**. |
| **Traffic Filtering** | None (High collision domain). | Filters per MAC address. | Filters and routes based on network address ranges. |
| **Primary Domain** | Local Segment | Local Area Network (LAN) | Inter-network / Internet (WAN) |

### Routing & Routing Tables
- **Routing:** The process of determining optimal path traversal across multiple intermediate nodes across networks[cite: 1].
- **Routing Table:** A stored lookup database inside a router containing network IP route configurations[cite: 1]:
  - *Destination Subnet Mask*[cite: 1]
  - *Next Hop / Gateway IP Address*[cite: 1]
  - *Network Interface*[cite: 1]
  - *Metric / Cost*[cite: 1]

### NAT (Network Address Translation)
- **Purpose:** Maps multiple private IP addresses within a local network to a single public IP address when accessing external networks[cite: 1].
- **Why We Need It:**[cite: 1]
  1. Conserves limited public IPv4 address pool[cite: 1].
  2. Hides internal network infrastructure, providing security defense against unauthorized external sweeps[cite: 1].

### Firewalls
A security platform (software or hardware device) that monitors and filters incoming and outgoing network traffic according to predefined security policy rules[cite: 1].
- Acts as a barrier between a trusted internal network and an untrusted external network (Internet)[cite: 1].

### Congestion Control (Basic Concept)
When network traffic load exceeds available link bandwidth capacity, performance degrades (packet drop, delays)[cite: 1].
- **Congestion Control:** Mechanisms enforced at the Transport Layer (TCP) to dynamically limit data transmission speed across network paths[cite: 1].
- Uses sender sliding window constraints, packet drop loss detection, and rate adjustments[cite: 1].

### Application Layer Protocols
- **HTTP (HyperText Transfer Protocol):** Facilitates web document requests and responses between web client browsers and web server nodes[cite: 1].
- **FTP (File Transfer Protocol):** Transfers bulk binary and text computer files across network connections. Uses separate control and data connections[cite: 1].
- **SMTP (Simple Mail Transfer Protocol):** Text-based protocol for sending and pushing outgoing email messages between mail servers[cite: 1].

## 2. Database Management Systems (DBMS)

### Indexing
An Index is a specialized data structure (typically a B-Tree or Hash Table) that speeds up data retrieval operations on a database table at the cost of additional write overhead and storage space[cite: 1].
- **How It Works:** Rather than performing full table scans $O(N)$, index structures allow log-time lookups $O(\log N)$[cite: 1].
- **Trade-off:** Slows down `INSERT`, `UPDATE`, and `DELETE` queries because the database must update index entries alongside table rows[cite: 1].

### Transactions: Commit & Rollback
A **Transaction** is a logical unit of execution containing one or more SQL statements[cite: 1].
- `COMMIT;` — Saves all transactional updates permanently to the database[cite: 1].
- `ROLLBACK;` — Reverts all transaction updates back to the state prior to transaction initiation if an error occurs[cite: 1].

### SQL GROUP BY, HAVING & Aggregates
- **Aggregate Functions:** Perform calculation operations across sets of values (`COUNT()`, `SUM()`, `AVG()`, `MAX()`, `MIN()`)[cite: 1].
- `GROUP BY`: Summarizes identical data groups into single output rows[cite: 1].
- `HAVING`: Filters summarized groups *after* aggregation (unlike `WHERE`, which filters individual rows *before* aggregation)[cite: 1].

```sql
SELECT department_id, AVG(salary) AS avg_sal
FROM employees
WHERE status = 'ACTIVE'
GROUP BY department_id
HAVING AVG(salary) > 50000;
```

### Basic Constraints
- `NOT NULL` — Ensures column cannot store NULL values[cite: 1].
- `UNIQUE` — Enforces all values in a column to be distinct[cite: 1].
- `CHECK` — Verifies column values satisfy specific logical expressions (e.g., `CHECK (age >= 18)`)[cite: 1].

### Stored Procedures
A set of pre-compiled SQL statements saved inside the database management system[cite: 1].
- **Benefits:** Reduces network bandwidth usage (single execution command), improves security through access permission isolation, and speeds up execution via compiled query execution plans[cite: 1].

## 3. Operating Systems (OS)

### Semaphores vs Mutex
| Feature | Mutex (Mutual Exclusion Object) | Semaphore |
| :--- | :--- | :--- |
| **Type** | Locking Mechanism | Signaling Mechanism |
| **Capacity** | Single resource unit limit ($1$). | Integer counter representing $N$ available units. |
| **Ownership** | Locked and unlocked **only** by the owning thread. | Any thread can signal (`signal() / V()`) or wait (`wait() / P()`). |
| **Types** | Binary. | Binary Semaphore ($0/1$) or Counting Semaphore ($N$). |

### Context Switching
The procedure performed by the OS CPU scheduler when switching the execution core from one process/thread to another[cite: 1].
- Steps: Stores execution state (registers, program counter, stack pointer) into the **Process Control Block (PCB)** of current process, and restores saved context state of target process[cite: 1].
- *Note:* Context switching introduces computational overhead where CPU works without advancing application logic[cite: 1].

### Multithreading vs Multiprocessing
- **Multithreading:** Executing multiple threads within a single process address space. Light weight, shares RAM, fast inter-thread communication, but single thread crash can destabilize whole process[cite: 1].
- **Multiprocessing:** Executing multiple concurrent CPU processes on multiple CPU cores. Higher memory overhead, isolated memory address spaces, strong failure isolation[cite: 1].

### Page Replacement Algorithms
When physical memory frames fill up and a page fault occurs, OS replaces an existing page frame in RAM[cite: 1]:
- **FIFO (First In, First Out):** Evicts oldest loaded page. Simple, but vulnerable to Belady's Anomaly (increasing RAM frames can increase page fault rate)[cite: 1].
- **LRU (Least Recently Used):** Evicts page that hasn't been accessed for the longest duration. Uses past access history to approximate future utility. Efficient and widely used[cite: 1].

### Memory Fragmentation
Inefficient memory utilization that occurs as processes are loaded and freed from memory[cite: 1]:
- **Internal Fragmentation:** Occurs when fixed-size memory blocks allocated to a process are larger than requested. The unused portion inside the block is wasted[cite: 1].
- **External Fragmentation:** Total free memory space across the system is sufficient to satisfy an allocation request, but it exists in small, non-contiguous holes[cite: 1].

## 4. Object-Oriented Programming (OOPs)

### Access Modifiers
Visibility access scopes assigned to classes, fields, and methods[cite: 1]:

| Modifier | Access within Class | Access in Subclasses (Same Package) | Access in Subclasses (Diff Package) | World / Global Access |
| :--- | :--- | :--- | :--- | :--- |
| `private` | **Yes** | No | No | No |
| `default` (package) | **Yes** | **Yes** | No | No |
| `protected` | **Yes** | **Yes** | **Yes** | No |
| `public` | **Yes** | **Yes** | **Yes** | **Yes** |

### Interface vs Abstract Class
| Feature | Abstract Class | Interface |
| :--- | :--- | :--- |
| **Inheritance** | Single class inheritance (`extends`). | Multiple interface implementation (`implements`). |
| **State/Fields** | Can declare instance variables and constructor state. | Constants only (`public static final`). |
| **Method Types** | Can contain abstract and fully implemented concrete methods. | Abstract methods, plus default/static methods in modern Java. |
| **Design Intent** | "Is-A" relationship sharing structural core state. | "Can-Do" behavioral contract binding across unrelated classes. |

### `this` and `super` Keywords
- `this`: References current active object instance executing the method or constructor[cite: 1].
  - Used to resolve variable shadow conflicts between fields and local method parameters (`this.id = id`)[cite: 1].
- `super`: References immediate parent base class instance[cite: 1].
  - Used to invoke overridden parent methods (`super.makeSound()`) or parent class constructors (`super(name)`)[cite: 1].

### Static vs Instance Members
- **Static Members (`static` keyword):** Belong directly to the **Class** itself, shared globally across all instance objects. Allocated once in memory when class loads. Accessed without creating object instance (`Math.abs()`)[cite: 1].
- **Instance Members:** Belong strictly to individual **Object instances**. Each instantiated object maintains its own isolated copy in memory[cite: 1].

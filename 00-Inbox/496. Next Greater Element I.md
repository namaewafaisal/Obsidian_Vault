# 496. Next Greater Element I

## Problem (LeetCode Statement)

**Input:**  
- Integer arrays `nums1` and `nums2`

**Output:**  
- For each element in `nums1`, find the next greater element in `nums2`  
- If none exists → `-1`

**Task:**  
For each number in `nums1`, find the first greater number to its right in `nums2`

---

## Constraints

- nums1 is a subset of nums2
- Must be O(n + m)
- Brute force O(n²) too slow

---

## Examples

```
Input:  nums1 = [4,1,2], nums2 = [1,3,4,2]
Output: [-1,3,-1]
```

---

## What Actually Matters

- This is a **next greater element problem**
- Searching to the right → stack problem
- nums1 only queries → nums2 drives computation
- Need fast lookup → hashmap

---

## Core Insight

> Precompute next greater elements using a monotonic stack, then map answers

---

## Invariant / Mental Model

> Stack stores elements in **decreasing order**
- Top = next greater candidate
- Smaller elements are useless → pop them

---

## Thinking Log (Your Style)

- Initial Thought:  
  For each element, scan right

- Issue:  
  O(n²)

- Realization:  
  Use stack to avoid re-checking

- Key Insight:  
  Process from right → left

- Final Understanding:  
  Use stack + map for quick lookup

---

## Algorithm (High Level)

1. Map nums1 values → their indices
2. Traverse nums2 from right → left:
   - Remove smaller elements from stack
   - If current element is in nums1:
     - assign next greater (top or -1)
3. Push current element into stack
4. Return result

---

## Code (Reference Only)

```java
class Solution {
    public int[] nextGreaterElement(int[] nums1, int[] nums2) {
        Stack<Integer> stack = new Stack<>();
        Map<Integer, Integer> map = new HashMap<>();
        int res[] = new int[nums1.length];

        for(int i = 0; i < nums1.length; i++) {
            map.put(nums1[i], i);
        }

        for(int i = nums2.length - 1; i >= 0; i--) {
            while(!stack.isEmpty() && stack.peek() <= nums2[i]) {
                stack.pop();
            }

            if(map.containsKey(nums2[i])) {
                res[map.get(nums2[i])] = stack.isEmpty() ? -1 : stack.peek();
            }

            stack.push(nums2[i]);
        }

        return res;
    }
}
```

## Edge Cases to Recall

- No greater element → -1
- Strictly decreasing array → all -1
- Single element

## One-Line Recall

> Use monotonic stack on nums2 and map results for nums1

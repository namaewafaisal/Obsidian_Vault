# Addressing Modes

## Purpose
- Defines how operand is specified
- Tells CPU where data comes from
- Operand can be:
  - Constant
  - Register
  - Memory location
  - Address stored in register
  - Program memory table

---

# Immediate Addressing

## Syntax
```asm
MOV A,#55H
```

## Meaning
- `#` → literal value
- Data present inside instruction

Result:
```text
A = 55H
```

## Example
```asm
MOV A,#30H
```

Result:
```text
A = 30H
```

## Features
- Fast
- No memory lookup
- Constant loading

---

# Register Addressing

## Syntax
```asm
MOV A,R2
```

## Meaning
- Copy data from register

Example:
```asm
MOV R2,#40H
MOV A,R2
```

Result:
```text
A = 40H
```

## Features
- Fastest practical data access
- Uses CPU registers directly

---

# Direct Addressing

## Syntax
```asm
MOV A,30H
```

## Meaning
- Operand = memory address
- CPU accesses specified address directly

Example:
```text
RAM[30H] = 77H
```

Instruction:
```asm
MOV A,30H
```

Result:
```text
A = 77H
```

## Can Access
- Internal RAM
- SFRs

Example:
```asm
MOV A,P1
```

---

# Immediate vs Direct

## Immediate
```asm
MOV A,#30H
```

Meaning:
```text
A = 30H
```

## Direct
```asm
MOV A,30H
```

Meaning:
```text
A = contents of RAM[30H]
```

Important:
- `#` changes entire meaning

---

# Register Indirect Addressing

## Syntax
```asm
MOV A,@R0
```

## Meaning
- Register stores address
- `@` = indirect access

Example:
```asm
MOV R0,#30H
MOV A,@R0
```

If:
```text
RAM[30H] = 88H
```

Result:
```text
A = 88H
```

## Flow
```text
R0
 ↓
30H
 ↓
RAM[30H]
 ↓
Data
 ↓
A
```

## Features
- Pointer-like behavior
- Useful for:
  - Arrays
  - Buffers
  - Strings
  - Loops

## Allowed Registers
```text
R0
R1
```

Only R0 and R1 support register-indirect RAM access.

---

# Indexed Addressing

## Syntax
```asm
MOVC A,@A+DPTR
```

## Purpose
- Read from program memory (ROM)
- Lookup tables

## MOVC
```text
Move from Code memory
```

## Address Calculation
```text
Final Address
=
DPTR + A
```

Example:
```text
DPTR = 1000H
A    = 03H
```

Final Address:
```text
1003H
```

CPU reads:
```text
ROM[1003H]
```

Result loaded into:
```text
A
```

## Used For
- 7-segment tables
- Character tables
- LCD fonts
- Lookup tables
- Protocol tables

## Concept
```text
Base Address + Index
```

Equivalent idea:
```java
array[index]
```

# Additional Addressing Modes

## Implied Addressing

Example:
```asm
CLR A
CPL A
RL A
```

Meaning:
- Operand already known
- No explicit operand needed

Example:
```asm
CLR A
```

CPU automatically uses:
```text
A
```

---

## Relative Addressing

Used in:
```asm
SJMP LABEL
```

Features:
- Target calculated relative to current PC
- Mainly used in branching instructions

---

## Absolute / Long Addressing

Used in:
```asm
AJMP
ACALL
LJMP
LCALL
```

Purpose:
- Program control transfer
- Jump/call instructions

# Quick Summary Table

| Mode | Example | Meaning |
|--------|--------|--------|
| Immediate | `MOV A,#55H` | Literal value |
| Register | `MOV A,R2` | Data in register |
| Direct | `MOV A,30H` | Address specified directly |
| Indirect | `MOV A,@R0` | Address stored in register |
| Indexed | `MOVC A,@A+DPTR` | Base + index ROM access |
| Implied | `CLR A` | Operand built into instruction |
| Relative | `SJMP LABEL` | Address relative to PC |
| Absolute/Long | `AJMP`, `LJMP` | Program jump/call addressing |

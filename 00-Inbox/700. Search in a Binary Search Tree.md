# 700. Search in a Binary Search Tree

## Problem

**Input:**
- Root of a Binary Search Tree
- Integer `val`

**Output:**
- The subtree rooted at the node with value `val`
- Return `null` if it does not exist

```
Input:  root = [4,2,7,1,3], val = 2
Output: [2,1,3]
```

---

## Pattern

**Binary Search on BST**

---

## Core Idea

- If current node equals `val`, return it.
- If `val` is larger, search the right subtree.
- If `val` is smaller, search the left subtree.
- Ignore half the tree at every step using the BST property.

---

## Dry Run

```
        4
      /   \
     2     7
    / \
   1   3

Search 2

4 > 2 → go left
2 == 2 → return subtree rooted at 2
```

---

## Code

```java
class Solution {
    public TreeNode searchBST(TreeNode root, int val) {
        if(root == null){
            return null;
        }

        if(root.val == val){
            return root;
        }

        TreeNode result;

        if(root.val < val){
            result = searchBST(root.right, val);
        } else {
            result = searchBST(root.left, val);
        }

        return result;
    }
}
```

---

## One-Line Recall

> Compare with the current node and recursively search only the side where the value can exist.

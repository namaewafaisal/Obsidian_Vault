# 2261. K Divisible Elements Subarrays

## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`  
- Integer `k`  
- Integer `p`

**Output:**  
- Number of **distinct subarrays** where at most `k` elements are divisible by `p`

**Task:**  
Count unique subarrays such that:
- Number of elements divisible by `p` ≤ `k`

---

## Constraints

- Must consider all subarrays
- Need uniqueness → hashing
- Brute force allowed but must avoid duplicates

---

## Examples

```
Input:  nums = [2,3,3,2,2], k = 2, p = 2
Output: 11
```

---

## What Actually Matters

- You must consider **all subarrays**
- But only keep those with ≤ k divisible elements
- Subarrays must be **distinct**
- Need structure to store uniqueness → Set

---

## Core Insight

> Generate all valid subarrays and store them uniquely using a set

---

## Invariant / Mental Model

> While expanding subarray:
- Track how many elements divisible by `p`
- Stop expanding when count > k

---

## Thinking Log (Your Style)

- Initial Thought:  
  Generate all subarrays

- Issue:  
  Duplicate subarrays possible

- Realization:  
  Need to store unique ones

- Key Insight:  
  Use StringBuilder to represent subarray

- Final Understanding:  
  Use set + early break when constraint fails

---

## Algorithm (High Level)

1. For each start index `i`
2. Expand `j` from `i → n`
3. Track count of elements divisible by `p`
4. If count > k → break
5. Add subarray representation to set
6. Return set size

---

## Code (Reference Only)

```java
class Solution {
    public int countDistinct(int[] nums, int k, int p) {
        int res = 0;
        int n = nums.length;
        Set<String> set = new HashSet<>();

        for(int i = 0; i < n; i++) {
            StringBuilder sb = new StringBuilder();
            int count = 0;

            for(int j = i; j < n; j++) {
                if(nums[j] % p == 0) count++;

                if(count > k) break;

                sb.append(nums[j]).append(",");
                set.add(sb.toString());
            }
        }

        return set.size();
    }
}
```

---

## ⚠️ Important Detail

```java
sb.append(nums[j]).append(",");
```

👉 Comma is critical  
Otherwise:
```
[1,11] and [11,1] → ambiguous
```

---

## Edge Cases to Recall

- k = 0 → no divisible elements allowed
- All elements divisible → small subarrays only
- All elements non-divisible → all subarrays valid

---

## Complexity

- Time: O(n²)
- Space: O(n²) (set storage)

---

## One-Line Recall

> Expand all subarrays, stop when divisible count exceeds k, store unique ones using set

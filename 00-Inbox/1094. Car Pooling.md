# 1094. Car Pooling

## Problem (LeetCode Statement)

**Input:**  
- `trips[i] = [numPassengers, from, to]`  
- Integer `capacity`

**Output:**  
- `true` if all trips can be completed without exceeding capacity  
- else `false`

**Task:**  
Simulate picking up and dropping passengers along a route and ensure capacity is never exceeded

---

## Constraints

- Locations range from 0 → 1000
- Must be efficient → avoid simulating each trip separately
- Prefer O(n + range)

---

## Examples

```
Input:  trips = [[2,1,5],[3,3,7]], capacity = 4
Output: false
```

```
Input:  trips = [[2,1,5],[3,3,7]], capacity = 5
Output: true
```

---

## What Actually Matters

- We don’t need exact simulation per trip
- Only need **net passenger change at each location**
- Overlapping intervals cause capacity issues
- Order of events matters → process in location order

---

## Core Insight

> Use a difference array to track passenger changes at each location

---

## Invariant / Mental Model

> At any point:
- `count` = current passengers in car  
- Must always satisfy: `count ≤ capacity`

---

## Thinking Log (Your Style)

- Initial Thought:  
  Simulate each trip and track passengers

- Issue:  
  Overlapping trips → complex and inefficient

- Realization:  
  Only care about changes at points

- Key Insight:  
  Add at pickup, subtract at drop

- Final Understanding:  
  Prefix sum over difference array gives current passengers

---

## Algorithm (High Level)

1. Create array of size 1001 (location range)
2. For each trip:
   - Add passengers at start index
   - Subtract at end index
3. Traverse array:
   - Maintain running sum
   - If exceeds capacity → return false
4. Return true

---

## Code (Reference Only)

```java
class Solution {
    public boolean carPooling(int[][] trips, int capacity) {
        int[] arr = new int[1001];

        for(int[] trip : trips) {
            arr[trip[1]] += trip[0];
            arr[trip[2]] += -trip[0];
        }

        int count = 0;

        for(int i : arr) {
            count += i;
            if(count > capacity) {
                return false;
            }
        }

        return true;
    }
}
```

---

## Edge Cases to Recall

- Trips that start and end at same point
- Capacity exactly met
- Large overlaps

---

## One-Line Recall

> Use difference array + prefix sum to track passenger count across locations

# 1819. Number of Different Subsequences GCDs

## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`

**Output:**  
- Number of distinct GCD values obtainable from any non-empty subsequence

**Task:**  
Find how many unique GCDs can be formed using any subsequence of `nums`

---

## Constraints

- `nums.length` can be large → cannot generate subsequences
- Values bounded → can iterate over range
- Brute force subsequences = exponential → impossible

---

## Examples

```
Input:  [6,10,3]
Output: 5
Explanation: Possible GCDs → {1,2,3,5,6}
```

---

## What Actually Matters

- We are NOT generating subsequences
- We only care about **possible GCD values**
- GCD reduces values → structure is based on divisibility
- Numbers contributing to a GCD must be **multiples of that GCD**

---

## Core Insight

> Instead of building subsequences, fix a GCD `g` and check if it can be formed using multiples of `g`

---

## Invariant / Mental Model

> If we take all numbers that are multiples of `g` and compute their GCD:
- If result becomes `g` → then `g` is achievable
- Else → not possible

So:
```text
g is valid ⇔ gcd(all multiples of g present in nums) == g
```

---

## Thinking Log (Your Style)

- Initial Thought:  
  Try all subsequences and compute GCD

- Issue:  
  Exponential → impossible

- Better Thought:  
  Instead of building subsequences, think from GCD side

- Key Realization:  
  Any number contributing to GCD `g` must be a multiple of `g`

- Jump:  
  So iterate `g = 1 → max`, and collect multiples

- Final Understanding:  
  Keep taking GCD of multiples → if it reduces exactly to `g`, it's valid

---

## Algorithm (High Level)

1. Find max value in array
2. Mark presence of numbers
3. For each `g` from `1 → max`:
   - Initialize `currGcd = 0`
   - Iterate multiples of `g`
   - If present → update GCD
4. If `currGcd == g` → count++

---

## Code (Reference Only)

```java
class Solution {
    public int countDifferentSubsequenceGCDs(int[] nums) {
        
        int max = 0;
        for (int i = 0; i < nums.length; i++) {
            max = Math.max(max, nums[i]);
        }

        boolean[] present = new boolean[max + 1];
        for (int x : nums) {
            present[x] = true;
        }

        int count = 0;

        for (int g = 1; g <= max; g++) {
            int currGcd = 0;

            for (int multiple = g; multiple <= max; multiple += g) {
                if (present[multiple]) {
                    currGcd = gcd(currGcd, multiple);
                }
            }

            if (currGcd == g) {
                count++;
            }
        }
        return count;
    }

    public int gcd(int a, int b) {
        while(b!=0) {
            int t = a;
            a = b;
            b = t % b;
        }
    }
}
```

## Edge Cases to Recall

- Single element array
- All numbers same
- Prime numbers → fewer GCDs
- Presence of 1 → guarantees GCD 1

---

## One-Line Recall

> Fix a GCD `g`, take all its multiples in the array, and if their GCD becomes `g`, then `g` is achievable

# 8.3 — Cost Estimation

Cost Estimation:
> predicting effort, time, and money required for a software project.

Goal:
> estimate project resources before development begins.

---

# Main Factors Affecting Cost

| Factor | Effect |
|---|---|
| Project Size | Larger systems cost more |
| Complexity | Complex systems need more effort |
| Team Experience | Experienced teams work faster |
| Technology | New tech may increase learning cost |
| Time Constraints | Tight deadlines increase cost |

---

# Estimation Components

```text
Effort
→ Time
→ Cost
```

---

# Effort Estimation

Measures:
> amount of work required

Units:
- person-hours
- person-days
- person-months

Example:

```text
5 developers × 2 months
= 10 person-months
```

---

# Time Estimation

Predicts:
> project duration/schedule

Depends on:
- effort
- team size
- dependencies

---

# Cost Estimation

Calculates:
- salaries
- infrastructure
- tools/licenses
- cloud services
- maintenance costs

---

# Estimation Techniques

| Technique | Idea |
|---|---|
| Expert Judgment | Experienced estimation |
| Analogous Estimation | Compare with previous projects |
| Decomposition/WBS | Estimate smaller tasks separately |
| Algorithmic Models | Mathematical formulas |

---

# Expert Judgment

Experienced developers/managers estimate effort.

Fast but experience-dependent.

---

# Analogous Estimation

Compare with similar previous project.

Example:

```text
Previous chat app:
3 months

Current similar app:
≈ 3–4 months
```

---

# Decomposition / WBS Estimation

Break project into smaller tasks.

Example:

```text
Backend API → 2 weeks
Frontend UI → 3 weeks
Testing → 1 week
```

Usually more accurate.

---

# Algorithmic Models

Use mathematical formulas.

Most common:
> COCOMO

---

# COCOMO

Constructive Cost Model.

Estimates:
- effort
- time
- cost

based on:
- project size (KLOC)

---

# Common Estimation Mistakes

- underestimation
- ignoring testing/debugging effort
- ignoring risks
- unrealistic deadlines

---

# Cone of Uncertainty

Early project estimates are:
> less accurate

Accuracy improves as project progresses.

---

# Important Insight

Cost Estimation predicts:
> effort, schedule, and budget before development begins

# Memory Interfacing

## Why External Memory

Internal memory:

```text
ROM = 4 KB
RAM = 128 B
```

Not enough for real systems.

Used for:
- Larger programs
- Buffers
- Tables
- Sensor data

---

# External Memory Space

| Memory | Size |
|----------|----------|
| Program Memory | 64 KB |
| Data Memory | 64 KB |

Program Memory:
```text
Code storage
```

Data Memory:
```text
Variables
Buffers
Runtime data
```

---

# Control Signals

| Signal | Purpose |
|----------|----------|
| PSEN | External ROM read |
| RD | External RAM read |
| WR | External RAM write |

---

# Address Bus

## P0

```text
A0–A7
+
D0–D7
```

Low address + data bus.

Called:

```text
Multiplexed Bus
```

---

## P2

```text
A8–A15
```

High address bus.

---

# ALE

```text
Address Latch Enable
```

Purpose:

```text
Separate address
from data
```

Flow:

```text
P0 outputs address
↓
ALE pulse
↓
Latch stores address
↓
P0 becomes data bus
```

---

# 74HC373

Purpose:

```text
Store A0–A7
```

Temporary address latch.

---

# Address Range

```text
16-bit address bus
```

Range:

```text
0000H → FFFFH
```

```text
64 KB
```

---

# Memory-Mapped I/O

Concept:

```text
Device assigned
memory address
```

Example:

```text
8000H → LCD
9000H → ADC
```

Accessed like memory.

Instruction:

```asm
MOVX A,@DPTR
MOVX @DPTR,A
```

---

# MOVX

```text
Move External Data
```

Used for:
- External RAM
- Memory-mapped devices

---

## Data Memory

---

# Address Decoder

Purpose:

```text
Select memory chip
based on address
```

Example:

```text
0000–7FFF → ROM
8000–FFFF → RAM
```

## External ROM

```text

↓
PSEN

```

## External RAM

```text

↓
```

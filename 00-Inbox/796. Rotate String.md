# 796. Rotate String

## Problem

**Input:**
- Two strings `s` and `goal`

**Output:**
- `true` if `goal` can be obtained by rotating `s`
- Otherwise `false`

```
Input:  s = "abcde", goal = "cdeab"
Output: true
```

```
Input:  s = "abcde", goal = "abced"
Output: false
```

---

## Pattern

**Circular Traversal + String Matching**

---

## Core Idea

- Every index of `s` is a possible rotation starting point.
- For each starting index:
  - Compare characters with `goal`.
  - Move through `s` circularly using modulo.
- If all characters match for any starting point, return `true`.

## Code

```java
class Solution {
    public boolean rotateString(String s, String goal) {

        if(s.length() != goal.length()) {
            return false;
        }

        int n = s.length();

        for(int i = 0; i < n; i++) {

            int index = i;
            int goalIndex = 0;

            while(goalIndex < n &&
                  s.charAt(index) == goal.charAt(goalIndex)) {

                index = (index + 1) % n;
                goalIndex++;
            }

            if(goalIndex == n)
                return true;
        }

        return false;
    }
}
```

---

## Things to Remember

- Check lengths first.
- `% n` wraps around to simulate rotation.
- Every index is treated as a possible starting point.
- **Better approach:** Check if `goal` is a substring of `s + s` in `O(n)` time.

```java
return s.length() == goal.length() && (s + s).contains(goal);
```

---

## One-Line Recall

> Try every index as the rotation start and compare circularly using modulo until a full match is found.

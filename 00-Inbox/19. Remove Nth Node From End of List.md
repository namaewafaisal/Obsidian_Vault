# 19. Remove Nth Node From End of List

## Problem

Given the head of a linked list, remove the `n`-th node from the end and return the modified list.

**Example:**

```
Input:  head = [1,2,3,4,5], n = 2
Output: [1,2,3,5]
```

---

## Pattern

**Two Pointers + Dummy Node**

## Core Idea

- Create a dummy node pointing to `head`.
- Use `fast` to calculate the list length.
- Move `slow` to the node immediately before the node to delete.
- Update `slow.next` to skip the target node.
- Return `temp.next` because the original head itself might have been deleted.

**Key calculation:**

\[
\text{slow moves} = \text{length} - n
\]

---

## Dry Run

### Case 1: Remove the 2nd node from the end

```
List:
dummy → 1 → 2 → 3 → 4 → 5 → null
```

**Step 1 — Calculate length**

`fast` traverses the list.

```
length = 5
```

**Step 2 — Move slow**

```
length - n = 5 - 2 = 3 moves
```

Initially:

```
slow = dummy
```

After 3 moves:

```
dummy → 1 → 2 → 3 → 4 → 5
                    ↑
                   slow
```

**Step 3 — Delete the target node**

```java
slow.next = slow.next.next;
```

Node `4` is skipped.

```
dummy → 1 → 2 → 3 → 5 → null
```

**Result:**

```
[1,2,3,5]
```

### Case 2: Remove the head

```
head = [1,2,3]
n = 3

length = 3
length - n = 0
```

`slow` stays at the dummy node.

```java
slow.next = slow.next.next;
```

The dummy now points to node `2`.

```
Result = [2,3]
```

---

## Code

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode temp = new ListNode();
        temp.next = head;

        ListNode fast = temp;
        ListNode slow = temp;

        int length = 0;

        while(fast.next != null) {
            fast = fast.next;
            length++;
        }

        for(int i = 0; i < length - n; i++) {
            slow = slow.next;
        }

        slow.next = slow.next.next;

        return temp.next;
    }
}
```

---

## Things to Remember

- Dummy nodes simplify deletion, especially when the head needs to be removed.
- `slow` must stop **one node before** the target.
- `length - n` gives the exact number of movements from the dummy node.
- `slow.next = slow.next.next` removes a node without manually changing pointers elsewhere.
- Time complexity: \(O(n)\) — one traversal to calculate length and another to locate the deletion point.
- Auxiliary space: \(O(1)\).

### Alternative: One-Pass Two-Pointer Approach

You can also solve this using a fixed gap of `n` nodes between `fast` and `slow`, avoiding the separate length calculation.

## One-Line Recall

> Use a dummy node, calculate the length, move slow `length - n` times, and skip the target node.

# Instruction Categories

## Purpose

| Category | Purpose |
|----------|---------|
| Data Transfer | Move data |
| Arithmetic | Calculations |
| Logical | Bit manipulation |
| Branch/Control | Change program flow |
| Bit Operations | Manipulate individual bits |

---

# Data Transfer Instructions

## MOV
```asm
MOV dest,src
```

Purpose:
- Copy data

Examples:
```asm
MOV A,#55H
MOV A,R0
MOV A,30H
```

---

## MOVX
```asm
MOVX A,@DPTR
MOVX @DPTR,A
```

Purpose:
- Access external RAM

Memory:
```text
External Data Memory
```

---

## MOVC
```asm
MOVC A,@A+DPTR
```

Purpose:
- Access program memory (ROM)
- Lookup tables

Memory:
```text
Code Memory
```

---

## MOV vs MOVX vs MOVC

| Instruction | Memory |
|------------|---------|
| MOV | Internal RAM, SFR, Registers |
| MOVX | External RAM |
| MOVC | Program ROM |

---

## XCH
```asm
XCH A,R0
```

Purpose:
- Exchange values

Example:
```text
Before:
A  = 10H
R0 = 20H

After:
A  = 20H
R0 = 10H
```

---

## XCHD
- Exchange lower nibble only
- Used mainly with BCD data

Nibble:
```text
4 bits
```

---

## PUSH
```asm
PUSH 30H
```

Purpose:
- Push data onto stack
- SP increments

---

## POP
```asm
POP 40H
```

Purpose:
- Pop data from stack
- SP decrements

---

## SWAP
```asm
SWAP A
```

Purpose:
- Swap upper and lower nibble

Example:
```text
ABH → BAH
```

---

# Arithmetic Instructions

## ADD
```asm
ADD A,R1
```

Operation:
```text
A = A + R1
```

---

## ADDC
```asm
ADDC A,R1
```

Operation:
```text
A = A + R1 + Carry
```

Purpose:
- Multi-byte arithmetic
- 16-bit/32-bit addition

---

## SUBB
```asm
SUBB A,R1
```

Operation:
```text
A = A - R1 - Carry
```

Carry acts as:
```text
Borrow
```

---

## MUL AB
```asm
MUL AB
```

Operation:
```text
A × B
```

Result:
```text
BA
```

- B = High byte
- A = Low byte

Example:
```text
20 × 20 = 400
```

---

## DIV AB
```asm
DIV AB
```

Result:
```text
A = Quotient
B = Remainder
```

Example:
```text
20 ÷ 3

A = 6
B = 2
```

---

## INC
```asm
INC A
```

Operation:
```text
A = A + 1
```

---

## DEC
```asm
DEC R0
```

Operation:
```text
R0 = R0 - 1
```

---

## DA A
```asm
DA A
```

Purpose:
- Decimal Adjust Accumulator
- Used after BCD addition

---

# Logical Instructions

## ANL
```asm
ANL A,#0FH
```

Operation:
```text
AND
```

Purpose:
- Masking bits

---

## ORL
```asm
ORL A,#01H
```

Operation:
```text
OR
```

Purpose:
- Set bits

---

## XRL
```asm
XRL A,#FFH
```

Operation:
```text
XOR
```

Purpose:
- Toggle bits
- Invert all bits using FFH

---

## CLR
```asm
CLR A
CLR C
```

Purpose:
- Clear accumulator
- Clear carry
- Clear bit

---

## CPL
```asm
CPL A
CPL P1.0
```

Purpose:
- Complement / invert

---

# Rotate Instructions

## RL

```asm
RL A
```

Purpose:
- Rotate left

---

## RR
```asm
RR A
```

Purpose:
- Rotate right

---

## RLC
```asm
RLC A
```

Purpose:
- Rotate left through carry

Concept:
```text
8 bits + Carry
```

---

## RRC
```asm
RRC A
```

Purpose:
- Rotate right through carry

---

# Branch / Control Instructions

## Unconditional Jumps

### LJMP
```asm
LJMP LABEL
```

- Long jump
- Anywhere in 64KB code space

---

### SJMP
```asm
SJMP LABEL
```

Range:
```text
-128 to +127 bytes
```

Relative jump

---

### AJMP
```asm
AJMP LABEL
```

- Jump within same 2KB page
- Smaller instruction

---

# Subroutine Instructions

## LCALL
```asm
LCALL SUB
```

- Call subroutine
- Return address pushed to stack

---

## ACALL
```asm
ACALL SUB
```

- Call within same 2KB page
- Smaller instruction

---

## RET
```asm
RET
```

- Return from subroutine

---

## RETI
```asm
RETI
```

- Return from interrupt
- Signals interrupt completion

---

# Conditional Instructions

## JZ
```asm
JZ LABEL
```

Condition:
```text
A == 0
```

---

## JNZ
```asm
JNZ LABEL
```

Condition:
```text
A != 0
```

---

## JC
```asm
JC LABEL
```

Condition:
```text
Carry = 1
```

---

## JNC
```asm
JNC LABEL
```

Condition:
```text
Carry = 0
```

---

## JB
```asm
JB bit,LABEL
```

Condition:
```text
Bit = 1
```

---

## JNB
```asm
JNB bit,LABEL
```

Condition:
```text
Bit = 0
```

---

## JBC
```asm
JBC bit,LABEL
```

Action:
- Jump if bit = 1
- Clear bit automatically

Useful for:
```text
Event flags
```

---

## CJNE
```asm
CJNE A,#10H,LABEL
```

Meaning:
```text
Compare and Jump if Not Equal
```

Important:
- Does not modify operands

---

## DJNZ
```asm
DJNZ R7,LABEL
```

Meaning:
```text
Decrement
+
Jump if Not Zero
```

Operation:
```text
R7 = R7 - 1

If R7 != 0
Jump
```

---

## Why DJNZ Is Important

Without DJNZ:
```asm
DEC R7
JNZ LOOP
```

With DJNZ:
```asm
DJNZ R7,LOOP
```

Combines:
```text
DEC + JNZ
```

Used heavily for:
- Loops
- Delays
- Counters

Example:
```asm
MOV R7,#10

LOOP:
...
DJNZ R7,LOOP
```

# Numerical: Add Two 8-bit Numbers

Problem:
```text
30H = Number1
31H = Number2

32H = Sum
33H = Carry
```

Program:
```asm
MOV A,30H
ADD A,31H
MOV 32H,A

CLR A
ADDC A,#00H
MOV 33H,A
```

Example:
```text
30H = FFH
31H = 02H
```

Result:
```text
32H = 01H
33H = 01H
```

# 63. Unique Paths II

## Problem

Given an `m x n` grid containing obstacles:

- `0` represents an empty cell.
- `1` represents an obstacle.

Find the number of unique paths from the top-left cell to the bottom-right cell.

You can only move **right or down**.

**Example:**

```
Input:
[
  [0,0,0],
  [0,1,0],
  [0,0,0]
]

Output: 2
```

---

## Pattern

**2D DP + Tabulation**

## Core Idea

- `dp[i][j]` represents the number of ways to reach cell `(i,j)`.
- A cell can be reached from:
  - Above: `dp[i-1][j]`
  - Left: `dp[i][j-1]`
- If the current cell is an obstacle, the number of ways is `0`.
- Otherwise, add the ways from above and left.

**Recurrence:**

\[
dp[i][j] =
\begin{cases}
0 & \text{if obstacle}\\
dp[i-1][j]+dp[i][j-1] & \text{otherwise}
\end{cases}
\]

---

## Dry Run

### Input

```
0 0 0
0 1 0
0 0 0
```

Your DP uses an extra row and column to simplify boundary handling.

**Initialization:**

```
dp[0][1] = 1
```

All other cells initially contain `0`.

**Step 1 — First row**

```
1 1 1
```

The only way to reach each cell is from the left.

**Step 2 — Second row**

- `(2,1)` receives `1` way from above.
- `(2,2)` is an obstacle → `0`.
- `(2,3)` receives `0` ways.

**Step 3 — Third row**

- `(3,1)` receives `1` way from above.
- `(3,2)` receives `1` way from above.
- `(3,3)` receives `1 + 0 = 1` way from above and left.

**Final DP table:**

```
0 1 1 1
0 1 0 0
0 1 1 1
0 1 2 2
```

<text color="success" weight="medium" size="sm">Answer = 2</text>

## Code

```java
class Solution {
    public int uniquePathsWithObstacles(int[][] obstacleGrid) {
        int m = obstacleGrid.length;
        int n = obstacleGrid[0].length;

        int[][] dp = new int[m + 1][n + 1];

        dp[0][1] = 1;

        for(int i = 1; i <= m; i++) {
            for(int j = 1; j <= n; j++) {
                if(obstacleGrid[i - 1][j - 1] == 1) {
                    dp[i][j] = 0;
                }
                else {
                    dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
                }
            }
        }

        return dp[m][n];
    }
}
```

---

## Things to Remember

- Extra row and column avoid separate boundary checks.
- `dp[0][1] = 1` acts as a virtual starting point, allowing the actual starting cell to receive one path.
- Obstacles block all paths through that cell.
- If the starting cell is an obstacle, its DP value becomes `0`.
- If the destination is an obstacle, the answer is `0`.
- Time complexity: \(O(mn)\).
- Space complexity: \(O(mn)\).

## One-Line Recall

> Each cell's path count is the sum of the paths from above and left; obstacles reset the count to zero.

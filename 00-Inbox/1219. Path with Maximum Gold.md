# 1219. Path with Maximum Gold

## Problem

Given an `m x n` grid where each cell contains gold (`0` means no gold), find the maximum gold you can collect.

- Start from any cell containing gold.
- Move up, down, left, or right.
- Visit each cell at most once.
- Stop whenever you want.

**Example:**

```
grid =
[
  [0,6,0],
  [5,8,7],
  [0,9,0]
]

Output: 24
```

One optimal path is `9 → 8 → 7`, collecting `24` gold.

---

## Pattern

**Backtracking + DFS + Maximum Path**

## Core Idea

- Start DFS from every cell.
- If a cell is out of bounds, contains `0`, or is already visited, return `0`.
- Mark the current cell as visited.
- Explore all four directions and find the maximum gold obtainable from any direction.
- Unmark the cell so it can be reused in other paths.
- Return the current cell's gold plus the best continuation.

The key is that `vis` tracks cells used in the **current path**, not cells visited globally.

---

## Dry Run

### Case 1: Maximum gold path

```
grid:
0 6 0
5 8 7
0 9 0
```

Start at cell `9`:

1. Collect `9`.
2. Move up to `8`: total = `17`.
3. Move right to `7`: total = `24`.
4. No further valid moves are available.

```
Path: 9 → 8 → 7
Gold = 9 + 8 + 7 = 24
```

DFS explores other possible paths too, then returns the maximum.

### Case 2: Separate gold cells

```
grid:
1 0 2
0 0 0
3 0 4
```

Each gold cell is isolated by zeros.

- Starting from `1` collects `1`.
- Starting from `2` collects `2`.
- Starting from `3` collects `3`.
- Starting from `4` collects `4`.

```
Maximum gold = 4
```

## Code

```java
class Solution {
    public int getMaximumGold(int[][] grid) {
        boolean[][] vis = new boolean[grid.length][grid[0].length];
        int max = 0;

        for(int i = 0; i < grid.length; i++) {
            for(int j = 0; j < grid[0].length; j++) {
                int curr = grid[i][j];
                int x = dfs(i, j, grid, vis);

                if(x > max) max = x;
            }
        }

        return max;
    }

    public int dfs(int i, int j, int[][] grid, boolean[][] vis) {
        if(i < 0 || i >= grid.length) return 0;
        if(j < 0 || j >= grid[0].length) return 0;
        if(grid[i][j] == 0) return 0;
        if(vis[i][j]) return 0;

        vis[i][j] = true;

        int curr = grid[i][j];
        int a = dfs(i + 1, j, grid, vis);
        int b = dfs(i - 1, j, grid, vis);
        int c = dfs(i, j + 1, grid, vis);
        int d = dfs(i, j - 1, grid, vis);

        int ans = Math.max(Math.max(a, b), Math.max(c, d));

        vis[i][j] = false;

        return curr + ans;
    }
}
```

---

## Things to Remember

- Unlike ordinary flood-fill DFS, this explores **all possible paths** to find the maximum.
- Never use a global visited set here; different paths can reuse the same cell.
- `vis[i][j] = false` is essential for backtracking.
- `Math.max()` selects the best continuation among the four directions.
- `curr` in the outer loop is unused and can be removed without changing the algorithm.
- Time complexity is exponential in the number of gold-containing cells in the worst case, because many paths must be explored.
- Auxiliary space: \(O(mn)\) for the visited matrix and up to \(O(mn)\) recursion depth.

## One-Line Recall

> Start DFS from every gold cell, collect the current cell's value plus the best valid continuation, and unmark cells during backtracking.

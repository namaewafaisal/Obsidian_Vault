# 130. Surrounded Regions

## Problem

Given an `m x n` board containing `'X'` and `'O'`, capture all regions of `'O'` that are completely surrounded by `'X'`.

- `'O'` represents an open region.
- `'X'` represents a blocked cell.
- Any `'O'` connected to the boundary cannot be captured.

Modify the board in place.

**Example:**

```
Input:
X X X X
X O O X
X X O X
X O X X

Output:
X X X X
X X X X
X X X X
X O X X
```

---

## Pattern

**Boundary DFS + Flood Fill**

## Core Idea

Instead of searching for surrounded regions directly:

1. Traverse all four boundaries.
2. Start DFS whenever a boundary cell contains `'O'`.
3. Temporarily mark all connected `'O'` cells as `'S'` (safe).
4. Traverse the entire board:
   - Remaining `'O'` → `'X'` (surrounded).
   - `'S'` → `'O'` (safe).

**Key insight:** Every region connected to the boundary is safe. Only regions disconnected from the boundary should be captured.

---

## Dry Run

### Input

```
X X X X
X O O X
X X O X
X O X X
```

### Step 1 — Find boundary-connected regions

The boundary `'O'` at `(3,1)` is marked as `'S'`.

```
X X X X
X O O X
X X O X
X S X X
```

No other boundary `'O'` exists.

### Step 2 — Capture surrounded regions

The remaining `'O'` cells are not connected to the boundary, so they become `'X'`.

```
X X X X
X X X X
X X X X
X O X X
```

### Step 3 — Restore safe regions

Convert `'S'` back to `'O'`.

Final board:

```
X X X X
X X X X
X X X X
X O X X
```

## Code

```java
class Solution {
    public void solve(char[][] board) {
        int m = board.length;
        int n = board[0].length;

        // Change all border islands to S temporarily
        for(int i = 0; i < m; i++) {
            dfs(i, 0, board);
            dfs(i, n - 1, board);
        }

        for(int j = 0; j < n; j++) {
            dfs(0, j, board);
            dfs(m - 1, j, board);
        }

        for(int i = 0; i < board.length; i++) {
            for(int j = 0; j < board[0].length; j++) {
                if(board[i][j] == 'O') board[i][j] = 'X';
                else if(board[i][j] == 'S') board[i][j] = 'O';
            }
        }
    }

    public void dfs(int r, int c, char[][] board) {
        if(r < 0 || r >= board.length) return;
        if(c < 0 || c >= board[0].length) return;
        if(board[r][c] != 'O') return;

        board[r][c] = 'S';

        dfs(r - 1, c, board);
        dfs(r + 1, c, board);
        dfs(r, c - 1, board);
        dfs(r, c + 1, board);
    }
}
```

---

## Things to Remember

- Start DFS from the **boundary**, not from interior cells.
- `'S'` acts as a temporary visited/safe marker.
- Boundary-connected regions must remain unchanged.
- Only interior `'O'` cells that cannot reach the boundary are captured.
- No separate visited array is needed because the board itself stores the visited state.
- Time complexity: \(O(mn)\).
- Auxiliary space: \(O(mn)\) worst case due to recursive DFS.

## One-Line Recall

> Mark boundary-connected O's as safe, capture all remaining O's, and restore the safe cells.

# 1109. Corporate Flight Bookings

## Problem (LeetCode Statement)

**Input:**  
- `bookings[i] = [first, last, seats]`  
- Integer `n` (number of flights)

**Output:**  
- Array of size `n` where each index represents total seats booked for that flight

**Task:**  
Apply multiple range updates and return final seat counts

---

## Constraints

- `n` can be large → O(n²) will TLE
- Many overlapping ranges
- Need O(n + bookings)

---

## Examples

```
Input:  bookings = [[1,2,10],[2,3,20],[2,5,25]], n = 5
Output: [10,55,45,25,25]
```

---

## What Actually Matters

- Each booking updates a **range**
- Your current solution loops inside range → slow
- This is a classic **range update problem**
- Must avoid nested loops

---

## Core Insight

> Use difference array instead of updating every index in range

---

## Invariant / Mental Model

> Instead of updating full range:
- Add at start
- Subtract after end
- Prefix sum reconstructs final values

---

## Thinking Log (Your Style)

- Initial Thought:  
  For each booking, update all indices in range

- Issue:  
  Nested loop → O(n²)

- Realization:  
  Only start and end matter

- Key Insight:  
  Convert range updates into point updates

- Final Understanding:  
  Use difference array + prefix sum

---

## Algorithm (High Level)

1. Create array `arr` of size `n`
2. For each booking:
   - `arr[start-1] += seats`
   - `arr[end] -= seats` (if within bounds)
3. Run prefix sum on arr
4. Return arr

}

---

### ✅ Optimal Code

```java
class Solution {
    public int[] corpFlightBookings(int[][] bookings, int n) {
        int[] arr = new int[n];

        for(int[] b : bookings) {
            arr[b[0] - 1] += b[2];
            if(b[1] < n) {
                arr[b[1]] -= b[2];
            }
        }

        for(int i = 1; i < n; i++) {
            arr[i] += arr[i - 1];
        }

        return arr;
    }
}
```

## Edge Cases to Recall

- Booking ends at last index → no subtraction needed
- Single booking
- All flights covered

## One-Line Recall

> Convert range updates into start/end markers and use prefix sum to rebuild final array

# 349. Intersection of Two Arrays

## Problem (LeetCode Statement)

**Input:**  
- Integer arrays `nums1` and `nums2`

**Output:**  
- Array of unique elements present in both arrays

**Task:**  
Return the intersection such that each element appears **only once**

---

## Constraints

- Must return **unique elements only**
- Order does not matter
- Prefer O(n + m)

---

## Examples

```
Input:  nums1 = [1,2,2,1], nums2 = [2,2]
Output: [2]
```

```
Input:  nums1 = [4,9,5], nums2 = [9,4,9,8,4]
Output: [4,9]
```

---

## What Actually Matters

- Unlike LC 350 → duplicates do NOT matter
- Each element should appear only once in result
- Need fast lookup → set
- Must avoid adding duplicates

---

## Core Insight

> Use a set for membership and remove after use to ensure uniqueness

---

## Invariant / Mental Model

> For each element in nums2:
- If it exists in set → add to result
- Remove from set → prevents duplicate additions

---

## Thinking Log (Your Style)

- Initial Thought:  
  Find common elements

- Issue:  
  Duplicates should not repeat

- Realization:  
  Use set instead of map

- Key Insight:  
  Remove after adding to result

- Final Understanding:  
  Set ensures uniqueness naturally

---

## Algorithm (High Level)

1. Add all elements of nums1 to set
2. Traverse nums2:
   - If present in set:
     - add to result
     - remove from set
3. Convert list to array

---

## Code (Reference Only)

```java
class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {

        Set<Integer> set = new HashSet<>();

        for (int x : nums1) {
            set.add(x);
        }

        List<Integer> res = new ArrayList<>();

        for (int x : nums2) {
            if (set.contains(x)) {
                res.add(x);
                set.remove(x);
            }
        }

        int[] ans = new int[res.size()];
        for (int i = 0; i < res.size(); i++) {
            ans[i] = res.get(i);
        }

        return ans;
    }
}
```

---

## Edge Cases to Recall

- No intersection → empty array
- All elements same → single element result
- One array empty

## One-Line Recall

> Use a set to track elements and remove after adding to ensure uniqueness

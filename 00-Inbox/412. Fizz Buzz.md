# 412. Fizz Buzz

## Problem

Given an integer `n`, return a list of strings representing numbers from `1` to `n`.

Rules:
- Multiples of `3` → `"Fizz"`
- Multiples of `5` → `"Buzz"`
- Multiples of both `3` and `5` → `"FizzBuzz"`
- Otherwise, return the number as a string.

**Example:**

```
Input: n = 5

Output: ["1","2","Fizz","4","Buzz"]
```

---

## Pattern

**Simulation + Divisibility**

## Core Idea

- Iterate from `1` to `n`.
- Check divisibility by both `3` and `5` first.
- Then check divisibility by `3`.
- Then check divisibility by `5`.
- If none match, convert the number into a string.

**Why check both first?**

A number divisible by both `3` and `5` is also divisible by each individually. Checking the individual conditions first would produce `"Fizz"` or `"Buzz"` instead of `"FizzBuzz"`.

---

## Dry Run

### Case 1

```
n = 5

i = 1 → "1"
i = 2 → "2"
i = 3 → "Fizz"
i = 4 → "4"
i = 5 → "Buzz"

Result:
["1", "2", "Fizz", "4", "Buzz"]
```

### Case 2

```
n = 15

i = 3  → "Fizz"
i = 5  → "Buzz"
i = 9  → "Fizz"
i = 10 → "Buzz"
i = 15 → "FizzBuzz"

Result at 15 = "FizzBuzz"
```

---

## Code

```java
class Solution {
    public List<String> fizzBuzz(int n) {
        List<String> result = new ArrayList<>();

        for(int i = 1; i <= n; i++) {
            if(i % 3 == 0 && i % 5 == 0)
                result.add("FizzBuzz");
            else if(i % 3 == 0)
                result.add("Fizz");
            else if(i % 5 == 0)
                result.add("Buzz");
            else
                result.add(String.valueOf(i));
        }

        return result;
    }
}
```

---

## Things to Remember

- Check combined conditions before individual conditions.
- `%` gives the remainder; remainder `0` means divisible.
- `String.valueOf(i)` converts an integer into a string.
- Time complexity: \(O(n)\).
- Space complexity: \(O(n)\) for the result.

## One-Line Recall

> Iterate from 1 to n, check divisibility by 15, 3, and 5 in that order, and append the corresponding string.

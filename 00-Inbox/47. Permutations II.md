# 47. Permutations II

## Problem

Given an integer array `nums` that may contain duplicates, return all possible **unique permutations**.

**Example:**

```
Input: nums = [1,1,2]

Output:
[
  [1,1,2],
  [1,2,1],
  [2,1,1]
]
```

---

## Pattern

**Backtracking + Sorting + Duplicate Pruning**

## Core Idea

- Sort the array so duplicate elements are adjacent.
- Use `vis[]` to track which indices are already used in the current permutation.
- Skip an element if:
  - Its index is already used.
  - It is equal to the previous element, and the previous element has not been used in the current path.

**Important duplicate condition:**

```java
if(i > 0 && nums[i] == nums[i-1] && !vis[i-1])
    continue;
```

This ensures duplicates are selected in a consistent order, preventing duplicate permutations.

---

## Dry Run

### Input

```
nums = [1,1,2]
```

After sorting:

```
[1₀, 1₁, 2₂]
```

The subscripts represent original indices.

### Case 1: Choose the first `1`

```
path = [1₀]
```

Now:

- Choose `1₁` → `[1₀, 1₁]`
- Choose `2₂` → `[1₀, 1₁, 2₂]`

Save:

```
[1,1,2]
```

Backtrack and explore:

```
[1₀,2₂,1₁]
```

Save:

```
[1,2,1]
```

### Case 2: Try choosing the second `1` first

At the root:

```
i = 1
nums[1] == nums[0]
vis[0] == false
```

The duplicate condition becomes true, so this choice is skipped.

Why?

Choosing the second `1` before the first would generate permutations already explored by choosing the first `1`.

### Case 3: Choose `2` first

```
path = [2₂]
```

Then choose both `1`s:

```
[2,1,1]
```

Save the permutation.

**Final result:**

```
[[1,1,2], [1,2,1], [2,1,1]]
```

## Code

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();

    public List<List<Integer>> permuteUnique(int[] nums) {

        Arrays.sort(nums);
        List<Integer> path = new ArrayList<>();

        rec(path, nums, new boolean[nums.length]);

        return res;
    }

    public void rec(List<Integer> path, int[] nums, boolean[] vis) {

        if(nums.length == path.size()) {
            res.add(new ArrayList<>(path));
            return;
        }

        for(int i = 0; i < nums.length; i++) {
            if(vis[i]) continue;

            if(i > 0 && nums[i] == nums[i - 1] && !vis[i - 1])
                continue;

            vis[i] = true;
            path.add(nums[i]);

            rec(path, nums, vis);

            vis[i] = false;
            path.remove(path.size() - 1);
        }
    }
}
```

---

## Things to Remember

- Sorting groups duplicate values together.
- `vis[]` tracks used **indices**, not values.
- `!vis[i-1]` means the previous duplicate has not been selected in the current path.
- Always select duplicate elements in their sorted order.
- `new ArrayList<>(path)` is necessary to save an independent copy.
- Backtracking: **Choose → Explore → Unchoose**.
- Time complexity: \(O(n \cdot n!)\) worst case, including copying permutations.
- Auxiliary space: \(O(n)\) for the recursion stack, path, and visited array, excluding output.

## One-Line Recall

> Sort the array, track used indices, and skip a duplicate whenever its previous equal element has not yet been used in the current path.

# Parallel Ports

## Overview
- 8051 has 4 ports:
  - P0
  - P1
  - P2
  - P3
- Each port = 8 bits
- Total I/O pins = 32
- Ports are SFRs

| Port | Address |
|--------|--------|
| P0 | 80H |
| P1 | 90H |
| P2 | A0H |
| P3 | B0H |

---

# Port 0 (P0)

## Features
- General I/O
- AD0–AD7 (Address/Data bus)
- Used for external memory access

## Important
- No internal pull-up resistor
- Open-drain / true bidirectional
- External pull-up required

## External Memory Role
```text
P0 = A0–A7 + D0–D7
```

---

# Port 1 (P1)

## Features
- Pure general-purpose I/O
- Internal pull-up present
- Simplest port

Used for:
- LEDs
- Switches
- Displays

---

# Port 2 (P2)

## Features
- General-purpose I/O
- High-byte address bus

```text
P2 = A8–A15
```

Used during:
```text
External memory access
```

Has:
```text
Internal pull-up
```

---

# Port 3 (P3)

## Features
- General I/O
- Alternate hardware functions

| Pin | Function |
|------|------|
| P3.0 | RXD |
| P3.1 | TXD |
| P3.2 | INT0 |
| P3.3 | INT1 |
| P3.4 | T0 |
| P3.5 | T1 |
| P3.6 | WR |
| P3.7 | RD |

---

# Output Operation

## Rule

```text
Write 1 → HIGH
Write 0 → LOW
```

Examples:

```asm
SETB P1.0
```

Result:
```text
P1.0 = HIGH
```

```asm
CLR P1.0
```

Result:
```text
P1.0 = LOW
```

---

# Input Operation

## Important Rule

Before reading:

```asm
SETB Px.y
```

Then read:

```asm
MOV C,P2.0
```

Reason:

```text
Write 1
→ Release pin

Write 0
→ Force LOW
```

If pin contains 0:
```text
External signal cannot control pin properly
```

---

# Quasi-Bidirectional Ports

Used by:
```text
P1
P2
P3
```

## Features
- No direction register
- Same pin behaves as input/output

Rule:

```text
Write 1
→ Input / HIGH state

Write 0
→ Output LOW
```

Meaning:
```text
Hybrid input-output behavior
```

---

# P0 Difference

## Features

```text
No internal pull-up
```

Therefore:

```text
HIGH output not reliable
without external pull-up
```

Called:

```text
True bidirectional
Open-drain
```

---

# Floating Pin

Meaning:

```text
Not definite HIGH
Not definite LOW
```

Caused by:
- Noise
- EMI
- No pull-up/pull-down

Danger:
```text
Unpredictable readings
```

 ↓

```

Binary:

11111110

```

Reason:

Current flows:
VCC
↓

↓
P1.0

# Switch Example

## Connection

```text
Switch → P2.0
```

Initialize:

```asm
SETB P2.0
```

Read:

```asm
JB P2.0,LABEL
```

Meaning:

```text
If P2.0 = 1
Jump
```

States:

```text
1 → Not Pressed
0 → Pressed
```

# Numerical

## Problem

```text
Switch → P3.2
LED → P1.0

Pressed = 0
```

## Program

```asm
SETB P3.2

CHECK:

JB P3.2,LED_OFF

CLR P1.0
SJMP CHECK

LED_OFF:
SETB P1.0
SJMP CHECK
```

## Logic

```text
Switch = 0
→ LED ON

Switch = 1
→ LED OFF
```

# 60. Permutation Sequence

## Problem (LeetCode Statement)

**Input:**  
- Integer `n` (1 ≤ n ≤ 9)  
- Integer `k`

**Output:**  
- The `k-th` permutation of numbers `[1, 2, ..., n]` in lexicographic order

**Task:**  
Return the `k-th` permutation without generating all permutations

---

## Constraints

- `n ≤ 9` → factorial fits in int  
- Cannot generate all permutations (too slow)

---

## Examples

```
Input:  n = 3, k = 3
Output: "213"
```

```
Input:  n = 4, k = 9
Output: "2314"
```

---

## What Actually Matters

- Total permutations = `n!`
- Each position cycles in blocks of size `(n-1)!`
- We are not building permutations → we are **jumping to the correct one**
- Order is fixed (lexicographic), so positions are predictable

---

## Core Insight

> After every `(n-1)!` permutations, the first digit changes

So:
- `(n-1)!` = size of one block
- `k / fact` → which block → which number to pick

---

## Invariant / Mental Model

> At every step:
- Remaining numbers form equal-sized groups
- Each group size = `(remaining-1)!`
- `k / fact` → which number to pick
- `k % fact` → remaining offset inside that block

You are basically:
```text
skipping entire permutations without generating them
```

---

## Thinking Log (Your Style)

- Initial Thought:  
  Try generating permutations and picking k-th

- Issue:  
  Too slow → factorial explosion

- Better Thought:  
  Instead of generating, see pattern in how permutations change

- Realization:  
  First digit stays same for `(n-1)!` times

- Key Jump:  
  So I can directly decide first digit using division

- Final Understanding:  
  After picking a digit → problem reduces with:
  - smaller list
  - smaller factorial
  - updated k

---

## Algorithm (High Level)

1. Store numbers `[1..n]`
2. Compute `(n-1)!`
3. Convert `k` to 0-based (`k--`)
4. Repeat:
   - `index = k / fact`
   - pick that number
   - remove it
   - `k = k % fact`
   - reduce factorial

---

## Code (Reference Only)

```java
class Solution {
    public String getPermutation(int n, int k) {
        List<Integer> available = new ArrayList<>();
        int fact = 1;

        for(int i = 1; i <= n; i++) {
            available.add(i);
        }

        for(int i = 1; i < n; i++) {
            fact *= i; // (n-1)!
        }

        k = k - 1; // 0-based

        StringBuilder str = new StringBuilder();

        while(true){
            int index = k / fact;
            k = k % fact;

            str.append(available.get(index));
            available.remove(index);

            if(available.size() == 0) break;

            fact = fact / available.size();
        }

        return str.toString();
    }
}
```

---

## Edge Cases to Recall

- `n = 1`
- `k = 1`
- `k = n!` → last permutation
- Off-by-one error if not converting to 0-based

---

## One-Line Recall

> Each position has `(n-1)!` permutations → use division to directly pick digits instead of generating permutations

## LC 242. Valid Anagram

| **Metric**     | **Value**                    |
| -------------- | ---------------------------- |
| **Date**       | Day 5                        |
| **Time Taken** | ~10–15 minutes               |
| **Difficulty** | Easy                         |
| **Pattern**    | Hashing / Frequency Counting |

---

### Problem (summary)

Given two strings `s` and `t`, determine if `t` is an **anagram** of `s`.
An anagram uses **exactly the same characters with the same frequencies**.

---

### Key Invariant

> For an anagram, **character supply must exactly match character demand**.

* Lengths must be equal.
* No character in `t` can appear **more times** than it appears in `s`.

---

### Thinking Log (Evolution of the Solution)

* **Initial Observation:**
  Anagrams only differ in order, not in character counts.

* **Early Rejection Rule:**
  If `s.length() != t.length()`, an anagram is impossible.

* **Data Structure Choice:**
  Since input is lowercase English letters, a fixed-size `int[26]` array is sufficient.
  This avoids `HashMap` overhead.

* **Supply Phase (`s`):**
  Increment frequency for each character.

* **Demand Phase (`t`):**
  Decrement frequency for each character.

  * If any count becomes **negative**, demand exceeded supply → return `false` immediately.

* **Final State:**
  If traversal completes without violations, strings are anagrams.

---

### Implementation Strategy

1. Check if lengths are equal.
2. Create an integer array of size 26.
3. Increment counts for characters in `s`.
4. Decrement counts for characters in `t`.
5. If any count drops below zero, return `false`.
6. Otherwise, return `true`.

---

### Final Code (Java)

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        int[] arr = new int[26];

        if (s.length() != t.length()) {
            return false;
        }

        for (char c : s.toCharArray()) {
            arr[c - 'a']++;
        }

        for (char c : t.toCharArray()) {
            arr[c - 'a']--;
            if (arr[c - 'a'] < 0) {
                return false;
            }
        }

        return true;
    }
}
```

---

### Complexity Analysis

| Metric    | Complexity | Reason                        |
| --------- | ---------- | ----------------------------- |
| **Time**  | O(n)       | Each string is traversed once |
| **Space** | O(1)       | Fixed-size array (26 letters) |

---

### Why This Solution Is Optimal

* No sorting
* No hash maps
* Constant memory
* Early exit on failure

This is the **canonical optimal solution** for this problem.

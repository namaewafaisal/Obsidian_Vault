## First: a critical clarification (very important)

Japanese **does NOT change verbs by person**.

So there is **no difference** between:

* I do
* you do
* he does
* mom does
* they do

👉 **The verb form stays the same.**
Only **context or subject words** change.

This is a *huge simplification* compared to English.

---

## The real dimensions that matter

Japanese verbs mainly change by:

1. **Tense**

   * present / past
2. **Polarity**

   * positive / negative
3. **Politeness**

   * casual / polite

That’s it (for now).

---

## We will use ONE verb as a model: する (to do)

Once you understand this, **all verbs behave similarly**.

---

## 1️⃣ Casual present (dictionary form)

Used in:

* thoughts
* casual speech
* anime-style lines

```
する
suru
do / does
```

Examples:

* する
  do (neutral)
* 何する？
  *nani suru?*
  What are you doing?

---

## 2️⃣ Casual past

```
した
shita
did
```

Examples:

* した
  did
* 昨日した
  *kinō shita*
  Did (it) yesterday

👉 Notice: **no “I / he / they” change**

---

## 3️⃣ Casual negative

```
しない
shinai
do not
```

Examples:

* しない
  don’t do
* 今日はしない
  *kyō wa shinai*
  Not doing it today

---

## 4️⃣ Casual past negative

```
しなかった
shinakatta
did not
```

Examples:

* しなかった
  didn’t do
* 昨日しなかった
  *kinō shinakatta*
  Didn’t do (it) yesterday

---

## 5️⃣ Polite present (〜ます form)

Used in:

* normal conversation
* strangers
* safe default

```
します
shimasu
do / does
```

Examples:

* します
  I do / you do / they do
* 今します
  *ima shimasu*
  I’ll do it now

---

## 6️⃣ Polite past

```
しました
shimashita
did
```

Examples:

* しました
  did
* もうしました
  *mō shimashita*
  Already did it

---

## 7️⃣ Polite negative

```
しません
shimasen
do not
```

Examples:

* しません
  don’t do
* 今日はしません
  *kyō wa shimasen*
  I won’t do it today

---

## 8️⃣ Polite past negative

```
しませんでした
shimasen deshita
did not
```

## Now answering your exact question

### “I do / he does / mom did / they did”

Japanese does this:

### I do

```
する / します
```

### He does

```
する / します
```

### Mom did

```
母がした
haha ga shita
```

### They did

```
した
shita
```

Same verb.
**No person-based change.**

This is why Japanese is **context-driven**, not subject-driven.

## ⚡ Simple Summary (no fluff)

A real project goes like this:

1. **Understand requirements**
2. **Design system (entities + flows + APIs)**
3. **Break into tasks**
4. **Build step-by-step**
5. **Test**
6. **Deploy**
7. **Improve**

👉 Loop between design ↔ build ↔ improve

---

## 🧭 YOUR First Step (exactly what to do)

### ✅ Step 1: Write a Requirement Document

### 📍 Where to do it?

Use any of these:

* Notion (best)
* Markdown file in your project (`docs/requirements.md`)
* Google Docs

👉 Recommendation: **Markdown in your repo** (looks professional)

---

## ✍️ What you should write (exact content)

Keep it simple like this:

```
Project: Code Dashboard

Actors:
- Platform Admin (me)
- Institution Admin
- Student

Core Features:
1. Institution creation (with email domain)
2. Student registration (must match domain)
3. Email verification
4. Login system
5. Role-based access (admin/student)
6. Institution dashboard
7. Filtering + export

Rules:
- Each user belongs to one institution
- Email must match institution domain
- Data is isolated per institution
```

# 3046. Split the Array

## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`

**Output:**  
- `true` if array can be split into two arrays with no duplicates  
- Otherwise `false`

**Task:**  
Determine if it’s possible to divide the array into two groups such that each group contains only unique elements

---

## Constraints

- Must be O(n)
- Values are bounded → allows frequency array

---

## Examples

```
Input:  [1,1,2,2,3,4]
Output: true
```

```
Input:  [1,1,1,2]
Output: false
```

---

## What Actually Matters

- Each number can appear at most **twice**
- Why? → one copy goes to each group
- If any number appears **3+ times → impossible**
- No need to actually form groups

---

## Core Insight

> Problem reduces to checking if max frequency ≤ 2

---

## Invariant / Mental Model

> While iterating:
- `freq[x]` tracks occurrences
- If it exceeds 2 → immediately invalid

---

## Thinking Log (Your Style)

- Initial Thought:  
  Try forming two arrays

- Issue:  
  Complicated and unnecessary

- Realization:  
  Only frequency matters

- Key Insight:  
  Each value can be used at most twice

- Final Understanding:  
  Just count and check limit

---

## Algorithm (High Level)

1. Initialize frequency array
2. Traverse nums:
   - increment count
   - if > 2 → return false
3. Return true

---

## Code (Reference Only)

```java
class Solution {
    public boolean isPossibleToSplit(int[] nums) {
        int[] freq = new int[101];

        for(int x : nums) {
            freq[x]++;
            if(freq[x] > 2) return false;
        }

        return true;
    }
}
```

---

## Edge Cases to Recall

- All elements unique → always true
- All elements same → false if > 2
- Exactly twice → valid

---

## One-Line Recall

> Check that no element appears more than twice

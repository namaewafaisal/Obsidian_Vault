# 99. Recover Binary Search Tree

## Problem

**Input:**
- Root of a BST where exactly two nodes have been swapped

**Output:**
- Recover the BST by swapping the two incorrect node values

```
Input:
    3
   / \
  1   4
     /
    2

Output:
    2
   / \
  1   4
     /
    3
```

---

## Pattern

**Inorder Traversal + BST Property**

---

## Core Idea

- Inorder traversal of a BST should produce a **sorted sequence**.
- Whenever `prev.val > current.val`, the BST property is violated.
- First violation:
  - `first = prev`
- Every violation:
  - `second = current`
- Swap their values after traversal.

---

## Dry Run

```
Inorder:

1, 3, 2, 4

        ↑
3 > 2

first = 3
second = 2

Swap them.

Result:
1, 2, 3, 4
```

Another case:

```
1, 5, 3, 4, 2, 6

Violations:

5 > 3
4 > 2

first = 5
second = 2

Swap 5 and 2
```

---

## Code

```java
class Solution {
    TreeNode first = null;
    TreeNode second = null;
    TreeNode prev = null;

    public void recoverTree(TreeNode root) {
        inorder(root);

        int temp = first.val;
        first.val = second.val;
        second.val = temp;
    }

    public void inorder(TreeNode root) {
        if(root == null) {
            return;
        }

        inorder(root.left);

        if(prev != null && prev.val > root.val) {
            if(first == null) {
                first = prev;
            }
            second = root;
        }

        prev = root;

        inorder(root.right);
    }
}
```

---

## Things to Remember

- Inorder of a BST is always sorted.
- `prev` stores the previously visited node.
- `first` is assigned **only once** (first violation).
- `second` is updated on every violation, handling both adjacent and non-adjacent swaps.

---

## One-Line Recall

> Traverse inorder, find where the sorted order breaks, record the misplaced nodes, then swap their values.

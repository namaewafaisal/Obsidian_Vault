# 1903. Largest Odd Number in String

## Problem

**Input:**
- String `num` representing a non-negative integer

**Output:**
- The largest-valued odd integer (as a string) that is a non-empty prefix of `num`

```
Input:  "52"
Output: "5"
```

```
Input:  "4206"
Output: ""
```

---

## Pattern

**Greedy + Reverse Traversal**

---

## Core Idea

- An odd number must end with an odd digit.
- Scan from the end to find the **rightmost odd digit**.
- Return the prefix ending at that digit.
- If no odd digit exists, no valid answer exists.

---

## Dry Run

```
num = "35427"

Start from right:

7 ✓ odd

Return:
"35427"
```

```
num = "4206"

6 even
0 even
2 even
4 even

No odd digit

Return ""
```

---

## Code

```java
class Solution {
    public String largestOddNumber(String num) {
        for(int i = num.length() - 1; i >= 0; i--) {
            if((num.charAt(i) - '0') % 2 == 1) {
                return num.substring(0, i + 1);
            }
        }
        return "";
    }
}
```

---

## Things to Remember

- Only the **last digit** determines whether a number is odd.
- The largest valid odd number must be a **prefix** of the original string.
- Traverse from the end to find the longest possible valid prefix.

---

## One-Line Recall

> Scan from right to left for the first odd digit and return the prefix ending there.

# 3272. Find the Lexicographically Smallest Valid Palindrome

## Problem

**Input:**
- Palindromic string `s`

**Output:**
- Lexicographically smallest palindrome that can be formed using the same characters

```
Input:  "babab"
Output: "abbba"
```

---

## Pattern

**Frequency Array + Greedy Construction**

---

## Core Idea

- Count the frequency of every character.
- Build the palindrome from the outside inward.
- Always place the **smallest available character** on both ends first.
- If the length is odd, place the remaining character in the middle.

---

## Dry Run

```
s = "babab"

freq:
a = 2
b = 3

Place 'a'

a _ _ _ a

Remaining:
b = 3

Place 'b'

a b _ b a

Remaining:
b = 1

Middle = b

Result:
abbba
```

---

## Code

```java
class Solution {
    public String smallestPalindrome(String s) {
        int freq[] = new int[26];

        for(char c : s.toCharArray()) {
            freq[c - 'a']++;
        }

        int n = s.length();
        int index = 0;
        int i = 0;
        char res[] = new char[n];

        while(i < n / 2) {

            while(index < 26 && freq[index] < 2) {
                index++;
            }

            while(freq[index] >= 2) {
                char c = (char) ('a' + index);

                res[i] = c;
                res[n - i - 1] = c;

                freq[index] -= 2;
                i++;
            }
        }

        if(n % 2 == 1) {
            for(int j = 0; j < 26; j++) {
                if(freq[j] == 1) {
                    res[n / 2] = (char) ('a' + j);
                    break;
                }
            }
        }

        return new String(res);
    }
}
```

---

## Things to Remember

- Fill the palindrome from both ends simultaneously.
- Greedily using the smallest available character guarantees the lexicographically smallest answer.
- **Middle character should come from the remaining frequency array**, **not** `s.charAt(n/2)`. The middle character in the original string may not remain the middle after rearrangement.

---

## One-Line Recall

> Count frequencies, greedily place the smallest available pair at both ends, and put the lone remaining character in the center.

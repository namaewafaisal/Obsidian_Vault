# 108. Convert Sorted Array to Binary Search Tree

## Problem

**Input:**
- Sorted integer array `nums`

**Output:**
- Height-balanced Binary Search Tree

```
Input:  nums = [-10,-3,0,5,9]
Output: A height-balanced BST
```

---

## Pattern

**Divide and Conquer**

---

## Core Idea

- Middle element becomes the root.
- Left half recursively forms the left subtree.
- Right half recursively forms the right subtree.
- Repeating this keeps the tree balanced.

---

## Dry Run

```
nums = [-10,-3,0,5,9]

          0
        /   \
      -10     5
        \      \
        -3      9
```

(Any balanced BST is valid.)

---

## Code

```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return helper(0, nums.length - 1, nums);
    }

    public TreeNode helper(int left, int right, int[] nums) {
        if(left > right) {
            return null;
        }

        int mid = (left + right) / 2;

        TreeNode root = new TreeNode(nums[mid]);

        root.left = helper(left, mid - 1, nums);
        root.right = helper(mid + 1, right, nums);

        return root;
    }
}
```

---

## One-Line Recall

> Pick the middle element as the root, then recursively build the left and right subtrees from the two halves.

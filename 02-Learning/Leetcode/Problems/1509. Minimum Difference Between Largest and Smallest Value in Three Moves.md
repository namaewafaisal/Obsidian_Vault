# 1509. Minimum Difference Between Largest and Smallest Value in Three Moves

## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`

**Output:**  
- Minimum difference between largest and smallest after at most 3 moves

**Task:**  
In one move, you can change any element to any value.  
After at most 3 moves, minimize `(max - min)`.

---

## Constraints

- Only 3 moves allowed
- Sorting is required → O(n log n)
- n can be small or large

---

## Examples

```
Input:  [5,3,2,4]
Output: 0
```

```
Input:  [1,5,6,14,15]
Output: 1
```

---

## What Actually Matters

- You can remove (modify) at most **3 elements**
- Best strategy → remove extremes (not middle)
- Only **4 possible cases** exist
- Order matters → sorting required

---

## Core Insight

> Instead of thinking “which 3 to remove”, think “which 4 elements remain at extremes”

---

## Invariant / Mental Model

> After sorting:
You are effectively removing combinations of:
- 3 largest
- 2 largest + 1 smallest
- 1 largest + 2 smallest
- 3 smallest

These give exactly **4 cases**

---

- Initial Thought:  
  Try removing any 3 elements

- Issue:  
  Too many combinations

- Realization:  
  Only extremes matter for min/max

- Key Insight:  
  Only 4 valid configurations exist

- Final Understanding:  
  Just check all 4 cases

---

## Algorithm (High Level)

1. Sort the array
2. If size ≤ 4 → return 0
3. Compute:
   - remove 3 largest → `nums[n-4] - nums[0]`
   - remove 2 largest + 1 smallest → `nums[n-3] - nums[1]`
   - remove 1 largest + 2 smallest → `nums[n-2] - nums[2]`
   - remove 3 smallest → `nums[n-1] - nums[3]`
4. Return minimum

---

## Code (Reference Only)

```java
class Solution {
    public int minDifference(int[] nums) {
        Arrays.sort(nums);

        if(nums.length <= 4) return 0;

        int n = nums.length;
        int max = Integer.MAX_VALUE;

        max = Math.min(nums[n-4] - nums[0], max);
        max = Math.min(nums[n-3] - nums[1], max);
        max = Math.min(nums[n-2] - nums[2], max);
        max = Math.min(nums[n-1] - nums[3], max);

        return max;
    }
}
```

---

## Edge Cases to Recall

- Array size ≤ 4 → can remove all extremes → answer = 0
- All elements same → already 0
- Large spread → depends on extreme removals

---

## One-Line Recall

> Sort and check 4 ways of removing 3 elements from extremes to minimize max - min

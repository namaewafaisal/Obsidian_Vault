# 350. Intersection of Two Arrays II

## Problem (LeetCode Statement)

**Input:**  
- Integer arrays `nums1` and `nums2`

**Output:**  
- Array representing intersection of both arrays (including duplicates)

**Task:**  
Return all elements that appear in both arrays, considering frequency

---

## Constraints

- Must handle duplicates correctly
- Order does not matter
- Prefer O(n + m)

---

## Examples

```
Input:  nums1 = [1,2,2,1], nums2 = [2,2]
Output: [2,2]
```

```
Input:  nums1 = [4,9,5], nums2 = [9,4,9,8,4]
Output: [4,9]
```

---

## What Actually Matters

- This is NOT set intersection
- Frequency matters
- Each element can be used only as many times as it appears
- Need efficient lookup → hashmap

---

## Core Insight

> Count frequencies in one array, consume while scanning the other

---

## Invariant / Mental Model

> For each element in nums2:
- If frequency > 0 → valid intersection
- Decrement count → prevents reuse

---

## Thinking Log (Your Style)

## Algorithm (High Level)

1. Build frequency map from nums1
2. Traverse nums2:
   - If present in map:
     - add to result
     - decrement count
3. Convert result list to array

---

## Code (Reference Only)

```java
class Solution {
    public int[] intersect(int[] nums1, int[] nums2) {

        Map<Integer, Integer> map = new HashMap<>();

        for (int x : nums1) {
            map.put(x, map.getOrDefault(x, 0) + 1);
        }

        List<Integer> res = new ArrayList<>();

        for (int x : nums2) {
            if (map.getOrDefault(x, 0) > 0) {
                res.add(x);
                map.put(x, map.getOrDefault(x, 0) - 1);
            }
        }

        int[] ans = new int[res.size()];
        for (int i = 0; i < res.size(); i++) {
            ans[i] = res.get(i);
        }

        return ans;
    }
}
```

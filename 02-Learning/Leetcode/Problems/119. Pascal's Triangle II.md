# 119. Pascal's Triangle II

## Problem

**Input:**
- Integer `rowIndex`

**Output:**
- The `rowIndex`-th row of Pascal's Triangle

```
Input:  rowIndex = 3
Output: [1,3,3,1]
```

---

## Pattern

**Mathematical Recurrence (nCr)**

---

## Core Idea

Instead of generating all previous rows, directly compute each element using:

```text
C(n,r) = C(n,r-1) × (n-r+1) / r
```

Each coefficient is derived from the previous one in **O(1)** time.

---

## Dry Run

```
rowIndex = 4

Start:
C(4,0) = 1

C(4,1) = 1 × 4 / 1 = 4
C(4,2) = 4 × 3 / 2 = 6
C(4,3) = 6 × 2 / 3 = 4
C(4,4) = 4 × 1 / 4 = 1

Result:
[1,4,6,4,1]
```

---

## Code

```java
class Solution {
    public List<Integer> getRow(int rowIndex) {
        long nck_1 = 1;
        List<Integer> res = new ArrayList<>();
        res.add(1);

        int n = rowIndex;

        for(int r = 1; r <= n; r++) {
            long nck = nck_1 * (n - r + 1) / r;
            res.add((int) nck);
            nck_1 = nck;
        }

        return res;
    }
}
```

---

## Things to Remember

- Start with `C(n,0) = 1`.
- Each coefficient depends only on the previous coefficient.
- Use `long` during computation to avoid intermediate overflow.
- No need to build the entire Pascal's Triangle.

---

## One-Line Recall

> Start with `1` and repeatedly compute the next coefficient using `C(n,r) = C(n,r-1) × (n-r+1) / r`.

# 103. Binary Tree Zigzag Level Order Traversal

## Problem

**Input:**
- Root of a binary tree

**Output:**
- Level order traversal where each level alternates direction:
  - Left → Right
  - Right → Left

```
Input:
      3
     / \
    9  20
      /  \
     15   7

Output:
[
  [3],
  [20,9],
  [15,7]
]
```

---

## Pattern

**Level Order Traversal (BFS) + Deque**

---

## Core Idea

- Perform a normal BFS level by level.
- Use a `Deque` to build the current level:
  - Left → Right : `addLast()`
  - Right → Left : `addFirst()`
- Flip the direction after every level.

---

## Dry Run

```
Level 0:
Queue: [3]
Direction: →

Deque:
[3]

Result:
[3]

-------------------

Level 1:
Queue: [9,20]
Direction: ←

9  -> addFirst -> [9]
20 -> addFirst -> [20,9]

Result:
[20,9]

-------------------

Level 2:
Queue: [15,7]
Direction: →

15 -> addLast -> [15]
7  -> addLast -> [15,7]
```

---

## Code

```java
class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();

        if(root == null) return result;

        boolean leftToRight = true;

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while(!queue.isEmpty()) {

            Deque<Integer> deque = new ArrayDeque<>();
            int size = queue.size();

            for(int i = 0; i < size; i++) {

                TreeNode current = queue.poll();

                if(leftToRight) {
                    deque.addLast(current.val);
                } else {
                    deque.addFirst(current.val);
                }

                if(current.left != null) queue.offer(current.left);
                if(current.right != null) queue.offer(current.right);
            }

            result.add(new ArrayList<>(deque));
            leftToRight = !leftToRight;
        }

        return result;
    }
}
```

---

## Things to Remember

- Process **one level at a time** using `queue.size()`.
- Use a **Deque**, not a Stack.
- Alternate direction after each level.
- Queue order never changes—only the insertion order into the deque changes.

---

## One-Line Recall

> Perform normal BFS, but insert values into a deque from opposite ends on alternating levels to achieve the zigzag order.

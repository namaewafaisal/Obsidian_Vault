## LC 26 — Remove Duplicates from Sorted Array

| **Metric** | **Value** |
| --- | --- |
| **Date** | December 29, 2025 |
| **Time Taken** | ~10 minutes |
| **Difficulty** | Easy |
| **Pattern** | Two Pointers (Read/Write Heads) |

---

### Problem (summary)

Given an integer array `nums` sorted in non-decreasing order, remove the duplicates **in-place** such that each unique element appears only once. The relative order of the elements should be kept the same. Then return the number of unique elements.

---

### Key Invariant

* **Sorted Property:** Since the array is sorted, any duplicates of an element must be positioned immediately adjacent to it.
* **The "Unique" Boundary:** The `index` pointer always tracks the position of the last confirmed unique element. Everything at or before `index` is a sorted list of unique values.

---

### Thinking Log (Evolution of the Solution)

* **Initial Observation:** The array is already sorted, so all duplicates are next to each other.
* **Strategy shift:** I do not need to physically remove elements (which is expensive in an array), only overwrite positions.
* **Setup:** I keep an `index` which represents the position of the last unique element. Initially, the first element is always unique, so `index = 0`.
* **The Scan:** I scan the array using another pointer `i`.
* **The Logic:** For each element:
* If `nums[i]` is greater than `nums[index]`, then this is a new unique value. I move `index` forward and place this value at `nums[index]`.
* If `nums[i]` is the same as `nums[index]`, it is a duplicate. I ignore it.


* **Conclusion:** I continue this until the scan finishes. At the end, all unique elements are stored from `nums[0]` to `nums[index]`. The number of unique elements is `index + 1`.
* **Why this works:** Sorted order guarantees duplicates are adjacent. Writing only when a new value appears keeps the array compact without needing extra space.

---

### Implementation Strategy

1. Initialize `index = 0` (the first element is always the first unique element).
2. Iterate through the array with a pointer `i` starting from `0`.
3. Whenever `nums[i] > nums[index]`:
* Increment `index`.
* Overwrite `nums[index]` with `nums[i]`.


4. Return `index + 1`.

---

### Final Code (Java)

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        // Base case: empty array
        if (nums.length == 0) return 0;
        
        int index = 0; // Position of the last unique element found
        
        for (int i = 0; i < nums.length; i++) {
            // Because the array is sorted, if current is greater than the last unique,
            // it must be a new unique element.
            if (nums[index] < nums[i]) {
                index++; // Move to the next available slot
                nums[index] = nums[i]; // Overwrite it with the new unique value
            }
        }
        
        // The count of unique elements is index + 1
        return index + 1;
    }
}

```

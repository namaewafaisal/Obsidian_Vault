# 2374. Node With Highest Edge Score

## Problem

**Input:**
- Integer array `edges` where `edges[i]` is the node pointed to by node `i`

**Output:**
- Node with the highest edge score
- If multiple nodes have the same score, return the smallest index

```
Input:  edges = [1,0,0,0,0,7,7,5]
Output: 7
```

---

## Pattern

**Score Accumulation**

---

## Core Idea

- Every node contributes its **index** to the node it points to.
- Maintain an array where:
  - `score[node] += sourceIndex`
- After processing all edges, scan the score array to find the maximum.

---

## Dry Run

```
edges = [1,0,0]

Node 0 -> 1
score = [0,0,0]

score[1] += 0
score = [0,0,0]

Node 1 -> 0
score[0] += 1
score = [1,0,0]

Node 2 -> 0
score[0] += 2
score = [3,0,0]

Maximum score = 3
Answer = 0
```

---

## Code

```java
class Solution {
    public int edgeScore(int[] edges) {
        long[] arr = new long[edges.length];

        for(int i = 0; i < edges.length; i++){
            arr[edges[i]] += i;
        }

        long max = Long.MIN_VALUE;
        int node = 0;

        for(int i = 0; i < arr.length; i++){
            if(arr[i] > max){
                max = arr[i];
                node = i;
            }
        }

        return node;
    }
}
```

---

## Things to Remember

- Use `long[]` since the sum of indices may exceed `int`.
- The first occurrence of the maximum score is kept, automatically satisfying the "smallest index" tie-break because the comparison is `>` and not `>=`.

---

## One-Line Recall

> Accumulate each node's incoming index values into a score array, then return the index with the highest score.

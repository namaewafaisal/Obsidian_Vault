# 1979. Find Greatest Common Divisor of Array

## Problem

**Input:**
- Integer array `nums`

**Output:**
- Greatest Common Divisor (GCD) of the smallest and largest element

```
Input:  nums = [2,5,6,9,10]
Output: 2
```

---

## Pattern

**Euclidean Algorithm**

---

## Core Idea

- Find the minimum and maximum elements in the array.
- The answer is simply:

```text
GCD(min, max)
```

- Compute the GCD efficiently using Euclid's algorithm.

---

## Dry Run

```
nums = [2,5,6,9,10]

min = 2
max = 10

gcd(10,2)

10 % 2 = 0

Answer = 2
```

---

## Code

```java
class Solution {
    public int findGCD(int[] nums) {
        int min = Integer.MAX_VALUE;
        int max = Integer.MIN_VALUE;

        for(int i : nums){
            max = Math.max(max, i);
            min = Math.min(min, i);
        }

        return gcd(max, min);
    }

    public int gcd(int a, int b){
        if(b == 0) return a;
        return gcd(b, a % b);
    }
}
```

---

## Things to Remember

- You only need the **minimum** and **maximum** values.
- Euclid's algorithm:

```text
gcd(a, b) = gcd(b, a % b)
```

- Base case:

```text
gcd(a, 0) = a
```

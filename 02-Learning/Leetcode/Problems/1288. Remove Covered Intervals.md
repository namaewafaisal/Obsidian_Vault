# 1288. Remove Covered Intervals

## Problem

**Input:**
- Array of intervals `[start, end]`

**Output:**
- Number of intervals that are **not completely covered** by another interval

```
Input:  [[1,4],[3,6],[2,8]]
Output: 2
```

---

## Pattern

**Sorting + Greedy**

---

## Core Idea

- Sort by:
  - Increasing start
  - If starts are equal, decreasing end
- Keep track of the largest end seen so far (`maxEnd`).
- If the current interval ends after `maxEnd`, it is not covered.
- Otherwise, it is already covered by a previous interval.

---

## Dry Run

```
Input:
[[1,4],[3,6],[2,8]]

After sorting:
[[1,4],[2,8],[3,6]]

maxEnd = 0

[1,4]
4 > 0 ✓
count = 1
maxEnd = 4

[2,8]
8 > 4 ✓
count = 2
maxEnd = 8

[3,6]
6 <= 8 ✗
Covered

Answer = 2
```

---

## Code

```java
class Solution {
    public int removeCoveredIntervals(int[][] intervals) {

        Arrays.sort(intervals, (a, b) -> {
            if (a[0] == b[0]) {
                return Integer.compare(b[1], a[1]);
            }
            return Integer.compare(a[0], b[0]);
        });

        int count = 0;
        int maxEnd = 0;

        for (int[] interval : intervals) {
            if (interval[1] > maxEnd) {
                count++;
                maxEnd = interval[1];
            }
        }

        return count;
    }
}
```

---

## Things to Remember

- Sort equal starts by **larger end first**. Otherwise, a smaller interval may incorrectly appear before the interval that covers it.
- `maxEnd` always stores the farthest ending point seen so far.
- An interval is covered if:

```text
currentEnd <= maxEnd
```

---

## One-Line Recall

> Sort by start ascending and end descending, then keep only intervals whose end extends beyond the maximum end seen so far.

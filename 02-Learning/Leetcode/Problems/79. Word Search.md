# 79. Word Search

## Problem

Given an `m x n` character board and a string `word`, return `true` if the word exists in the grid.

- Characters must be adjacent horizontally or vertically.
- Each cell can be used **at most once** in a path.

**Example:**

```
board =
[
  ['A','B','C','E'],
  ['S','F','C','S'],
  ['A','D','E','E']
]

word = "ABCCED"
Output: true
```

---

## Pattern

**Backtracking + DFS**

## Core Idea

- Start DFS from every cell.
- Match the current cell with `word.charAt(index)`.
- If it matches, mark the cell as visited and explore all four directions.
- If any direction finds the remaining word, return `true`.
- After exploring, unmark the cell so other paths can reuse it.

**Why backtracking?**

A cell cannot be reused within the same path, but it must be available when exploring a different path.

---

## Dry Run

### Case 1: Word exists

```
board:
A B C
S F D
A D E

word = "ABF"
```

Start at `(0,0)`:

1. `A` matches `word[0]` → mark visited.
2. Move right to `(0,1)`: `B` matches `word[1]`.
3. Move down to `(1,1)`: `F` matches `word[2]`.
4. All characters matched.

```
Result = true
```

### Case 2: Word does not exist

```
board:
A B
C D

word = "ABCD"
```

1. Match `A` at `(0,0)`.
2. Move right and match `B` at `(0,1)`.
3. From `B`, the only unvisited adjacent cell is `D`.
4. `D` does not match the expected `C`.
5. DFS fails and backtracks.

No path spells `"ABCD"`.

```
Result = false
```

## Code

```java
class Solution {
    public boolean exist(char[][] board, String word) {
        boolean vis = new boolean[board.length][board[0].length];
        for(int i = 0; i < board.length; i++) {
            for(int j = 0; j < board[0].length; j++) {
                if(dfs(i, j, 0, vis, word, board)) {
                    return true;
                }
            }
        }
        return false;
    }

    public boolean dfs(int r, int c, int index, boolean[][] vis,
                       String word, char[][] board) {

        if(index == word.length()) return true;

        int m = board.length;
        int n = board[0].length;

        if(r < 0 || r >= m) return false;
        if(c < 0 || c >= n) return false;
        if(vis[r][c]) return false;
        if(board[r][c] != word.charAt(index)) return false;

        vis[r][c] = true;

        boolean flag =
            dfs(r + 1, c, index + 1, vis, word, board) ||
            dfs(r - 1, c, index + 1, vis, word, board) ||
            dfs(r, c + 1, index + 1, vis, word, board) ||
            dfs(r, c - 1, index + 1, vis, word, board);

        vis[r][c] = false;

        return flag;
    }
}
```

---

## Things to Remember

- `index` tracks the next character to match.
- Check `index == word.length()` first because all characters have been matched.
- Mark a cell before exploring neighbors.
- **Unmark it after exploring** to restore the state for other paths.
- The `||` operator short-circuits: once one direction succeeds, later directions are skipped. In that case, the function returns without unmarking the successful path's cells, but this is harmless here because the search immediately returns `true` and that visited array is discarded.
- Time complexity: \(O(mn \cdot 3^L)\) as a common upper bound for non-empty words, where \(L\) is the word length. The first move has up to four choices, then each move has at most three choices because the previous cell is visited.
- Auxiliary space: \(O(mn + L)\) for the visited matrix and recursion stack.

## One-Line Recall

> Start from every cell, match characters with DFS, mark cells along the path, and unmark them during backtracking.

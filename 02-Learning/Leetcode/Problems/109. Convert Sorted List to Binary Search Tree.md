# 109. Convert Sorted List to Binary Search Tree

## Problem

**Input:**
- Head of a sorted singly linked list

**Output:**
- Height-balanced Binary Search Tree

```
Input:  head = [-10,-3,0,5,9]
Output: A height-balanced BST
```

---

## Pattern

**Fast & Slow Pointer + Divide and Conquer**

---

## Core Idea

- Find the middle node of the list using fast and slow pointers.
- Middle node becomes the root.
- Split the list into two halves.
- Recursively build the left and right subtrees.

---

## Dry Run

```
List:
-10 -> -3 -> 0 -> 5 -> 9

Middle = 0

        0
      /   \
[-10,-3] [5,9]

Repeat recursively.
```

---

## Code

```java
class Solution {
    public TreeNode sortedListToBST(ListNode head) {
        return helper(head);
    }

    public TreeNode helper(ListNode head) {
        if(head == null) {
            return null;
        }

        if(head.next == null) {
            return new TreeNode(head.val);
        }

        ListNode slow = head;
        ListNode slowPrev = null;
        ListNode fast = head;

        while(fast != null && fast.next != null) {
            slowPrev = slow;
            slow = slow.next;
            fast = fast.next.next;
        }

        slowPrev.next = null;

        TreeNode root = new TreeNode(slow.val);

        root.left = helper(head);
        root.right = helper(slow.next);

        return root;
    }
}
```

---

## Things to Remember

- `slow` points to the middle node.
- `slowPrev` is needed to split the list:
  ```java
  slowPrev.next = null;
  ```
- Base case with one node prevents infinite recursion.
- Unlike LC 108 (sorted array), finding the middle takes **O(n)** each recursive call.

---

## One-Line Recall

> Find the middle of the linked list with fast/slow pointers, make it the root, split the list, and recursively build both halves.

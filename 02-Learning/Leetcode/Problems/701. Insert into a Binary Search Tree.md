# 701. Insert into a Binary Search Tree

## Problem

**Input:**
- Root of a Binary Search Tree
- Integer `val`

**Output:**
- Root of the BST after inserting `val`

```
Input:  root = [4,2,7,1,3], val = 5
Output: [4,2,7,1,3,5]
```

---

## Pattern

**BST Insertion**

---

## Core Idea

- Traverse the tree using the BST property.
- When a `null` position is reached, create the new node there.
- Return the root so recursive calls reconnect the modified subtree.

---

## Dry Run

```
        4
      /   \
     2     7
          /
         5

Insert 5

4 < 5 → go right
7 > 5 → go left
null → create node 5
```

---

## Code

```java
class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        if(root == null){
            return new TreeNode(val);
        }

        if(root.val < val){
            root.right = insertIntoBST(root.right, val);
        } else {
            root.left = insertIntoBST(root.left, val);
        }

        return root;
    }
}
```

---

## One-Line Recall

> Follow the BST property until reaching a `null` child, insert the new node there, and return the root to reconnect the tree.

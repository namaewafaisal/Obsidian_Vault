# 77. Combinations

## Problem

Given two integers `n` and `k`, return all possible combinations of `k` numbers chosen from the range `[1, n]`.

Each number can be selected at most once, and the order of numbers within a combination does not matter.

**Example:**

```
Input: n = 4, k = 2

Output:
[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```

---

## Pattern

**Backtracking + Combinations**

## Core Idea

- Start choosing numbers from `1` to `n`.
- Add a number to the current combination.
- Recursively choose the next number, starting from `i + 1`.
- When the combination contains `k` numbers, save a copy.
- Remove the last number to explore other combinations.

**Why `i + 1`?**

It prevents selecting the same number again and ensures combinations are generated in increasing order without duplicates.

```

Backtrack and choose `4`:

```

Remove `1`.

### Step 2: Choose `2`

```
comb = [2]
```

Choose `3`:

```
comb = [2,3]  -> save
```

Choose `4`:

```
comb = [2,4]  -> save
```

### Step 3: Choose `3`

```
comb = [3]
```

Choose `4`:

```
comb = [3,4]  -> save
```

**Final result:**

```
[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```

## Code

```java
class Solution {
    public List<List<Integer>> combine(int n, int k) {
        List<List<Integer>> result = new ArrayList<>();
        List<Integer> comb = new ArrayList<>();

        backtrack(1, n, k, comb, result);

        return result;
    }

    public void backtrack(int start, int n, int k, List<Integer> comb,
                          List<List<Integer>> result) {
        if(comb.size() == k) {
            result.add(new ArrayList<>(comb));
            return;
        }

        for(int i = start; i <= n; i++) {
            comb.add(i);
            backtrack(i + 1, n, k, comb, result);
            comb.remove(comb.size() - 1);
        }
    }
}
```

---

## Things to Remember

- `start` prevents choosing earlier numbers again.
- `backtrack(i + 1, ...)` ensures each number is used at most once.
- `comb.size() == k` is the base case.
- Always save a copy with `new ArrayList<>(comb)`.
- **Backtracking template:** Choose → Explore → Unchoose.
- Number of combinations: \(\binom{n}{k}\).
- Time complexity: \(O(k \cdot \binom{n}{k})\), including copying each combination into the result.
- Auxiliary space: \(O(k)\) for the current combination and recursion stack, excluding output.

## One-Line Recall

> Choose increasing numbers, recurse from `i + 1`, save when the path reaches size `k`, and remove each choice while backtracking.

# 133. Clone Graph

## Problem

**Input:**
- Reference to a node in a connected undirected graph

**Output:**
- Deep copy of the entire graph

```
Input:
1 -- 2
|    |
4 -- 3

Output:
A completely new graph with the same connections.
```

---

## Pattern

**DFS + HashMap (Visited Map)**

---

## Core Idea

- Traverse the graph using DFS.
- Create a clone the first time a node is visited.
- Store the mapping:

```text
original node -> cloned node
```

- If a node is visited again (cycle), return its clone instead of cloning again.
- Recursively clone all neighbors.

---

## Dry Run

```
1
| \
2--3

clone(1)

Create 1'
Map: 1 -> 1'

Clone 2
Create 2'
Map: 2 -> 2'

Clone 1 again
Already in map ✓
Return 1'

Clone 3
...
```

---

## Code

```java
class Solution {
    private Map<Node, Node> map = new HashMap<>();

    public Node cloneGraph(Node node) {
        if (node == null) return null;

        if (map.containsKey(node))
            return map.get(node);

        Node copy = new Node(node.val);
        map.put(node, copy);

        for (Node neighbor : node.neighbors) {
            copy.neighbors.add(cloneGraph(neighbor));
        }

        return copy;
    }
}
```

---

## Things to Remember

- The HashMap acts as both:
  - **Visited set**
  - **Original → Clone mapping**
- Put the cloned node into the map **before** exploring neighbors to avoid infinite recursion on cycles.
- Never reuse original nodes—always connect cloned nodes.

---

## One-Line Recall

> DFS the graph, clone each node once, store the original-to-clone mapping, and reuse cloned nodes whenever a cycle is encountered.

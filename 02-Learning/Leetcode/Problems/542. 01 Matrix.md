# 542. 01 Matrix

## Problem

Given a binary matrix `mat`, return a matrix where each cell contains the distance to the nearest `0`.

Distance is measured using four-directional movement: up, down, left, and right.

**Example:**

```
Input:
0 0 0
0 1 0
1 1 1

Output:
0 0 0
0 1 0
1 2 1
```

---

## Pattern

**Multi-Source BFS + Shortest Path**

## Core Idea

Instead of running BFS separately from every `1`, start BFS from **all zeros simultaneously**.

1. Add every `0` cell to the queue.
2. Mark every `1` as `-1` to indicate it is unvisited.
3. Process cells level by level using BFS.
4. When an unvisited neighbor is found, assign its distance as the current cell's distance plus one.
5. Add that neighbor to the queue.

Because BFS explores cells in increasing distance order, the first time a cell is visited, its distance to the nearest zero is guaranteed to be minimum.

---

## Dry Run

### Case 1

```
Input:
0 0 0
0 1 0
1 1 1
```

**Step 1 — Initialize the queue**

All zero cells are added to the queue. Every `1` becomes `-1`.

```
0  0  0
0 -1  0
-1 -1 -1
```

**Step 2 — Process the queue**

The cell `(1,1)` is adjacent to zeros, so:

```
mat[1][1] = mat[1][0] + 1 = 1
```

The bottom-left cell `(2,0)` is reached from `(1,0)`:

```
mat[2][0] = 0 + 1 = 1
```

The bottom-middle cell `(2,1)` is reached from `(2,0)` or `(1,1)`:

```
mat[2][1] = 1 + 1 = 2
```

The bottom-right cell `(2,2)` is adjacent to `(1,2)`, which is zero:

```
mat[2][2] = 0 + 1 = 1
```

**Final matrix:**

```
0 0 0
0 1 0
1 2 1
```

## Code

```java
class Solution {
    public int[][] updateMatrix(int[][] mat) {
        int m = mat.length;
        int n = mat[0].length;

        Queue<int[]> q = new ArrayDeque<>();

        for(int i = 0; i < m; i++) {
            for(int j = 0; j < n; j++) {
                if(mat[i][j] == 1)
                    mat[i][j] = -1;
                else
                    q.add(new int[] {i, j});
            }
        }

        int[][] directions = {
            {0, 1}, {0, -1}, {1, 0}, {-1, 0}
        };

        while(!q.isEmpty()) {
            int[] cell = q.poll();

            for(int[] dir : directions) {
                int nr = dir[0] + cell[0];
                int nc = dir[1] + cell[1];

                if(nr >= 0 && nr < m &&
                   nc >= 0 && nc < n &&
                   mat[nr][nc] == -1) {

                    mat[nr][nc] = mat[cell[0]][cell[1]] + 1;
                    q.add(new int[] {nr, nc});
                }
            }
        }

        return mat;
    }
}
```

## Things to Remember

- **Multi-source BFS:** Initialize the queue with every source cell (`0`).
- Mark unvisited cells with `-1` so each cell is enqueued at most once.
- Assign the neighbor's distance as `current distance + 1`.
- No separate `visited` array is required because updating `-1` marks a cell as visited.
- Time complexity: \(O(mn)\).
- Auxiliary space: \(O(mn)\) for the queue in the worst case.
- The input matrix is modified in place.

## One-Line Recall

> Start BFS from every zero simultaneously and expand outward, assigning each unvisited cell its parent's distance plus one.

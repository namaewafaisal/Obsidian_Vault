# 59. Spiral Matrix II

## Problem (LeetCode Statement)

**Input:**
- `int n` — size of the matrix

**Output:**
- `n x n` matrix filled with elements 1 to n² in spiral order

**Task:**
Generate a square matrix filled with numbers 1 to n² written in spiral (clockwise) order from the outside in.

---

## Constraints

- `1 <= n <= 20`
- Must fill exactly n² cells in order

---

## Examples
```
Input:  n = 3
Output: [[1,2,3],
         [8,9,4],
         [7,6,5]]
```
```
Input:  n = 1
Output: [[1]]
```

---

## What Actually Matters

- Identical mechanism to Spiral Matrix I — same 4 shrinking boundaries, same traversal order
- Only difference: instead of reading values, write `num++` at each position
- The 3rd and 4th directions need guards (`if top <= bottom`, `if left <= right`) — for odd `n`, a single row or column remains in the center and only one direction should handle it
- Boundary must shrink immediately after each direction completes

---

## Core Insight

> Maintain 4 boundaries (top, bottom, left, right) and shrink each after traversal. At every cell just write the next incrementing number instead of reading it.

---

## Invariant / Mental Model

> After each of the 4 directional passes, the corresponding boundary shrinks inward by 1. The while condition `left <= right && top <= bottom` ensures you stop exactly when all cells are filled.

---

## Thinking Log (Evolution of the Solution)

- **Initial Thought:** Exactly like Spiral I — same 4-direction loop with shrinking boundaries, just write instead of read
- **Key Concern:** Two problems identified — boundary tracking and index tracking. Both solved by the same mechanism as Spiral I
- **Realization:** The output index tracking is implicit — `num++` at each step naturally fills in spiral order as long as boundaries are correct
- **Final Realization:** Guards on move-left and move-up directions handle the odd `n` case where a single center row or column remains

---

## Algorithm (High Level)

1. Initialize `top=0, bottom=n-1, left=0, right=n-1` and counter `num=1`
2. While `left <= right && top <= bottom`, traverse all 4 directions writing `num++`:
   - Left→right along top, then `top++`
   - Top→bottom along right, then `right--`
   - Right→left along bottom (if `top <= bottom`), then `bottom--`
   - Bottom→top along left (if `left <= right`), then `left++`
3. Return the filled matrix

---

## Code (Reference Only)
```java
class Solution {
    public int[][] generateMatrix(int n) {
        int i = 1;
        int[][] matrix = new int[n][n];
        int left = 0, right = n - 1;
        int top = 0, bottom = n - 1;
        while (left <= right && top <= bottom) {
            for (int col = left; col <= right; col++) {
                matrix[top][col] = i++;
            }
            top++;

            for (int row = top; row <= bottom; row++) {
                matrix[row][right] = i++;
            }
            right--;

            if (top <= bottom) {
                for (int col = right; col >= left; col--) {
                    matrix[bottom][col] = i++;
                }
                bottom--;
            }

            if (left <= right) {
                for (int row = bottom; row >= top; row--) {
                    matrix[row][left] = i++;
                }
                left++;
            }
        }
        return matrix;
    }
}
```

---

## Edge Cases to Recall

- `n = 1` → single cell, loop runs once, writes 1, both guards prevent extra traversal
- Odd `n` → center row handled by left→right pass, guard on move-up prevents double-writing
- Even `n` → no single center cell, all 4 directions always valid, guards never trigger

> Same 4-boundary spiral as Spiral I — just write `num++` instead of reading, with guards on directions 3 and 4 for odd `n`.

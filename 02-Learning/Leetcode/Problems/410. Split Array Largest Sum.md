# 410. Split Array Largest Sum

## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`  
- Integer `k`

**Output:**  
- Minimum possible largest sum among `k` subarrays  

**Task:**  
Split array into exactly `k` contiguous subarrays such that the **maximum subarray sum is minimized**

---

## Constraints

- Must be better than brute force
- Brute force splitting → exponential
- Use binary search → O(n log sum)

---

## Examples

```
Input:  nums = [7,2,5,10,8], k = 2
Output: 18
```

---

## What Actually Matters

- You are minimizing the **maximum subarray sum**
- This is not about splitting directly
- It’s about **finding the best possible answer**
- Valid answers lie between:
  - `max(nums)` → minimum possible
  - `sum(nums)` → maximum possible

---

## Core Insight

> Binary search on answer + greedy check

---

## Invariant / Mental Model

> For a given `mid` (max allowed sum):
- Try to split array
- Count how many subarrays are needed

If:
- needed > k → mid too small
- needed ≤ k → mid valid (try smaller)

---

## Thinking Log (Your Style)

- Initial Thought:  
  Try all splits

- Issue:  
  Too many combinations

- Realization:  
  Answer lies in a range → not exact construction

- Key Insight:  
  Binary search on max sum

- Final Understanding:  
  Use greedy to validate each candidate

---

## Algorithm (High Level)

1. Set:
   - `low = max(nums)`
   - `high = sum(nums)`
2. Binary search:
   - mid = candidate max sum
   - find how many subarrays needed
3. If more than k:
   - increase low
4. Else:
   - try smaller → reduce high
5. Return low

---

## Code (Reference Only)

```java
class Solution {
    public int splitArray(int[] nums, int k) {
        if(nums.length < k) return -1;

        int low = Integer.MIN_VALUE;
        int high = 0;

        for(int i : nums) {
            high += i;
            low = Math.max(low, i);
        }

        while(low <= high) {
            int mid = (high + low) / 2;

            int n = findArrays(nums, mid);

            if(n > k) {
                low = mid + 1;
            }
            else {
                high = mid - 1;
            }
        }
        return low;
    }

    public int findArrays(int[] nums, int mid) {
        int array = 1;
        int currArray = 0;

        for(int i = 0; i < nums.length; i++) {
            if(currArray + nums[i] <= mid) {
                currArray += nums[i];
            }
            else {
                array++;
                currArray = nums[i];
            }
        }
        return array;
    }
}
```

## Edge Cases to Recall

- k = 1 → answer = total sum
- k = n → answer = max element
- Large numbers → watch overflow in sum

---

## One-Line Recall

> Binary search the answer and use greedy to check how many splits are needed

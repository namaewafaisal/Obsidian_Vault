# 2652. Sum of Multiples

## Problem (LeetCode Statement)

**Input:**
- `int n` — positive integer

**Output:**
- Sum of all integers in range `[1, n]` divisible by 3, 5, or 7

**Task:**
Find the sum of every number from 1 to n that is a multiple of 3, 5, or 7.

---

## Constraints

- `1 <= n <= 1000`

---

## Examples
```
Input:  n = 7
Output: 21  (3+5+6+7)
```
```
Input:  n = 10
Output: 40  (3+5+6+7+9+10)
```

---

## What Actually Matters

- A number divisible by multiple of 3, 5, 7 should only be counted once — OR condition handles this naturally
- Simple linear scan is O(n) and perfectly sufficient given constraints

---

## Core Insight

> Single pass from 3 to n — add `i` to sum if divisible by 3, 5, or 7. OR condition prevents double counting.

---

## Invariant / Mental Model

> Each number is checked once and added at most once regardless of how many of 3, 5, 7 divide it.

---

## Algorithm (High Level)

1. Initialize `sum = 0`
2. Loop `i` from 3 to n
3. If `i % 3 == 0 || i % 5 == 0 || i % 7 == 0` → add to sum
4. Return sum

---

## Code (Reference Only)
```java
class Solution {
    public int sumOfMultiples(int n) {
        int sum = 0;
        for (int i = 3; i <= n; i++) {
            if (i % 3 == 0 || i % 5 == 0 || i % 7 == 0) {
                sum += i;
            }
        }
        return sum;
    }
}
```

---

## Edge Cases to Recall

- `n < 3` → loop never runs → return 0
- Numbers divisible by multiple bases (e.g. 15 = 3×5) → counted once due to OR

---

## One-Line Recall

> Loop 3 to n, add i if divisible by 3, 5, or 7 — OR prevents double counting.

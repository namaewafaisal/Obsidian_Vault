### Problem (summary)

Given two strings `s` and `t` of lengths `m` and `n`, return the minimum window substring of `s` such that every character in `t` (including duplicates) is included in the window. If no such substring exists, return an empty string.

---

### Key Invariant

* **The "Satisfied" Condition:** A window is valid only when the count of every unique character in  is matched or exceeded by its count in the current window of .
* **Expansion vs. Contraction:** We expand the `right` pointer to find a valid window. Once valid, we contract the `left` pointer as much as possible to find the *minimal* version of that window before it becomes invalid again.

---

### Thinking Log (Evolution of the Solution)

* **Initial Observation:** Finding all substrings is , which is too slow. Since we need a contiguous range that meets a frequency criteria, **Sliding Window** is the optimal choice.
* **Frequency Tracking:** We need to know what  requires. Two HashMaps (or frequency arrays) track the counts of characters in  and the current window in .
* **Avoiding Re-scans:** Instead of checking the whole map every time the window moves, we use a `satisfied` counter. It increments only when the count of a specific character in the window **exactly matches** the required count in .
* **The Java Object Trap:** Since we are using `Map<Character, Integer>`, the `.get()` method returns an `Integer` object. Comparing these with ` ==` fails for counts  due to Java's Integer Cache. We must use `.equals()`.
* **Shrinking Logic:** Once `satisfied == required`, the window is valid. We record the minimum size and start index, then move `left` forward. If removing a character makes its count drop below the required frequency, we decrement `satisfied` and go back to expanding.
* **Final Output:** Instead of building a `char[]` manually, `s.substring(minLeft, minLeft + minSize)` is the most idiomatic and efficient way to return the result.

---

### Implementation Strategy

1. Initialize `tMap` with character frequencies from `t`.
2. Set `required = tMap.size()` and `satisfied = 0`.
3. Use two pointers `left` and `right`. Expand `right`:
* Add `s.charAt(right)` to `sMap`.
* If the count matches `tMap`, increment `satisfied`.


4. While `satisfied == required`:
* Update `minSize` and `minLeft` if the current window is smaller.
* Retrieve `chl = s.charAt(left)`.
* If `chl` is a required character and its count is about to drop below `tMap`'s requirement, decrement `satisfied`.
* Decrement `chl` count in `sMap` and increment `left`.


5. Return the substring based on `minLeft` and `minSize`.

---

### Code (Java)

```java
class Solution {
    public String minWindow(String s, String t) {
        int m = s.length();
        int n = t.length();
        if(n > m) {
            return "";
        }
        
        Map<Character, Integer> sMap = new HashMap<>();
        Map<Character, Integer> tMap = new HashMap<>();

        int right = 0;
        int left = 0;

        int required = 0;
        int satisfied = 0;

        int minSize = Integer.MAX_VALUE;
        int minLeft = 0;

        for(int i = 0; i < n; i++) {
            char curr = t.charAt(i);
            tMap.put(curr, tMap.getOrDefault(curr, 0) + 1);
        }
        required = tMap.size();

        while(right < m) {
            char curr = s.charAt(right);
            sMap.put(curr, sMap.getOrDefault(curr, 0) + 1);
            
            // Critical: Use .equals() for Integer objects to avoid cache issues
            if(tMap.containsKey(curr) && sMap.get(curr).equals(tMap.get(curr))) {
                satisfied++;
            }

            while(satisfied == required) {
                if(minSize > right - left + 1) {
                    minLeft = left;
                    minSize = right - left + 1;
                }
                
                char chl = s.charAt(left++);
                sMap.put(chl, sMap.get(chl) - 1);
                
                if(tMap.containsKey(chl) && sMap.get(chl) < tMap.get(chl)) {
                    satisfied--;
                }
                
                if(sMap.get(chl) == 0) {
                    sMap.remove(chl);
                }
            }
            right++;
        }
        
        return minSize == Integer.MAX_VALUE ? "" : s.substring(minLeft, minLeft + minSize);
    }
}

```

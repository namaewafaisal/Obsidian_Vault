# 1695. Maximum Erasure Value

## Problem

**Input:**
- Integer array `nums`

**Output:**
- Maximum possible sum of a subarray containing only unique elements

```
Input:  [4,2,4,5,6]
Output: 17
```

---

## Pattern

**Sliding Window + HashSet**

---

## Core Idea

- Maintain a window with **only unique elements**.
- Expand the right pointer.
- If a duplicate appears, shrink the left pointer until the duplicate is removed.
- Track the current window sum and update the maximum.

---

## Dry Run

```
nums = [4,2,4,5,6]

Window:
[4]
sum = 4

[4,2]
sum = 6

Next = 4 (duplicate)

Remove 4
Window:
[2]

Add 4
Window:
[2,4]
sum = 6

Add 5
Window:
[2,4,5]
sum = 11

Add 6
Window:
[2,4,5,6]
sum = 17

Answer = 17
```

---

## Code

```java
class Solution {
    public int maximumUniqueSubarray(int[] nums) {

        Set<Integer> set = new HashSet<>();
        int l = 0;
        int r = 0;
        int sum = 0;
        int currSum = 0;

        while(r < nums.length) {
            int rightElem = nums[r];

            while(set.contains(rightElem)) {
                int leftElem = nums[l++];
                set.remove(leftElem);
                currSum -= leftElem;
            }

            set.add(rightElem);
            currSum += rightElem;

            sum = Math.max(sum, currSum);
            r++;
        }

        return sum;
    }
}
```

---

## Things to Remember

- The window invariant is:

```text
All elements inside the window are unique.
```

- Shrink only until the duplicate is removed.
- Maintain the window sum while expanding and shrinking to avoid recomputing it.

---

## One-Line Recall

> Expand the window, remove elements until it becomes unique again, maintain the running sum, and keep the maximum.

# 96. Unique Binary Search Trees

## Problem (LeetCode Statement)

**Input:**  
- Integer `n`

**Output:**  
- Number of structurally unique BSTs that store values `1...n`

**Task:**  
Count how many different BST structures can be formed using `n` nodes

---

## Constraints

- n ≤ 19
- Must avoid generating actual trees
- Need efficient counting → DP

---

## Examples

```
Input:  n = 3
Output: 5
```

---

## What Actually Matters

- BST property splits tree into:
  - left subtree (values < root)
  - right subtree (values > root)
- Structure depends only on **count of nodes**, not actual values
- Every node can be chosen as root

---

## Core Insight

> Fix each node as root → left × right combinations

---

## Invariant / Mental Model

> For any `i` nodes:
- Choose `root`
- Left subtree size = `root - 1`
- Right subtree size = `i - root`

Total trees:
```
dp[i] += dp[left] * dp[right]
```

---

## 🔥 Thinking (This is the KEY part)

Let’s say `n = 3`

Possible roots:

### Root = 1
- left = 0 nodes → dp[0]
- right = 2 nodes → dp[2]

Ways = dp[0] * dp[2]

---

### Root = 2
- left = 1
- right = 1

Ways = dp[1] * dp[1]

---

### Root = 3
- left = 2
- right = 0

Ways = dp[2] * dp[0]

---

### Total

```
dp[3] = dp[0]*dp[2] + dp[1]*dp[1] + dp[2]*dp[0]
```

👉 This is exactly what your code does.

---

## 🧠 Why Multiplication?

Because:
- Left subtree can be built in `dp[left]` ways
- Right subtree can be built in `dp[right]` ways

👉 For each left × each right → combinations

---

## 🧠 Why dp[0] = 1 ?

Very important:

> Empty tree is considered 1 valid structure

Otherwise multiplication breaks:
```
dp[1] = dp[0] * dp[0] = 1
```

---

## Algorithm (High Level)

1. Initialize:
   - dp[0] = 1
   - dp[1] = 1
2. For each `i` from 2 → n:
   - Try all roots
   - Add combinations
3. Return dp[n]

---

## Code (Reference Only)

```java
class Solution {
    public int numTrees(int n) {
        long[] dp = new long[n + 1];

        dp[0] = 1;
        dp[1] = 1;

        for(int i = 2; i <= n; i++) {
            for(int root = 1; root <= i; root++) {
                dp[i] += dp[root - 1] * dp[i - root];
            }
        }

        return (int) dp[n];
    }
}
```

---

## Edge Cases to Recall

- n = 0 → 1 (empty tree)
- n = 1 → 1
- n = 2 → 2

---

## 🔗 Pattern Recognition

This is **Catalan Number**

Formula:
```
C(n) = Σ C(left) * C(right)
```

Appears in:
- BST count
- valid parentheses
- polygon triangulation

---

## One-Line Recall

> For each root, multiply ways of left and right subtree and sum over all roots

# 16. 3Sum Closest

## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`
- Integer `target`

**Output:**  
- Integer representing the sum of three elements closest to `target`

**Task:**  
Find three distinct elements whose sum is closest to `target`.  
Return the **sum**, not the indices or the triplet.

---

## Constraints

- `3 ≤ nums.length ≤ 1000`
- `-10^4 ≤ nums[i] ≤ 10^4`
- Exactly one closest sum exists

---

## Examples

```
Input:  nums = [-1,2,1,-4], target = 1
Output: 2
```

---

## What Actually Matters

- We return the **sum**, not distance or triplet
- Array can be sorted (indices not required)
- Pointer movement logic is identical to 3Sum

---

## Core Insight

> Pointer movement decides *where to search*; absolute difference only decides *which answer is best*.

---

## Invariant / Mental Model

> Pointer movement depends only on `sum` vs `target`, never on closeness.

---

## Thinking Log (Evolution of the Solution)

### Initial Thought (your words)

> This is like 3Sum.  
> Earlier I exited when I saw the exact answer.  
> Now I have to save the closest sum and continue.  
>  
> Sort first, fix one index, use two pointers.  
> Calculate the difference between the sum and target and pick the minimum.  
> Since we don’t need indices, I can just track the difference.  
>  
> I had an issue where I returned the difference instead of the sum and had to debug.

---

### Correction / Refinement

- The **difference is only a metric**, not the answer
- The **answer is the sum** that produced the smallest difference
- Returning the difference answers the wrong question
- Pointer movement must stay **exactly the same as 3Sum**

Correct rule:

> Whenever a smaller `|sum − target|` is found, update the stored **best sum**.

---

## Algorithm (High Level)

1. Sort the array
2. Fix one index `i`
3. Use two pointers on the suffix
4. Update best sum if closer
5. Move pointers based on `sum` vs `target`
6. Return stored best sum

---

## Code (Reference Only)

```java
class Solution {
    public int threeSumClosest(int[] nums, int target) {
        Arrays.sort(nums);
        int dif = Integer.MAX_VALUE;
        int result = 0;

        for (int i = 0; i < nums.length - 2; i++) {
            int left = i + 1;
            int right = nums.length - 1;

            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                int curDif = Math.abs(sum - target);

                if (curDif < dif) {
                    dif = curDif;
                    result = sum;
                }

                if (sum > target) right--;
                else left++;
            }
        }
        return result;
    }
}
```

## Edge Cases to Recall

- All numbers positive or negative
- Target outside possible sum range
- Exact match exists but must still track properly

---

## One-Line Recall

> Use 3Sum pointer movement, but store the sum that minimizes `|sum − target|`.

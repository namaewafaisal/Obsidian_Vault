## LC 125 — Valid Palindrome

| **Metric**     | **Value**                  |
| -------------- | -------------------------- |
| **Date**       | December 29, 2025          |
| **Time Taken** | 10 minutes                 |
| **Difficulty** | Easy                       |
| **Pattern**    | Two Pointers (Inward Scan) |

---

### Problem (summary)

A phrase is a **palindrome** if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward. Alphanumeric characters include letters and numbers.

---

### Key Invariant

* **Symmetry Check:** At any step , the character at  must match the character at  after normalization.
* **Skip Logic:** Any character not satisfying `isLetterOrDigit` is bypassed; it does not participate in the palindrome symmetry.

---

### Thinking Log (Evolution of the Solution)

* **Initial Observation:** A palindrome reads the same from both ends. This naturally suggests **two pointers**: one from the beginning, one from the end.
* **First Naive Thought:** Compare characters at `left` and `right` and move inward.
* *Problem noticed:* Input contains uppercase, lowercase, digits, and punctuation/spaces. Direct comparison will fail.


* **Refinement 1 — Normalization:** Characters must be compared **case-insensitively**. Convert characters to lowercase during the comparison.
* **Refinement 2 — Ignoring Invalid Characters:** Non-alphanumeric characters should be ignored entirely.
* *Correction:* Do not preprocess the string (which costs  space). Skip invalid characters **on the fly** using pointer movement.


* **Key Insight:** Pointer movement becomes conditional. Move `left` until it hits a valid char; move `right` until it hits a valid char. Only then compare.
* **Termination Reasoning:** If pointers cross without any mismatch, all valid pairs matched. The middle character (in odd-length strings) is irrelevant.
* **Final Mental Model:** Skip invalid  normalize  compare  move inward. Repeat until pointers cross or mismatch occurs.

---

### Implementation Strategy

1. Initialize `left = 0` and `right = s.length() - 1`.
2. Use a `while` loop that runs while `left < right`.
3. Inside, use nested `while` loops to increment `left` and decrement `right` as long as they point to non-alphanumeric characters (ensure `left < right` check is maintained here too).
4. Compare `Character.toLowerCase(s.charAt(left))` and `Character.toLowerCase(s.charAt(right))`.
5. If they don't match, return `false`. Otherwise, move both pointers inward.

---

### Final Code (Java)

```java
class Solution {
    public boolean isPalindrome(String s) {
        int left = 0;
        int right = s.length() - 1;

        while (left < right) {
            // Move left pointer to the next alphanumeric character
            while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
                left++;
            }
            // Move right pointer to the previous alphanumeric character
            while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
                right--;
            }

            // Perform case-insensitive comparison
            if (Character.toLowerCase(s.charAt(left)) != Character.toLowerCase(s.charAt(right))) {
                return false;
            }

            left++;
            right--;
        }
        return true;
    }
}

```

# 134. Gas Station

## Problem (LeetCode Statement)

**Input:**  
- Integer arrays `gas` and `cost`

**Output:**  
- Starting index if you can complete the circuit  
- Otherwise `-1`

**Task:**  
Find a starting gas station such that you can travel around the circuit once

---

## Constraints

- Must be O(n)
- Brute force (trying every start) is O(n²) → too slow

---

## Examples

```
Input:
gas  = [1,2,3,4,5]
cost = [3,4,5,1,2]

Output:
3
```

---

## What Actually Matters

- At each index → net gain = `gas[i] - cost[i]`
- If total sum < 0 → impossible
- If tank becomes negative → current start is invalid
- Order is circular but handled linearly

---

## Core Insight

> If you fail at index `i`, then any start between previous start and `i` is also invalid

---

## Invariant / Mental Model

> While iterating:
- `tank` = current fuel from chosen start
- If `tank < 0` → cannot reach next → reset start
- `total` tracks overall feasibility

---

## Thinking Log (Your Style)

- Initial Thought:  
  Try starting from each index

- Issue:  
  Too slow → O(n²)

- Observation:  
  If I fail somewhere, that path is useless

- Key Realization:  
  If I can’t reach `i+1`, none of the previous starts can either

- Final Understanding:  
  Greedily reset start whenever tank goes negative

---

## Algorithm (High Level)

1. Initialize:
   - `tank = 0`
   - `total = 0`
   - `start = 0`
2. Loop through array:
   - Compute `diff = gas[i] - cost[i]`
   - Add to `tank` and `total`
   - If `tank < 0`:
     - reset start = i + 1
     - reset tank = 0
3. If `total >= 0` → return start  
   else → return -1

---

## Code (Reference Only)

```java
class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) {
        int n = gas.length;
        int tank = 0;
        int start = 0;
        int total = 0;

        for(int i = 0; i < n; i++) {
            int diff = gas[i] - cost[i];
            total += diff;
            tank += diff;

            if(tank < 0) {
                start = i + 1;
                tank = 0;
            }
        }

        return total >= 0 ? start : -1;
    }
}
```

---

## Edge Cases to Recall

- Total gas < total cost → always -1
- Single station
- Large dips early → forces reset

---

## One-Line Recall

> Track running fuel, reset start when tank goes negative, and check total feasibility

## LC 1876. Substrings of Size Three with Distinct Characters

| **Metric** | **Value** |
| --- | --- |

### Problem (summary)

A string is **good** if there are no repeated characters. Given a string `s`, return the number of **good substrings** of length **three**.

---

### Example

Input: `s = "xyzzaz"`

Output: `1`

Explanation: There are 4 substrings of size 3: "xyz", "yzz", "zza", and "zaz". Only "xyz" has distinct characters.

---

### Pattern Classification

* Sliding Window (Fixed Size )
* Hash Map / Frequency Counting
* Substring Validation

---

### Key Invariant

* The window size  must be maintained at exactly 3.
* A window is "good" if the number of unique entries in the frequency map is equal to 3.

---

### Thinking Log (Evolution of the Solution)

* **Initial Thought:** Use `s.substring(i, i+3)` in a loop and check each character.
* *Correction:* While simple for , it involves creating many string objects. A sliding window with a frequency map is more idiomatic and scales better if  were larger.
* **Early Confusion:** Do I need a full `HashMap` for just 3 characters?
* *Correction:* For , a simple `if` check `(s[i] != s[i+1] && s[i] != s[i+2] && s[i+1] != s[i+2])` is faster, but using the `HashMap` template reinforces the sliding window pattern for harder problems.
* **Key Insight:** This is a restricted version of **LC 3 (Longest Substring Without Repeating Characters)**. Instead of finding the *longest* window, we are counting how many windows of a *fixed size* meet the "unique" criteria.

---

### Implementation Strategy

1. Initialize a frequency map, `left` pointer, and `count`.
2. **Expand:** Move the `right` pointer and increment the frequency of `s.charAt(right)`.
3. **Window Hit:** Once `right - left + 1 == 3`:
* Check if `freq.size() == 3`. If yes, increment `count`.
* **Slide:** Decrement the frequency of `s.charAt(left)`. If the frequency reaches 0, remove the key from the map entirely to keep `size()` accurate.
* Increment `left`.



---

### Code

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int countGoodSubstrings(String s) {
        Map<Character, Integer> freq = new HashMap<>();

        int left = 0, right = 0;
        int count = 0;
        int size = s.length();
        int k = 3;

        while(right < size) {
            char r = s.charAt(right);
            freq.put(r, freq.getOrDefault(r, 0) + 1);

            // Window reaches the fixed size k
            if(right + 1 - left == k) {
                // If map size is k, all characters in the window are distinct
                if(freq.size() == k) {
                    count++;
                }
                
                // Prepare to slide: remove the leftmost character
                char l = s.charAt(left);
                freq.put(l, freq.get(l) - 1);
                if(freq.get(l) == 0) {
                    freq.remove(l);
                }
                left++;
            }
            right++;
        } 
        return count;
    }
}

```

# 419. Battleships in a Board

## Problem

Given an `m x n` board containing `'X'` (battleship) and `'.'` (empty), count the number of battleships.

Battleships are placed horizontally or vertically, and ships do not touch each other diagonally.

**Example:**

```
Input:
X..X
...X
...X

Output: 2
```

---

## Pattern

**DFS + Connected Components**

## Core Idea

- Traverse every cell in the board.
- Whenever an unvisited `'X'` is found:
  - Increment the ship count.
  - Use DFS to visit the entire connected ship.
- Change visited `'X'` cells to `'.'` so the same ship is not counted again.

Each DFS call from the main loop discovers one complete battleship.

---

## Dry Run

### Case 1: Two battleships

```
Board:
X..X
...X
...X
```

**Step 1 — Start at `(0,0)`**

- Find `'X'` → `count = 1`
- DFS marks the ship at `(0,0)` as `'.'`

```
...X
...X
...X
```

**Step 2 — Continue scanning**

- Find `'X'` at `(0,3)` → `count = 2`
- DFS visits the vertically connected cells `(1,3)` and `(2,3)`.

```
....
....
....
```

**Step 3 — Finish scanning**

No unvisited `'X'` remains.

```
Answer = 2
```

### Case 2: Horizontal battleship

```
Board:
XXX
...
```

- Find `'X'` at `(0,0)` → `count = 1`
- DFS visits `(0,1)` and `(0,2)`.
- Both cells are marked as `'.'`.
- No additional ships are counted.

```
Answer = 1
```

## Code

```java
class Solution {
    public int countBattleships(char[][] board) {
        int count = 0;
        int m = board.length;
        int n = board[0].length;

        for(int i = 0; i < m; i++) {
            for(int j = 0; j < n; j++) {
                if(board[i][j] == 'X') {
                    count++;
                    dfs(i, j, board);
                }
            }
        }

        return count;
    }

    public void dfs(int r, int c, char[][] board) {
        if(r < 0 || r >= board.length) return;
        if(c < 0 || c >= board[0].length) return;
        if(board[r][c] == '.') return;

        board[r][c] = '.';

        dfs(r + 1, c, board);
        dfs(r - 1, c, board);
        dfs(r, c + 1, board);
        dfs(r, c - 1, board);
    }
}
```

---

## Things to Remember

- Increment `count` **before** starting DFS, once per undiscovered ship.
- DFS marks every cell belonging to that ship as visited.
- Only horizontal and vertical neighbors are explored.
- The board is modified in place.
- Time complexity: \(O(mn)\).
- Auxiliary space: \(O(mn)\) in the worst case due to the recursive DFS stack.

## One-Line Recall

> Every unvisited `'X'` starts a new ship: count it, then use DFS to mark its entire connected component as visited.

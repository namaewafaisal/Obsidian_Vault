# 205. Isomorphic Strings

## Problem

**Input:**
- Two strings `s` and `t`

**Output:**
- `true` if every character in `s` can be replaced to form `t`
- `false` otherwise

```
Input:  s = "egg", t = "add"
Output: true
```

```
Input:  s = "foo", t = "bar"
Output: false
```

---

## Pattern

**Bidirectional Character Mapping**

---

## Core Idea

- Every character in `s` must map to exactly one character in `t`.
- No two different characters in `s` can map to the same character in `t`.
- Maintain two mappings:
  - `s -> t`
  - `t -> s`

---

## Dry Run

### Case 1

```
s = "egg"
t = "add"

e -> a
g -> d
g -> d ✓

Result: true
```

---

### Case 2

```
s = "foo"
t = "bar"

f -> b
o -> a

Next:
o -> r

Existing mapping:
o -> a

Mismatch

Result: false
```

---

### Case 3

```
s = "ab"
t = "aa"

a -> a

Next:
b -> a

'a' is already mapped from 'a'

Two characters cannot map to the same character.

Result: false
```

---

## Code

```java
class Solution {
    public boolean isIsomorphic(String s, String t) {
        char[] c1 = new char[256];
        char[] c2 = new char[256];

        for(int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            char d = t.charAt(i);

            if (c1[c] != '\0') {
                if (c1[c] != d)
                    return false;
            } else {
                if (c2[d] != '\0')
                    return false;

                c1[c] = d;
                c2[d] = c;
            }
        }

        return true;
    }
}
```

---

## Things to Remember

- One-direction mapping is **not enough**.
- Always verify both:
  - One character maps to only one character.
  - One character cannot receive mappings from multiple characters.
- Using two arrays is faster than using two HashMaps for ASCII characters.

---

## One-Line Recall

> Maintain two-way character mappings so every mapping is one-to-one and consistent.

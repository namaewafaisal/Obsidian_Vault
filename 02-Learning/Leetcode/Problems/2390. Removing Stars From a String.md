# 2390. Removing Stars From a String

## Problem

**Input:**
- String `s` containing lowercase letters and `'*'`

**Output:**
- String after repeatedly removing each `'*'` and the closest non-star character to its left

```
Input:  "leet**cod*e"
Output: "lecoe"
```

---

## Pattern

**Stack Simulation (Using Character Array)**

---

## Core Idea

- Treat the character array as a stack.
- `j` represents the current stack size (next insertion position).
- Normal character → push (`result[j++] = ch`)
- `'*'` → pop (`j--`)
- No extra stack object is needed since the input array itself acts as the stack.

---

## Dry Run

```
Input: "ab*c*d"

a -> [a]
b -> [a,b]
* -> [a]
c -> [a,c]
* -> [a]
d -> [a,d]

Answer: "ad"
```

---

## Code

```java
class Solution {
    public String removeStars(String s) {
        char[] result = s.toCharArray();
        int j = 0;

        for(int i = 0; i < s.length(); i++) {
            if(result[i] == '*') {
                j--;
            } else {
                result[j] = result[i];
                j++;
            }
        }

        return new String(result, 0, j);
    }
}
```

---

## Things to Remember

- `j` is the top of the simulated stack.
- `j--` removes the previously stored character.
- The original array is reused, giving **O(1)** extra space (excluding the output string).

## One-Line Recall

> Simulate a stack using the input character array—push letters, pop on `'*'`, and return the remaining prefix.

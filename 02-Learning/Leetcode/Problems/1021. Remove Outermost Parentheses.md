# 1021. Remove Outermost Parentheses

![1021. Remove Outermost Parentheses.excalidraw](../../../Excalidraw/1021.%20Remove%20Outermost%20Parentheses.excalidraw.md)

## Problem

**Input:**
- A valid parentheses string `s`

**Output:**
- Remove the outermost parentheses from every primitive valid parentheses string

```
Input:  "(()())(())"
Output: "()()()"
```

---

## Pattern

**Balance Counter (Stack Simulation)**

---

## Core Idea

- Maintain the current balance (`open`).
- For `'('`:
  - Append only if already inside a primitive (`open > 0`).
  - Then increment `open`.
- For `')'`:
  - Decrement `open`.
  - Append only if still inside the primitive (`open > 0` after decrement).

The first `'('` and the matching last `')'` of each primitive are skipped.

---

## Dry Run

```
Input:
(()())

open = 0

(  open=0 -> skip, open=1
(  open=1 -> append, open=2
)  open=2 -> append, open=1
(  open=1 -> append, open=2
)  open=2 -> append, open=1
)  open=1 -> skip, open=0

Result:
()()
```

---

## Code

```java
class Solution {
    public String removeOuterParentheses(String s) {
        int open = 0;
        StringBuilder str = new StringBuilder();

        for(char c : s.toCharArray()) {

            if(c == '(' && open++ > 0) {
                str.append('(');
            }

            else if(c == ')' && open-- > 1) {
                str.append(')');
            }
        }

        return str.toString();
    }
}
```

---

## Things to Remember

- `open++ > 0` checks the balance **before** incrementing.
- `open-- > 1` checks the balance **before** decrementing.
- The counter simulates a stack, so no actual stack is needed.

---

## One-Line Recall

> Track the parentheses balance and append only the characters that are not the outermost pair of each primitive.

# 1629. Slowest Key

## Problem (LeetCode Statement)

**Input:**  
- Integer array `releaseTimes`  
- String `keysPressed`

**Output:**  
- Character of the key with the longest press duration  

**Task:**  
Find the key that was pressed for the longest duration.  
If multiple keys have same duration → return lexicographically larger key.

---

## Constraints

- Single pass required → O(n)
- Must handle tie-breaking correctly

---

## Examples

```
Input:
releaseTimes = [9,29,49,50]
keysPressed = "cbcd"

Output:
"c"
```

---

## What Actually Matters

- Duration is:
  - First key → `releaseTimes[0]`
  - Others → `releaseTimes[i] - releaseTimes[i-1]`
- Track maximum duration
- Tie → pick lexicographically larger character

---

## Core Insight

> This is just max tracking with custom tie-breaking

---

## Invariant / Mental Model

> At every step:
- `maxInterval` stores best duration so far
- `candidate` stores index of best key
- Update when:
  - duration is greater
  - OR equal but character is larger

---

## Thinking Log (Your Style)

- Initial Thought:  
  Find longest duration

- Confusion:  
  First key has no previous → special case

- Realization:  
  First duration = releaseTimes[0]

- Next Issue:  
  What if durations tie?

- Final Understanding:  
  Compare characters → pick lexicographically larger

---

## Algorithm (High Level)

1. Initialize:
   - `maxInterval = releaseTimes[0]`
   - `candidate = 0`
2. Loop from index 1:
   - Compute duration
   - If better → update
   - If equal → compare chars
3. Return character at `candidate`

---

## Code (Reference Only)

```java
class Solution {
    public char slowestKey(int[] releaseTimes, String keysPressed) {
        int maxInterval = releaseTimes[0];
        int candidate = 0;

        for(int i = 1; i < releaseTimes.length; i++) {
            int duration = releaseTimes[i] - releaseTimes[i-1];

            if(duration > maxInterval ||
               (duration == maxInterval && keysPressed.charAt(i) > keysPressed.charAt(candidate))) {

                maxInterval = duration;
                candidate = i;
            }
        }

        return keysPressed.charAt(candidate);
    }
}
```

---

## Edge Cases to Recall

- Single key
- All durations equal → pick largest char
- First key is the answer

---

## One-Line Recall

> Track max duration and break ties using lexicographically larger character

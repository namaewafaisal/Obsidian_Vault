# 4. Median of Two Sorted Arrays

## Problem

**Input:**
- Two sorted arrays `nums1` and `nums2`

**Output:**
- Median of the combined sorted array

```
Input:  nums1 = [1,3], nums2 = [2]
Output: 2.0
```

```
Input:  nums1 = [1,2], nums2 = [3,4]
Output: 2.5
```

---

## Pattern

**Binary Search on Partition**

---

## Core Idea

- Instead of merging the arrays, partition them into a **left half** and **right half**.
- Binary search only on the **smaller array**.
- A valid partition satisfies:

```text
l1 <= r2
l2 <= r1
```

where:

- `l1` = largest element on left of nums1
- `r1` = smallest element on right of nums1
- `l2` = largest element on left of nums2
- `r2` = smallest element on right of nums2

Once this condition is true, the median can be computed directly.

## Code

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {

        if(nums1.length > nums2.length){
            return findMedianSortedArrays(nums2, nums1);
        }

        int n = nums1.length;
        int m = nums2.length;

        int low = 0;
        int high = n;

        while(low <= high){

            int cut1 = (low + high) / 2;
            int cut2 = (n + m + 1) / 2 - cut1;

            int l1 = cut1 == 0 ? Integer.MIN_VALUE : nums1[cut1 - 1];
            int r1 = cut1 == n ? Integer.MAX_VALUE : nums1[cut1];

            int l2 = cut2 == 0 ? Integer.MIN_VALUE : nums2[cut2 - 1];
            int r2 = cut2 == m ? Integer.MAX_VALUE : nums2[cut2];

            if(l1 <= r2 && l2 <= r1){

                if((n + m) % 2 == 0){
                    return (Math.max(l1, l2) + Math.min(r1, r2)) / 2.0;
                }

                return Math.max(l1, l2);
            }
            else if(l1 > r2){
                high = cut1 - 1;
            }
            else{
                low = cut1 + 1;
            }
        }

        return 0;
    }
}
```

---

## Things to Remember

- Always binary search on the **smaller array**.
- Left partition contains:

```text
(n + m + 1) / 2
```

elements.

- Handle partitions at array boundaries using:

```java
Integer.MIN_VALUE
Integer.MAX_VALUE
```

- Valid partition:

```text
l1 <= r2
l2 <= r1
```

- If `l1 > r2`, move partition left.
- Otherwise, move partition right.

---

## One-Line Recall

> Binary search the partition of the smaller array until every left element is ≤ every right element, then compute the median from the partition boundaries.

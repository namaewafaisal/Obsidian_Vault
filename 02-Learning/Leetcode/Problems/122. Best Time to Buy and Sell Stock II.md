# 122. Best Time to Buy and Sell Stock II

## Problem (LeetCode Statement)

**Input:**  
- Integer array `prices`

**Output:**  
- Maximum profit obtainable

**Task:**  
Buy and sell the stock any number of times, but you can only hold one stock at a time.

---

## Constraints

- Unlimited transactions
- Cannot hold multiple stocks
- Decisions depend on future days

---

## What Actually Matters

- Every day has two choices:
  - **Act** (buy/sell)
  - **Skip**
- The answer is the maximum profit from the **current day onward**, not profit earned so far.

---

## Core Insight

> Define the state by what information is needed to make future decisions.

State:

```text
(index, canBuy)
```

- `index` → current day
- `canBuy`
  - `1` → currently not holding a stock
  - `0` → currently holding a stock (must sell before buying again)

---

## Invariant / Mental Model

> `dp[index][canBuy]` stores the **maximum future profit** starting from this state.

Think:

```text
"What is the best I can do from today?"
```

NOT

```text
"What is the best profit I have made so far?"
```

---

## Thinking Log

### Initial Thought

Recursively try every possibility:
- Buy / Skip
- Sell / Skip

### Issue

The same state gets computed repeatedly.

Example:

```text
help(5,1)
```

may be reached through multiple paths.

### Correction

Store every solved state:

```text
(index, canBuy)
```

so it is computed only once.

### Final Realization

DP is simply **remembering recursion results**.

---

## Algorithm (High Level)

1. Define recursive state `(index, canBuy)`.
2. Base case:
   - End of array → profit = 0.
3. If state already computed → return it.
4. Otherwise:
   - Buy state:
     - Buy
     - Skip
   - Sell state:
     - Sell
     - Skip
5. Store maximum profit.

---

## Code (Reference Only)

```java
class Solution {
    public int maxProfit(int[] prices) {
        int[][] dp = new int[prices.length][2];

        for(int i = 0; i < prices.length; i++){
            Arrays.fill(dp[i], -1);
        }

        return helper(0, 1, dp, prices);
    }

    public int helper(int index, int canBuy, int[][] dp, int[] prices){

        if(index == prices.length){
            return 0;
        }

        if(dp[index][canBuy] != -1){
            return dp[index][canBuy];
        }

        int profit;

        if(canBuy == 1){
            profit = Math.max(
                -prices[index] + helper(index + 1, 0, dp, prices),
                helper(index + 1, 1, dp, prices)
            );
        }
        else{
            profit = Math.max(
                prices[index] + helper(index + 1, 1, dp, prices),
                helper(index + 1, 0, dp, prices)
            );
        }

        return dp[index][canBuy] = profit;
    }
}
```

# How to Recreate DP for Any Problem

## Step 1 — Write Recursion First

Don't think about DP.

Think:

> "If I were solving this recursively, what information do I need?"

That information becomes the **state**.

Example:

```text
(index, canBuy)
```

---

## Step 2 — Identify the State

Ask:

> What changes between recursive calls?

Those variables become DP dimensions.

Examples:

```text
(index)
(index, canBuy)
(index, remainingTransactions)
(row, col)
(index, target)
```

Rule:

> Every changing parameter belongs in the DP state.

---

## Step 3 — Base Case

Ask:

> When does recursion stop?

Example:

```java
if(index == prices.length)
    return 0;
```

---

## Step 4 — Choices

Every DP is just:

```text
Current State
      ↓
 Possible Choices
      ↓
Take the best answer
```

Here:

```text
Buy
Skip
```

or

```text
Sell
Skip
```

---

## Step 5 — Memoize

Before solving:

```java
if(dp[state] != -1)
    return dp[state];
```

After solving:

```java
return dp[state] = answer;
```

That's all memoization is.

---

# DP Conversion Checklist

Whenever you finish recursion, ask:

- ✅ What is my state?
- ✅ What are my choices?
- ✅ What is my base case?
- ✅ Which recursive parameters change?
- ✅ Those become DP dimensions.

## Tricks to Recognize DP

### Trick 1

If recursion has **overlapping states**, think DP.

---

### Trick 2

If the answer is:

```text
best
minimum
maximum
count
ways
```

it's often DP.

---

### Trick 3

If recursion parameters repeat:

```text
(index, ...)
```

store them.

---

### Trick 4

DP never stores the entire path.

It stores:

> "Best answer from this state."

---

## One-Line Recall

> Write recursion first, identify the changing parameters as the state, cache each state once, and DP appears naturally.

### Problem (summary)

Given  non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

---

### Key Invariant

* **The Lower Bound Rule:** The amount of water at any index is determined by the **shorter** of the two tallest boundaries (left and right).
* **The Process Rule:** If `leftMax < rightMax`, the water trapped at the `left` pointer depends solely on `leftMax` because the `rightMax` is already confirmed to be tall enough to "hold" the water on that side.

---

### Thinking Log (your words, structured)

* **The Core Insight:** The water stored is based on the boundaries, especially the less taller side. At any point, the taller side does not matter if the other side is shorter, because water will spill from that side.
* **Setup:** I start with two pointers, `left = 0` and `right = n - 1`, and maintain running maximums `leftMax` and `rightMax` (both starting at 0).
* **Pointer Movement:** I loop while `left < right`. In each iteration, I update `leftMax` using the current left height and `rightMax` using the current right height.
* **Decision Logic:** Now I decide which side to process:
* If the left boundary is smaller, then the water trapped depends only on the left side. The right side is guaranteed to be tall enough.
* So when the left side is smaller: I add `leftMax - currentLeftHeight` to water and move `left++`.
* Otherwise: I add `rightMax - currentRightHeight` to water and move `right--`.


* **Conclusion:** Once I add water for an index, I never need to look at that index again. I keep doing this until both pointers meet.

---

### Implementation Strategy

1. Initialize `left = 0`, `right = length - 1`, `leftMax = 0`, `rightMax = 0`, and `water = 0`.
2. While `left < right`:
* Update `leftMax` with `Math.max(leftMax, height[left])`.
* Update `rightMax` with `Math.max(rightMax, height[right])`.
* If `leftMax < rightMax`, calculate trapped water at `left` and increment `left`.
* Else, calculate trapped water at `right` and decrement `right`.


3. Return the total `water`.

---

### Final Code (Java)

```java
class Solution {
    public int trap(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int leftMax = 0;
        int rightMax = 0;
        int water = 0;

        while (left < right) {
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);

            // If the left boundary is lower, water level is dictated by leftMax
            if (leftMax < rightMax) {
                water += leftMax - height[left++];
            } 
            // Otherwise, water level is dictated by rightMax
            else {
                water += rightMax - height[right--];
            }
        }
        return water;
    }
}

```

# LC 203. Remove Linked List Elements

## Problem (LeetCode Statement)

**Input:**  
- Head of a singly linked list `head`
- Integer `val`

**Output:**  
- Head of the modified list after removing all nodes with value `val`

**Task:**  
Delete all nodes whose value equals `val` and return the new head.

---

## Constraints

- `0 ≤ number of nodes ≤ 10^4`
- `-10^5 ≤ Node.val ≤ 10^5`
- Must modify links in-place

---

## Examples

```
Input:  head = [1,2,6,3,4,5,6], val = 6
Output: [1,2,3,4,5]
```

```
Input:  head = [], val = 1
Output: []
```

---

## What Actually Matters

- The head itself may need to be removed
- Multiple consecutive nodes may need deletion
- Must relink nodes correctly

---

## Core Insight

> Removing nodes in a linked list is always about correctly updating `next` pointers.

---

## Invariant / Mental Model

> At every step, the list before the current pointer is already cleaned of `val`.

---

## Thinking Log (Evolution of the Solution)

### Initial Thought (likely first instinct)

Traverse the list and whenever `node.val == val`, remove it by skipping it.

---

### Issue

If the head itself has value `val`, removing it is tricky because we lose reference to the new head.

Example:
```
[6,6,1,2]  val = 6
```

We must repeatedly update the head.

---

### Correction

Introduce a **dummy node** before head.

Why:

- It standardizes removal logic
- No special case for head deletion
- Always operate on `prev.next`

---

### Final Realization

> Dummy nodes eliminate head-edge cases and simplify pointer logic.

---

## Algorithm (High Level)

1. Create a dummy node pointing to head
2. Use a `prev` pointer starting at dummy
3. Traverse list:
   - If `prev.next.val == val`, skip it
   - Else move `prev` forward
4. Return `dummy.next`

---

## Code (Reference Only)

```java
class Solution {
    public ListNode removeElements(ListNode head, int val) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        ListNode prev = dummy;

        while (prev.next != null) {
            if (prev.next.val == val) {
                prev.next = prev.next.next;
            } else {
                prev = prev.next;
            }
        }

        return dummy.next;
    }
}
```

---

## Edge Cases to Recall

- Head contains `val`
- All nodes contain `val`
- Empty list
- Consecutive nodes equal to `val`

---

## One-Line Recall

> Use a dummy node so removal logic works uniformly, even when deleting the head.

# 151. Reverse Words in a String

## Problem

**Input:**
- String `s` containing words separated by spaces

**Output:**
- String with the words in reverse order
- Remove leading, trailing, and extra spaces

```
Input:  "  the sky   is blue  "
Output: "blue is sky the"
```

---

## Pattern

**Reverse Traversal + Two Pointers**

---

## Core Idea

- Traverse the string **from right to left**.
- Skip extra spaces.
- Identify one complete word using two pointers.
- Append the word to the result.
- Insert a space only between words.

---

## Dry Run

```
Input:
"  the sky   is blue  "

Skip trailing spaces

Find "blue"
Result: "blue"

Find "is"
Result: "blue is"

Find "sky"
Result: "blue is sky"

Find "the"
Result: "blue is sky the"
```

---

## Code

```java
class Solution {
    public String reverseWords(String s) {

        StringBuilder result = new StringBuilder();
        int size = s.length();
        int r = size;
        int l = r - 1;

        while(l >= 0) {

            while(l >= 0 && s.charAt(l) == ' ') {
                l--;
            }

            if(l < 0) {
                break;
            }

            r = l + 1;

            while(l >= 1 && s.charAt(l - 1) != ' ') {
                l--;
            }

            if(!result.isEmpty())
                result.append(" ");

            result.append(s.substring(l, r));

            l--;
        }

        return result.toString();
    }
}
```

---

## Things to Remember

- Skip consecutive spaces before finding a word.
- `r` stores the index just after the current word.
- `substring(l, r)` extracts the complete word.
- Add spaces **only between words**, not before the first word.

---

## One-Line Recall

> Scan from right to left, extract each word, and append it to the answer while skipping extra spaces.

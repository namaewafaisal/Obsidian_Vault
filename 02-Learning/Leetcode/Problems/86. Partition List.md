# 86. Partition List

## Problem

**Input:** head of a linked list and integer `x`

**Output:** linked list where:
- all nodes with value `< x` come first
- all nodes with value `>= x` come after
- relative order within each group is preserved

```
Input:  head = [1,4,3,2,5,2], x = 3
Output: [1,2,2,4,3,5]
```

---

## Core Insight

> Instead of rearranging nodes in-place, build **two separate lists**:
> - small values
> - large values
>
> Connect them at the end.

---

## Thinking Log

- Initial thought: Move nodes around inside one list.
- Issue: Pointer updates become messy.
- Realization: Build two independent lists while traversing once.
- Final understanding: Dummy nodes remove all edge cases, then simply connect the two lists.

---

## State / Build / Combine

| Step | Action |
|---|---|
| Small list | Nodes with `val < x` |
| Large list | Nodes with `val >= x` |
| Finish | `large.next = null` to avoid old links |
| Combine | `small.next = largeDummy.next` |

---

## Algorithm

1. Create two dummy nodes.
2. Traverse the original list once.
3. Append each node to the appropriate list.
4. Terminate the large list.
5. Connect small list to large list.
6. Return `smallDummy.next`.

---

## Code

```java
class Solution {
    public ListNode partition(ListNode head, int x) {
        ListNode smallDummy = new ListNode(0);
        ListNode largeDummy = new ListNode(0);

        ListNode small = smallDummy;
        ListNode large = largeDummy;

        while(head != null){

            if(head.val < x){
                small.next = head;
                small = small.next;
            }
            else{
                large.next = head;
                large = large.next;
            }

            head = head.next;
        }

        large.next = null;
        small.next = largeDummy.next;

        return smallDummy.next;
    }
}
```

---

## Bugs / Things to Remember

- Always set:

```java
large.next = null;
```

Otherwise old links from the original list may create incorrect connections.

- Dummy nodes simplify handling empty partitions.

---

## One-Line Recall

> Build two linked lists using dummy nodes, then connect the small list to the large list while preserving order.

# 2. Add Two Numbers

## Problem

**Input:**
- Two linked lists `l1` and `l2`
- Digits are stored in reverse order

**Output:**
- Linked list representing their sum (also in reverse order)

```
Input:  l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
```

---

## Pattern

**Dummy Node + Carry Simulation**

---

## Core Idea

- Traverse both lists simultaneously.
- Treat missing nodes as `0`.
- Keep track of carry.
- Create one new node for each digit.
- Continue while either list has nodes **or** carry remains.

---

## Dry Run

```
l1: 2 -> 4 -> 3
l2: 5 -> 6 -> 4

2 + 5 = 7
Result: 7

4 + 6 = 10
Digit = 0
Carry = 1

3 + 4 + 1 = 8
Result: 7 -> 0 -> 8
```

---

## Code

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {

        ListNode result = new ListNode(0);
        ListNode temp = result;
        int carry = 0;

        while(l1 != null || l2 != null || carry != 0){

            int val1 = l1 != null ? l1.val : 0;
            int val2 = l2 != null ? l2.val : 0;

            int sum = val1 + val2 + carry;

            carry = sum - sum % 10;
            sum = sum - carry;
            carry /= 10;

            ListNode curr = new ListNode(sum);
            temp.next = curr;
            temp = curr;

            if(l1 != null) l1 = l1.next;
            if(l2 != null) l2 = l2.next;
        }

        return result.next;
    }
}
```

## One-Line Recall

> Traverse both lists together, simulate digit-by-digit addition with carry, and build the answer using a dummy node.

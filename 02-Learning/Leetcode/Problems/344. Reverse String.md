# 344. Reverse String

## Problem (LeetCode Statement)

**Input:**  
- Character array `s`

**Output:**  
- Reverse the array in-place

**Task:**  
Reverse the given character array without using extra space.

---

## Constraints

- `1 ≤ s.length ≤ 10^5`
- `s[i]` is a printable ASCII character
- Must modify the input array in-place
- `O(1)` extra memory required

---

## Examples

```
Input:  s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]
```

```
Input:  s = ["H","a","n","n","a","h"]
Output: ["h","a","n","n","a","H"]
```

---

## What Actually Matters

- No extra array allowed
- Must swap elements in-place
- Reverse means symmetric swap

---

## Core Insight

> Reversal is symmetric.

The first element swaps with the last,  
second with second-last, and so on.

This naturally leads to a **two-pointer approach**.

---

## Invariant / Mental Model

> Everything before `left` and after `right` is already correctly reversed.

- `left` moves forward
- `right` moves backward
- Stop when they meet

Each swap places two characters in correct final position.

---

## Thinking Log (Evolution of the Solution)

### Initial Understanding (your words)

> “Use left and right pointers and swap until they meet.”

Correct — this is the standard reversal pattern.

---

### Important Detail

Loop condition:
```
while (left < right)
```

Not `<=`, because:
- When they meet at center (odd length), no swap needed

---

## Algorithm (High Level)

1. Initialize:
   - `left = 0`
   - `right = n - 1`
2. While `left < right`:
   - Swap `s[left]` and `s[right]`
   - `left++`
   - `right--`

Time: `O(n)`  
Space: `O(1)`

---

## Code (Reference Only)

```java
class Solution {
    public void reverseString(char[] s) {
        int left = 0;
        int right = s.length - 1;

        while (left < right) {
            char temp = s[left];
            s[left] = s[right];
            s[right] = temp;
            right--;
            left++;
        }
    }
}
```

# 1905. Count Sub Islands

## Problem

Given two binary grids `grid1` and `grid2`, count the number of islands in `grid2` that are completely contained within an island in `grid1`.

- `1` represents land.
- `0` represents water.
- An island consists of horizontally or vertically connected land cells.

An island in `grid2` is a sub-island only if **every land cell in that island also contains land in `grid1`**.

---

## Pattern

**DFS + Connected Components + Grid Comparison**

## Core Idea

- Traverse `grid2` and find every unvisited land cell.
- Start DFS to explore its entire connected component.
- Compare corresponding cells in both grids.
- If any cell in `grid2` is land but the corresponding cell in `grid1` is water, the island is invalid.
- Mark visited cells in `grid2` as `0`.
- Combine the results of all four directions to determine whether the entire island is valid.

**Important:** Even if one cell makes the island invalid, DFS must still visit the remaining cells to avoid counting the same island again.

---

## Dry Run

### Case 1: Valid sub-island

```
grid1:          grid2:

1 1 1           1 1 0
1 1 0           0 1 0
0 0 1           0 0 1
```

Start at `(0,0)` in `grid2`.

1. `(0,0)` → `grid1 = 1`, valid.
2. `(0,1)` → `grid1 = 1`, valid.
3. `(1,1)` → `grid1 = 1`, valid.

All cells belonging to this island exist in `grid1`.

```
Result = true
```

The isolated cell `(2,2)` is also a valid sub-island.

```
Total count = 2
```

### Case 2: Invalid sub-island

```
grid1:          grid2:

1 0             1 1
1 1             1 1
```

Start DFS from `(0,0)`.

| Cell | grid1 value | Result |
|---|---:|---|
| `(0,0)` | 1 | Valid |
| `(0,1)` | 0 | Invalid |
| `(1,0)` | 1 | Valid |
| `(1,1)` | 1 | Valid |

One cell in `grid2` does not exist as land in `grid1`.

```
Result = false
```

The entire island is rejected.

## Code

```java
class Solution {
    public int countSubIslands(int[][] grid1, int[][] grid2) {
        int count = 0;

        for(int i = 0; i < grid2.length; i++) {
            for(int j = 0; j < grid2[0].length; j++) {
                if(grid2[i][j] == 1) {
                    if(reducer(i, j, grid1, grid2)) {
                        count++;
                    }
                }
            }
        }

        return count;
    }

    public boolean reducer(int r, int c, int[][] grid1, int[][] grid2) {
        if(r < 0 || grid2.length - 1 < r) return true;
        if(c < 0 || grid2[0].length - 1 < c) return true;
        if(grid2[r][c] == 0) return true;
        if(grid2[r][c] != grid1[r][c]) return false;

        grid2[r][c] = 0;

        boolean up = reducer(r - 1, c, grid1, grid2);
        boolean down = reducer(r + 1, c, grid1, grid2);
        boolean left = reducer(r, c - 1, grid1, grid2);
        boolean right = reducer(r, c + 1, grid1, grid2);

        return up && down && left && right;
    }
}
```

---

## Things to Remember

- The DFS explores an entire connected component in `grid2`.
- Out of bounds → `true`: moving outside the grid does not invalidate the island.
- Water in `grid2` → `true`: nothing needs to be checked in that direction.
- A mismatch (`grid2 = 1`, `grid1 = 0`) → `false`.
- **Important bug in your implementation:** When a mismatch is found, you return immediately without marking that cell visited or exploring its neighbors. Because of this, the remaining cells of an invalid island can be discovered again by the outer loop and incorrectly counted as separate islands.
- Fix: record the mismatch, but continue exploring all four directions.

A corrected DFS:

```java
public boolean reducer(int r, int c, int[][] grid1, int[][] grid2) {
    if(r < 0 || r >= grid2.length ||
       c < 0 || c >= grid2[0].length) return true;

    if(grid2[r][c] == 0) return true;

    boolean valid = grid1[r][c] == 1;
    grid2[r][c] = 0;

    boolean up = reducer(r - 1, c, grid1, grid2);
    boolean down = reducer(r + 1, c, grid1, grid2);
    boolean left = reducer(r, c - 1, grid1, grid2);
    boolean right = reducer(r, c + 1, grid1, grid2);

    return valid && up && down && left && right;
}
```

- Notice that `&&` is safe in the final return because all four recursive calls have already executed and been stored in variables.
- Time complexity: \(O(mn)\), since every cell in `grid2` is visited at most once.
- Auxiliary space: \(O(mn)\) worst case due to recursive DFS.

## One-Line Recall

> DFS every island in grid2, compare each land cell against grid1, and count the component only if every cell matches.

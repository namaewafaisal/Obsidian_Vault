# 230. Kth Smallest Element in a BST

## Problem

**Input:**
- Root of a Binary Search Tree
- Integer `k`

**Output:**
- The `k`-th smallest element in the BST

```
Input:  root = [3,1,4,null,2], k = 1
Output: 1
```

---

## Pattern

**Inorder Traversal**

---

## Core Idea

- Inorder traversal of a BST visits nodes in **sorted order**.
- Count nodes as you visit them.
- The moment the count reaches `k`, record the answer.

---

## Dry Run

```
        3
       / \
      1   4
       \
        2

Inorder:
1 → 2 → 3 → 4

k = 3

Visit:
1 (count=1)
2 (count=2)
3 (count=3) ✓ answer = 3
```

---

## Code

```java
class Solution {
    int count = 0;
    int answer;

    public int kthSmallest(TreeNode root, int k) {
        inorder(root, k);
        return answer;
    }

    private void inorder(TreeNode root, int k) {
        if(root == null || count >= k) return;

        inorder(root.left, k);

        count++;
        if(count == k) {
            answer = root.val;
            return;
        }

        inorder(root.right, k);
    }
}
```

---

## One-Line Recall

> Inorder traversal of a BST gives sorted order; count visited nodes until reaching the k-th one.

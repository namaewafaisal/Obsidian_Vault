# 992. Subarrays with K Different Integers

## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`  
- Integer `k`

**Output:**  
- Number of subarrays with **exactly k distinct integers**

**Task:**  
Count subarrays where number of distinct elements = k

---

## Constraints

- Brute force O(n²) → too slow
- Must use sliding window
- Distinct count tracking needed → hashmap

---

## Examples

```
Input:  nums = [1,2,1,2,3], k = 2
Output: 7
```

---

## What Actually Matters

- “Exactly k” is hard to track directly
- “At most k” is easy using sliding window
- Key trick:
```
exactly(k) = atMost(k) - atMost(k-1)
```

---

## Core Insight

> Convert “exactly k” into difference of two “at most k” problems

---

## Invariant / Mental Model

> In sliding window:
- Window always has ≤ k distinct elements
- For each `right`, valid subarrays ending at `right` = `right - left + 1`

---

## 🔥 Thinking Log (Your Style)

- Initial Thought:  
  Try to count exactly k directly

- Issue:  
  Hard to maintain exact count dynamically

- Realization:  
  Easier to track ≤ k

- Key Insight:  
  Subtract two ranges

- Final Understanding:  
  Solve using helper function

---

## 🧠 Why `count += right - left + 1` ?

At any `right`:
- All subarrays ending at `right` and starting from `[left → right]` are valid

Count:
```
[right]
[left, right]
[left+1, right]
...
```

Total:
```
right - left + 1
```

---

## Algorithm (High Level)

### Main:
1. Return:
```
atMost(k) - atMost(k-1)
```

---

### Helper (atMost k):

1. Expand right
2. Add element to map
3. Shrink window if distinct > k
4. Add `(right - left + 1)` to result

---

## Code (Reference Only)

```java
class Solution {
    public int subarraysWithKDistinct(int[] nums, int k) {
        return help(nums, k) - help(nums, k - 1);
    }

    public int help(int[] arr, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        int left = 0;
        int count = 0;

        for(int right = 0; right < arr.length; right++) {

            map.put(arr[right], map.getOrDefault(arr[right], 0) + 1);

            while(map.size() > k) {
                map.put(arr[left], map.get(arr[left]) - 1);
                if(map.get(arr[left]) == 0) {
                    map.remove(arr[left]);
                }
                left++;
            }

            count += right - left + 1;
        }

        return count;
    }
}
```

## Edge Cases to Recall

- k = 1 → count subarrays with single distinct
- All elements same
- All elements unique

---

## ⚠️ Common Mistakes

- Trying to directly track “exactly k”
- Forgetting to remove elements when freq = 0
- Missing `(right - left + 1)` logic

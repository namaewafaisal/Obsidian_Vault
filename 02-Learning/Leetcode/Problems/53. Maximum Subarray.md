## LC 53 — Maximum Subarray

### Problem (summary)

Given an integer array `nums`, find the contiguous subarray (containing at least one number) which has the largest sum, and return its sum.

---

### Example

Input: `nums = [-2,1,-3,4,-1,2,1,-5,4]`

Output: `6`

Explanation: The subarray `[4, -1, 2, 1]` has the largest sum.

---

### Pattern Classification

* Prefix-based accumulation
* Greedy decision per index
* Dynamic Programming (space optimized)
* Kadane’s Algorithm

---

### Key Invariant

* At every index `i`, we only care about the maximum subarray sum ending exactly at `i`.
* Any prefix with a negative sum will only reduce the sum of any future subarray.
* Therefore, a negative running sum can be safely discarded.

---

### Thinking Log (Evolution of the Solution)

* **Initial Thought:** Any array problem can be solved using more and more loops by checking all subarrays.
* *Correction:* This leads to **O(n²)** time, which is inefficient.
* **Early Confusion:** This problem feels like a sliding window, but there is no fixed or variable `k`.
* *Correction:* This is not sliding window because there is no "window validity" constraint (like unique characters).
* **Rejected Idea:** Sort the array and start forming subarrays from the largest element.
* *Correction:* Sorting breaks the **contiguous** constraint and ignores the cost of negative numbers in between.
* **Key Doubt:** Retaining a running sum feels unsafe; it seems like we are putting too much faith in not abandoning earlier elements.
* *Correction:* If the running sum before index `i` is negative, it will **always** reduce any future subarray that includes it.
* **Critical Insight:** If `nums[i] + currSum < nums[i]`, then starting fresh from `nums[i]` is always better than extending the previous subarray.

---

### Implementation Strategy

1. Maintain a running sum `currSum` representing the maximum subarray ending at index `i`.
2. At each index, choose between:
* **Extending** the previous subarray: `currSum + nums[i]`
* **Starting fresh**: `nums[i]`


3. Track the global maximum using `maxSum`.

---

### Code

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int currSum = 0;
        int maxSum = Integer.MIN_VALUE;

        for(int i = 0; i < nums.length; i++) {
            // Decision: Extend the previous streak or start a new one?
            currSum = Math.max(nums[i], currSum + nums[i]);
            maxSum = Math.max(maxSum, currSum);
        }

        return maxSum;
    }
}

```

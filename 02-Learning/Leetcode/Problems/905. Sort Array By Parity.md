# 905. Sort Array By Parity

## Problem (LeetCode Statement)

**Input:**  
- Integer array `nums`

**Output:**  
- Same array with all even numbers first, followed by odd numbers

**Task:**  
Rearrange the array so that all even elements come before odd elements (order does not matter)

---

## Constraints

- Must be in-place
- O(n) time expected
- Order is NOT required to be preserved

---

## Examples

```
Input:  [3,1,2,4]
Output: [4,2,1,3] (any valid order)
```

---

## What Actually Matters

- Only grouping matters → not sorting
- Even vs odd → simple condition
- Order does not matter → allows swapping
- This is a **partition problem**, not sorting

---

## Core Insight

> Treat it like partitioning: push evens to left, odds to right

---

## Invariant / Mental Model

> At any point:
- Left side → contains only even numbers
- Right side → contains unchecked or odd numbers

You move:
- `left` → forward when correct
- `right` → backward when incorrect

---

## Thinking Log (Your Style)

- Initial Thought:  
  Maybe sort based on parity

- Issue:  
  Sorting is unnecessary → overkill

- Better Thought:  
  Just separate even and odd

- Realization:  
  Use two pointers from both ends

- Final Understanding:  
  If right has even → bring it to left

---

## Algorithm (High Level)

1. Initialize `left = 0`, `right = n-1`
2. While `left < right`:
   - If right is even:
     - swap with left
     - move left++
   - Else:
     - move right--
3. Return array

---

## Code (Reference Only)

```java
class Solution {
    public int[] sortArrayByParity(int[] nums) {
        int left = 0;
        int right = nums.length - 1;

        while(left < right) {
            if(nums[right] % 2 == 0) {
                swap(left, right, nums);
                left++;
            }
            else {
                right--;
            }
        }
        return nums;
    }

    public void swap(int left, int right, int[] nums) {
        int temp = nums[left];
        nums[left] = nums[right];
        nums[right] = temp;
    }
}
```

---

## Edge Cases to Recall

- All even → no swaps
- All odd → no swaps
- Single element → unchanged

---

## One-Line Recall

> Use two pointers to partition array into evens (left) and odds (right) without caring about order

# What is a Program

A **program** is a set of instructions that tell the computer what to do.  
Its main purpose is to **process data** and **perform tasks**.

Programs collect data, process it, and store results in memory or files.

---

**Example:**
A program that adds two numbers:
```java
int a = 2;
int b = 3;
System.out.println(a + b);
```
**Output** : 5

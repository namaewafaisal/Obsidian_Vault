# `char` Data Type in Java

The **`char`** data type stores a single 16-bit Unicode character.

---

### Overview

- **Size:** 2 bytes (16 bits)
    
- **Range:** 0 to 65,535 (Unicode characters)
    
- **Default Value:** '\u0000' (null character)
    
- **Type Category:** Primitive
    
- **When to Use:**
    
    - To represent characters or Unicode symbols.
        

---

### Example

```java
char grade = 'A';
System.out.println(grade);
```

---

### Notes

- Enclosed in single quotes `' '`.
    
- Internally stores numeric Unicode values (e.g., `'A'` = 65).
    
- Can participate in arithmetic expressions (like adding chars).

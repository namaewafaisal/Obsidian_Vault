# Variables in Java

A **variable** is a container used to store data in a program.  
Every variable has a **name (identifier)**, a **data type**, and a **value**.

Variables must follow Java’s naming rules (no spaces, cannot start with a number, etc.).

---

## 1. Declaration
This step defines the variable and its type.
```java
int a;
```
Here, `a` is a variable of type `int`.
It is not yet given a value, but it holds a default value (0 for integers).

---
## 2. Initialization

Assign a value to the variable using the assignment operator (`=`).
```java
a = 5;
```
 Now `a` has the value `5`
---
## 3. Declaration + Initialization

You can do both in one line:
```java
int a = 5;
```

Database Design — Two Collections

One flat students document for all leaderboard queries. A separate platform_data document for full detail per student per platform.

Collection 1: students
One document per student (~2KB). Used for ALL leaderboard and filter queries. Never joined.
{
  _id: ObjectId,
  roll_number: "21CSE001",
  name: "Mohamed Faisal",
  department: "CSE",
  year: 3,
  is_active: true,

  // platform handles — what the student registered
  handles: { leetcode: "faisal_lc", codeforces: "faisal_cf", ... },

  // denormalized summary — written by sync engine, powers all queries
  lc: {
    solved: 234, easy: 69, medium: 120, hard: 45,
    rating: 1820, contest_rank: 45230,
    last_synced: ISODate("2025-03-18T02:11:00Z"),
    sync_status: "ok" // "ok" | "failed" | "never"
  },
  cf: { rating: 1450, max_rating: 1512, rank: "specialist", ... },
  cc: { rating: 1580, stars: 3, solved: 89, ... },
  hr: { badges: 12, gold_badges: 3, ... },
  gfg: { solved: 145, score: 620, ... }
}
Fields used by each view:
name, roll_number, department, year lc.solved, lc.hard, lc.medium, lc.rating cf.rating, cf.rank cc.stars, hr.badges, gfg.score
Collection 2: platform_data
One document per student per platform (~5–20KB). Only fetched when student detail page is opened.
{
  student_id: ObjectId, // ref to students._id
  platform: "leetcode",
  username: "faisal_lc",
  fetched_at: ISODate,
  sync_status: "ok",
  consecutive_failures: 0,

  // full raw payload — shape differs per platform, stored as-is
  data: {
    recent_submissions: [ /* last 20 */ ],
    topic_tags: { "dynamic-programming": 34, "graphs": 12 },
    badges: [ "50 Days Badge", "Annual 2024" ],
    contest_history: [ /* array of contests */ ]
  }
}
Indexes
// leaderboard: year filter + lc sort — covers 80% of queries
db.students.createIndex({ year: 1, "lc.solved": -1 })
db.students.createIndex({ year: 1, "lc.hard": -1 })
db.students.createIndex({ year: 1, "cf.rating": -1 })
db.students.createIndex({ department: 1, year: 1 })

// detail page lookup
db.platform_data.createIndex({ student_id: 1, platform: 1 }, { unique: true })
Query examples
// 3rd year, LC solved > 200, sort by hard desc
Student.find({
  year: 3,
  "lc.solved": { $gte: 200 },
  "lc.sync_status": "ok"
}).sort({ "lc.hard": -1 }).limit(100)

// student detail — two parallel fetches, no join
Promise.all([
  Student.findById(id),
  PlatformData.find({ student_id: id }) // max 5 docs
])

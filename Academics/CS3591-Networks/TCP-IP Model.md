# TCP/IP Model

**What it is**  
The **TCP/IP model** is a **4-layer practical networking model** used on the Internet.

**Layers**
- Application
- Transport
- Internet
- Network Access

**Design philosophy**
Built around **real protocols**, not abstractions.

**Key point**
All real-world networking (Internet) follows TCP/IP, not OSI.

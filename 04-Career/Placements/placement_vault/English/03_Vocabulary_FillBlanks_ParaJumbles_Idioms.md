## 🔴 CONTEXTUAL VOCABULARY APPROACH

1. Read the **full sentence** where the word appears
2. Identify the **tone** (positive/negative/neutral)
3. Substitute each option — which fits contextually?
4. Eliminate extreme options first

### Example:
*"The scientist was known for her ______ attention to detail."*
Options: a) Meticulous b) Reckless c) Sporadic d) Ambivalent
- Scientist + attention to detail → positive word needed
- Reckless (negative) ❌, Sporadic (irregular) ❌, Ambivalent (uncertain) ❌
- Meticulous ✅

# PART 2: FILL IN THE BLANKS

## 🔴 TYPES

### Type 1 — Grammar-based (article/preposition/tense)
> She has been working here ______ 2019. → **since** (point of time)
> He has been ill ______ three days. → **for** (duration)

### Type 2 — Vocabulary-based (right word choice)
> Despite working hard, she could not ______ the exam. → **pass** (not "pass through")

### Type 3 — Double blanks
> The ______ of the speech left the audience both ______ and confused.
→ Ambiguity / amused? Look for word pairs that logically fit together.

# PART 3: PARA JUMBLES

## 🔴 SOLVING APPROACH

1. Find the **opening sentence** — introduces topic, no pronoun reference to unknown noun, no connector like "however/therefore/but" at start
2. Find the **closing sentence** — concluding word/phrase: "thus", "therefore", "in conclusion", "finally"
3. Find **connector pairs** — sentences that logically must follow each other (pronoun → noun, cause → effect, example → claim)
4. Build chain from opening to closing

---

## 🔴 CONNECTORS TO WATCH

| Word | What follows |
|------|-------------|
| However / But / Yet | Contrast to previous sentence |
| Therefore / Thus / Hence | Conclusion from previous |
| Moreover / Furthermore | Addition to previous |
| For example / For instance | Example of previous claim |
| This / That / These / Those | Refers to noun in previous sentence |
| He / She / They | Refers to person in previous sentence |
| The former / The latter | Refers to two items mentioned before |

---

## 🟠 SOLVED EXAMPLES — PARA JUMBLES

### Example 1
Sentences:
- A: He then revised it three times.
- B: The author wrote the first draft quickly.
- C: Finally he submitted it to the publisher.
- D: Each revision improved the clarity.

Opening = B (introduces "the author" — no pronoun)
B → A (wrote draft, then revised)
A → D (revised it — "each revision")
D → C ("finally" = closing)
**Order: B-A-D-C** ✅

---

### Example 2
Sentences:
- P: This led to widespread public protests.
- Q: The government announced a new tax policy.
- R: Eventually, the policy was withdrawn.
- S: Many citizens felt the tax was unfair.

Opening = Q (introduces topic, no reference)
Q → S (policy announced → citizens react)
S → P (felt unfair → protests)
P → R (protests → policy withdrawn, "eventually" = closing)
**Order: Q-S-P-R** ✅

## ❌ COMMON MISTAKES

- Vocabulary: picking dictionary meaning without reading context
- Fill blanks: "since" vs "for" — since = point in time, for = duration
- Para jumbles: placing "however/therefore" sentences at the start
- Idioms: interpreting literally instead of figuratively
- Phrasal verbs: "bring about" ≠ "bring off" — check exact meaning

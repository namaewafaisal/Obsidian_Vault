title: Bus Trip Capacity Check (Difference Array)
topic: Arrays
---

## 🧩 Problem
Given a bus with capacity **C** and multiple trips:

Each trip:
```
passengers, from, to
```

- At `from` → passengers get in  
- At `to` → passengers get out  

### Goal
Check if at any point passengers exceed capacity.

---

## 🚧 Challenge
Trips can **overlap**, so passengers from multiple trips may be inside simultaneously.

---

## 💡 Core Idea (Difference Array)
Instead of tracking each passenger:

- Mark **entry and exit changes**
- Then compute running total

---

## ⚙️ Algorithm

### Step 1: Create array
```
stops[0...1000] = 0
```

---

### Step 2: Mark changes
```
stops[from] += passengers
stops[to]   -= passengers
```

---

### Step 3: Traverse and track
```
curr += stops[i]

if curr > C → return 0
```

---

## 🧪 Code
```java
int n = sc.nextInt();
int stops[] = new int[1001];

for(int i = 0; i < n; i++) {
    int p = sc.nextInt();
    int start = sc.nextInt();
    int end = sc.nextInt();

    stops[start] += p;
    stops[end] -= p;
}

int C = sc.nextInt();

int curr = 0;
for(int i = 0; i < stops.length; i++) {
    curr += stops[i];
    if(curr > C) {
        System.out.println(0);
        return;
    }
}

System.out.println(1);
```

---

## 🔍 Key Insight
We track only **changes**, not full state.

---

## ⚠️ Common Mistake
Wrong:
```
stops[start] = p
stops[end] = -p
```

Correct:
```
stops[start] += p
stops[end] -= p
```

👉 Because multiple trips can overlap at same location

---

## ⏱ Complexity
- Time: O(n + 1000)
- Space: O(1000)

---

## 🧠 Memory Hook
“Mark where people enter and leave, then accumulate”

# Custom Problem — Vowel-Based Pair Count

## Problem (LeetCode Statement)

**Input:**  
- Integer `n`  
- Array `arr` of size `n`  

**Output:**  
- A string representing a number  

**Task:**  
1. Convert each number to its English word  
2. Count total vowels in all words  
3. Find number of pairs whose sum = vowel count  
4. Return result in word form  

---

## Constraints

- `0 ≤ arr[i] ≤ 100`
- Must avoid O(n²) pair counting

---

## Examples

```
Input:  [1,2,3]
Words: "one", "two", "three"
Vowels: 2 + 1 + 2 = 5
Pairs: (2,3)
Output: "one"
```

---

## What Actually Matters

- Problem is **3-step pipeline**
- Conversion → count → pair logic
- Pair counting is classic hashmap pattern
- Don’t mix steps → keep them separate

---

## Core Insight

> This is just **Two Sum count after transforming input**

---

## Invariant / Mental Model

- Vowel count = target `k`
- For each `x`, we need `(k - x)`
- Store frequencies → build answer in one pass

---

## Thinking Log (Your Style)

- Convert numbers → words  
- Count vowels → get target  
- Need pairs → feels like Two Sum  
- Use hashmap → done

## Algorithm (High Level)

1. Convert numbers → words  
2. Count vowels  
3. Use hashmap to count pairs  
4. Convert result → word

## Code (Reference Only)

```java
package q18144;
import java.util.*;

public class CTJ18144 {

    static String[] ones = {
        "", "one", "two", "three", "four", "five",
        "six", "seven", "eight", "nine"
    };
    
    static String[] teens = {
        "ten", "eleven", "twelve", "thirteen", "fourteen",
        "fifteen", "sixteen", "seventeen", "eighteen", "nineteen"
    };
    
    static String[] tens = {
        "", "", "twenty", "thirty", "forty",
        "fifty", "sixty", "seventy", "eighty", "ninety"
    };

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] arr = new int[n];

        for(int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        int count = 0;

        for(int i : arr) {
            String word = numToWords(i);
            for(char c : word.toCharArray()){
                if("aeiou".indexOf(c) != -1){
                    count++;
                }
            }
        }

        System.out.println(numToWords(pairs(arr, count)));
    }

    public static String numToWords(int n) {

        if(n == 0) return "zero";
        if(n == 100) return "hundred";

        if(n >= 1 && n <= 9) {
            return ones[n];
        }

        if(n >= 10 && n <= 19) {
            return teens[n - 10];
        }

        if(n >= 20 && n <= 99) {
            int tp = n / 10;
            int op = n % 10;

            if(op == 0) {
                return tens[tp];
            }
            return tens[tp] + " " + ones[op];
        }

        return "";
    }

    public static int pairs(int[] arr, int k) {
        Map<Integer,Integer> map = new HashMap<>();
        int count = 0;

        for (int x : arr) {
            count += map.getOrDefault(k - x, 0);
            map.put(x, map.getOrDefault(x, 0) + 1);
        }

        return count;
    }
}
```

---

## Edge Cases to Recall

- 0 → "zero"
- 10–19 → teens
- No pairs → "zero"
- Duplicate values handled via frequency

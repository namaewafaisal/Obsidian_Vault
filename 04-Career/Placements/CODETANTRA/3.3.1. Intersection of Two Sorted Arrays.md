## 🧩 Problem
Given two **sorted arrays**, find their intersection.

- Include duplicates (minimum frequency)
- Output must be sorted
- If no common elements → print `-1`

---

## 💡 Core Idea
Use **two pointers** to traverse both arrays simultaneously.

---

## ⚙️ Full Code
```java
package q86109;
import java.util.*;

public class CTJ86109 {
    static Scanner sc;

    public static void main(String[] args) {
        sc = new Scanner(System.in);

        int n1 = sc.nextInt();
        int[] arr1 = new int[n1];
        getInput(arr1, n1);

        int n2 = sc.nextInt();
        int[] arr2 = new int[n2];
        getInput(arr2, n2);

        List<Integer> res = intersection(arr1, arr2);

        if (res.size() == 0) {
            System.out.print(-1);
        } else {
            for (int i = 0; i < res.size(); i++) {
                System.out.print(res.get(i) + " ");
            }
        }
    }

    public static void getInput(int[] arr, int n) {
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }
    }

    public static List<Integer> intersection(int[] nums1, int[] nums2) {
        int l1 = 0;
        int l2 = 0;
        List<Integer> result = new ArrayList<>();

        while (l1 < nums1.length && l2 < nums2.length) {
            if (nums1[l1] == nums2[l2]) {
                result.add(nums1[l1]);
                l1++;
                l2++;
            } else if (nums1[l1] < nums2[l2]) {
                l1++;
            } else {
                l2++;
            }
        }

        return result;
    }
}
```

---

## 🔍 Key Insight
- Since arrays are sorted, skip smaller elements
- Move both pointers only forward → efficient

---

## ⚠️ Important Edge Case
Always check:
```
l1 < nums1.length && l2 < nums2.length
```

---

## ⏱ Complexity
- Time: O(n + m)
- Space: O(k) (result size)

---

## 🧠 Memory Hook
“Compare → match → move both, else move smaller”

# TRACKING TOOLS — PRACTICAL SETUP (ROADMAP-ALIGNED)

## First: One Non-Negotiable Rule

> **Tools do NOT define progress.
> Tools only RECORD signals of progress.**

If a tool pushes you toward:

* daily streaks
* checklists
* dopamine tracking

→ you are using it **wrong**.

---

## 1. Goodtime — *Time Boundary Only*


### What to Use It For

* Enforcing **focused sessions**
* Preventing burnout
* Seeing *rough* time distribution

### What NOT to Use It For

* Measuring mastery
* Comparing days
* “I studied 5 hours so I’m good”

### Correct Setup

* Categories:

  * DSA
  * Aptitude
  * Project
* No goals
* No streak obsession

**Interpretation rule:**
Time ≠ progress.
Time only tells you *where effort went*, not *what you learned*.

---

## 2. Google Sheets — *Lightweight Quantitative Signals*


### Use Sheets ONLY if you need visibility

#### Minimal Sheet Structure (Recommended)

| Track    | Topic          | Confidence (1–5) | Failure Notes        | Status |
| -------- | -------------- | ---------------- | -------------------- | ------ |
| DSA      | Sliding Window | 3                | Breaks on negatives  | Active |
| Aptitude | Profit & Loss  | 4                | Discounts mixed      | Stable |
| Project  | Auth flow      | 2                | Token expiry unclear | Weak   |

### Rules

* Update **weekly**, not daily
* “Confidence” is **self-assessment**
* “Failure Notes” is the most important column

If this becomes tedious → delete it.

---

## 3. Obsidian — *Deep Thinking & Knowledge Graph*

### Best Tool for YOU (given your style)

### Folder Structure (Simple)

```
/DSA
  Arrays.md
  Sliding_Window.md

/Aptitude
  Profit_Loss.md

/Project
  Architecture.md
  Decisions.md
  Failures.md
```

### How to Write Notes (Critical)

Each note answers:

* What is the core idea?
* Where does it break?
* Why naive thinking fails?
* What question exposed this gap?

**No summaries. No copy-paste.**

Obsidian is your **thinking mirror**, not a textbook.

---

## 4. Notion — *Optional High-Level Dashboard*

### Use Notion ONLY if:

* You want a **single visual dashboard**
* You like structured databases

### Recommended Use (Minimal)

One table:

* Track
* Current focus
* Known weakness
* Next clarification needed

Avoid:

* Kanban overload
* 10 databases
* Fancy templates

Notion should **summarize**, not manage your brain.

---

## 5. The Correct Combination (Recommended for You)

**Best Setup for Your Roadmap:**

* **Goodtime** → focus & time hygiene
* **Obsidian** → primary learning & tracking
* **Google Sheets** → optional weekly signal
* **Notion** → optional overview (or skip)

If you want **only ONE tool** → **Obsidian**.

---

## 6. What to NEVER Track (Very Important)

Do NOT track:

* Problems solved count
* Hours per topic
* Days studied
* Completion percentages

These create **false confidence**.

---

If you want the **cleanest, future-proof system**:

1. Use **Goodtime** when studying
2. Use **Obsidian** to write:

   * failures

   * decisions
3. Keep **MASTER_ROADMAP.md** as authority
4. Ignore everything else unless pain appears

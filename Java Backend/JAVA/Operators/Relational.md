# Relational Operators

Relational operators are used to **compare two values**. The result of a relational operation is always a **Boolean value** (`true` or `false`).

|Operator|Purpose|Notes|Citation|
|:--|:--|:--|:--|
|`>`|Greater than|Checks if the first value is larger.||
|`<`|Less than|Checks if the first value is smaller.||
|`==`|Equal to|Compares if two values are exactly equal. **Note:** Using a single `=` performs assignment, not comparison.||
|`!=`|Not equal to|Checks if two values are different.||
|`>=`|Greater than or equal to|Combines comparisons.||
|`<=`|Less than or equal to|Combines comparisons.||

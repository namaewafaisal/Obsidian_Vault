# Assignment and Shorthand Operators

### Assignment Operator (`=`)

The equal symbol (`=`) is the **assignment operator**; it assigns the value on the right to the variable on the left.

### Compound Shorthand Operators

When you want to perform an operation on a variable and then assign the result back to that same variable (e.g., `num1 = num1 + 2`), Java provides shorthand operators.

| Operator | Expanded Form       | Description                    | Citation |
| :------- | :------------------ | :----------------------------- | :------- |
| `+=`     | `num = num + value` | Addition and assignment.       |          |
| `-=`     | `num = num - value` | Subtraction and assignment.    |          |
| `*=`     | `num = num * value` | Multiplication and assignment. |          |
| `/=`     | `num = num / value` | Division and assignment.       |          |
| `%=`     | `num = num % value` | Modulus and assignment.        |          |

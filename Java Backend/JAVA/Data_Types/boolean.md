# `boolean` Data Type in Java

The **`boolean`** data type represents one bit of information — **true** or **false**.

---

### Overview

- **Size:** 1 bit (not precisely defined; JVM dependent)
    
- **Range:** true or false
    
- **Default Value:** false
    
- **Type Category:** Primitive
    
- **When to Use:**
    
    - To store logical states or conditions.
        

---

### Example

```java
boolean isJavaFun = true;
System.out.println(isJavaFun);
```

---

### Notes

- Commonly used in control structures like `if`, `while`, or `for`.
    
- Cannot be cast to other numeric types.
- In Java, boolean is not in 1 or 0, only true and false.

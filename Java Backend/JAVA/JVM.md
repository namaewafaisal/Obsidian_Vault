# JVM (Java Virtual Machine)

The JVM is the engine that runs Java programs.  
It converts bytecode into machine code that your OS can understand.

The JVM is **platform-dependent**, meaning different OSes (like Windows or iOS) require different JVM implementations.

It is not exclusive to Java — languages like **Kotlin** and **Groovy** also compile to JVM bytecode.

**Responsibilities:**
- Loads `.class` files
- Verifies bytecode
- Executes code using JIT (Just-In-Time) compiler
- Handles Garbage Collection

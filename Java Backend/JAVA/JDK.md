 # JDK (Java Development Kit)

The JDK is a software development kit that provides tools to write, compile, and debug Java programs.

> **Always Use LTS version**

It contains:
- The [[JRE]]
- The compiler (`javac`)
- Debugger
- Other development tools

**Structure:**

`JDK → (JRE → (JVM + Core Libraries)) + Compiler + Debugger`

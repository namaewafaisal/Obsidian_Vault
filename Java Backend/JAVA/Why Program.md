# Why Program is Needed

Programs are used to solve **real-world problems** using computers.  
They let us create systems that make everyday tasks faster, safer, and more accurate.

---

### Examples:
- Banking (track and process transactions)
- Healthcare (store patient data)
- Online Shopping (manage carts, payments, and delivery)

---

Without programs, computers would be useless machines with no specific purpose.

# What is Java

Java is one of the most popular programming languages.  
It is **object-oriented**, **platform-independent**, and designed for **readability and maintainability**.

It has a policy of Write Once and Run Anywhere

If you know Java, it becomes easier to learn other languages such as Kotlin, C#, or Scala.

**Key Features:**
- Object-Oriented
- Platform Independent
- Robust and Secure
- Readable and Maintainable
- Java filename.java can compile and run.

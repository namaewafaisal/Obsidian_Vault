# Jshell

Jshell is an interactive REPL (Read-Eval-Print Loop) introduced in Java 9.  
It allows you to run Java code snippets line-by-line — similar to Python's interpreter mode.

**Usage:**
```jshell
jshell> System.out.println("Hello Java");
```

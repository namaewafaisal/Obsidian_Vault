# Java Platform Independence

Java is **platform-independent** — you can run the same `.class` file on any operating system that has a JVM.

However, the **JVM itself is platform-dependent**,  
meaning each OS (Windows, Linux, macOS) has its own JVM version.

**Example:**
- Write Java on Windows → run same `.class` file on Linux

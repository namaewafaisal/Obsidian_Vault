# Data Types in Java

Data types define the **kind of data** a variable can store.

---

### 1. Primitive Data Types
| Type                             | Size    | Example      |
| -------------------------------- | ------- | ------------ |
| [byte](byte.md)       | 1 byte  | 10           |
| [short](short.md)     | 2 bytes | 200          |
| [int](int.md)         | 4 bytes | 1000         |
| [long](long.md)       | 8 bytes | 10000L       |
| [float](float.md)     | 4 bytes | 3.14f        |
| [double](double.md)   | 8 bytes | 3.14159      |
| [char](char.md)       | 2 bytes | 'A'          |
| [boolean](boolean.md) | 1 bit   | true / false |

---

### 2. Non-Primitive Data Types
These are objects and can hold multiple values or structures.
- String
- Arrays
- Classes
- Interfaces

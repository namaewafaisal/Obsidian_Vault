## 1. What Is Being Tracked (Exactly)

You are tracking **three independent dimensions**, not time or completion.

### 1.1 DSA Tracking Dimension

Tracked by:

* Topic depth
* Pattern recognition maturity
* Failure awareness
* Interview-readiness confidence

**NOT tracked by:**

* Number of problems solved
* Platforms completed
* Streaks or days

---

### 1.2 Aptitude Tracking Dimension

Tracked by:

* Formula recall reliability
* Model recognition speed
* Error types (conceptual vs careless)
* Accuracy under pressure

**NOT tracked by:**

* Topic completion
* Video progress
* Mock count alone

---

### 1.3 Project Tracking Dimension

Tracked by:

* Architectural clarity
* Decision justification ability
* Debugging maturity
* Explanation capability

**NOT tracked by:**

* Feature count
* Lines of code
* UI completeness

## 3. How Progress Is Actually Measured

### 3.1 DSA Progress Signal

You are considered progressing when:

* You ask **why a solution breaks**
* You challenge edge cases
* You recognize patterns across problems
* You reduce brute force instinctively

Stagnation signal:

* Repeatedly asking for “full solution”
* Inability to explain failures
* Jumping topics

---

### 3.2 Aptitude Progress Signal

You are considered progressing when:

* You recall formulas without prompting
* You reject slow methods instinctively
* You classify questions within seconds

Stagnation signal:

* Re-deriving formulas every time
* Inconsistent accuracy
* Speed without correctness

---

### 3.3 Project Progress Signal

You are considered progressing when:

* You ask “where should this logic live?”
* You question framework behavior
* You can explain trade-offs verbally

Stagnation signal:

* Blind copying
* Feature-first thinking
* Framework worship

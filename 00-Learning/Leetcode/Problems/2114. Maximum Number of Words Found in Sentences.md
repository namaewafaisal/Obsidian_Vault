# 2114. Maximum Number of Words Found in Sentences

## Problem (LeetCode Statement)

**Input:**  
- Array of strings `sentences`, each containing words separated by a single space

**Output:**  
- Integer → maximum number of words in any sentence

**Task:**  
Return the highest word count among all given sentences

---

## Constraints

- Words are separated by exactly one space
- No leading or trailing spaces
- Linear scan is sufficient

---

## Examples

```
Input: ["alice and bob love leetcode", "i think so too", "this is great thanks very much"]
Output: 6
```

```
Input: ["please wait", "continue to fight", "continue to win"]
Output: 3
```

---

## What Actually Matters

- Words are separated by spaces → counting tokens is enough
- No need to preserve order or modify input
- Each sentence is independent
- Full parsing or complex logic is unnecessary

---

## Core Insight

> Word count = number of splits (or spaces + 1)

---

## Invariant / Mental Model

> Track the maximum word count seen so far while iterating

---

## Thinking Log (Evolution of the Solution)

- Initial Thought:  
  Iterate through each sentence and count words manually

- Issue:  
  Counting characters one by one is unnecessary

- Correction:  
  Use built-in split to directly get word count

- Final Realization:  
  Each sentence can be independently evaluated with simple string processing

---

## Algorithm (High Level)

1. Initialize `max = 0`
2. Loop through each sentence
3. Split sentence by space
4. Update max using length of split array
5. Return max

---

## Code (Reference Only)

```java
class Solution {
    public int mostWordsFound(String[] sentences) {
        
        int max = 0;
        for(String s : sentences){
            String[] arr = s.split(" ");
            max = Math.max(max, arr.length);
        }
        return max;
    }
}
```

---

## Edge Cases to Recall

- Single word sentence → answer = 1
- All sentences same length
- Minimal input size

---

## One-Line Recall

> Split each sentence by space and track the maximum word count

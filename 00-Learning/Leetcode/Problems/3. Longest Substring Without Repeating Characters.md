# 3. Longest Substring Without Repeating Characters

## Problem (LeetCode Statement)

**Input:**  
- String `s`

**Output:**  
- Integer representing the length of the longest substring without repeating characters

**Task:**  
Find the maximum length of any substring that contains no duplicate characters.

---

## Constraints

- `0 ≤ s.length ≤ 10^5`
- `s` consists of ASCII characters
- Must run in linear time

---

## Examples

```
Input:  "abcabcbb"
Output: 3
```

```
Input:  "bbbbb"
Output: 1
```

```
Input:  "pwwkew"
Output: 3
```

---

## What Actually Matters

- Substring must be **contiguous**
- Characters must be **unique**
- Brute force substring generation is too slow

---

## Core Insight

> Maintain a sliding window that is always valid by shrinking it whenever a duplicate appears.

---

## Invariant / Mental Model

> The current window is valid if every character inside it appears at most once.

---

## Thinking Log (Evolution of the Solution)

- **Initial Thought:**  
  Generate all substrings and check each for uniqueness.

- **Issue:**  
  This leads to `O(n³)` or `O(n²)` time complexity.

- **Early Confusion:**  
  Whether to use a `Set` or a `Map`.

- **Correction:**  
  Since we need to know *when* a character becomes invalid, tracking frequency is safer.

- **Rejected Idea:**  
  Jump the `left` pointer directly using stored indices.

- **Correction:**  
  While possible, the shrink-while-invalid rule is more robust and easier to reason about.

- **Final Realization:**  
  Only the character added at the `right` pointer can invalidate the window, so shrinking is driven solely by that condition.

---

## Algorithm (High Level)

1. Initialize two pointers `left` and `right`
2. Expand window by moving `right`
3. Shrink from `left` while window is invalid
4. Update maximum length when window is valid

---

## Code (Reference Only)

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> freq = new HashMap<>();
        int left = 0, right = 0;
        int maxLen = 0;

        while (right < s.length()) {
            char r = s.charAt(right);
            freq.put(r, freq.getOrDefault(r, 0) + 1);

            while (freq.get(r) > 1) {
                char l = s.charAt(left++);
                freq.put(l, freq.get(l) - 1);
            }

            maxLen = Math.max(maxLen, right - left + 1);
            right++;
        }
        return maxLen;
    }
}
```

---

## Edge Cases to Recall

- Empty string
- String with all identical characters
- String with repeating pattern

---

## One-Line Recall

> Expand the window and shrink it only when the current character causes a duplicate.

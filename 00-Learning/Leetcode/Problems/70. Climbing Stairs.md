# 70. Climbing Stairs

## Problem (LeetCode Statement)

**Input:**  
- Integer `n` representing the number of steps in a staircase

**Output:**  
- Return the number of distinct ways to reach the top

**Task:**  
You can climb:
- `1` step  
- `2` steps  

Find how many different ways exist to reach the top.

---

## Constraints

- `1 ≤ n ≤ 45`

---

## Examples

```
Input:  n = 2
Output: 2

Ways:
1 + 1
2
```

```
Input:  n = 3
Output: 3

Ways:
1 + 1 + 1
1 + 2
2 + 1
```

---

## What Actually Matters

- At every step you can come from:
  - `1 step before`
  - `2 steps before`

So the number of ways to reach step `i` depends on previous steps.

---

## Core Insight

> The number of ways to reach step `i` equals the sum of ways to reach `i-1` and `i-2`.

```
ways(i) = ways(i-1) + ways(i-2)
```

This is exactly the **Fibonacci recurrence**.

---

## Invariant / Mental Model

> `dp[i]` stores the number of ways to reach step `i`.

Base cases:

```
dp[1] = 1
dp[2] = 2
```

Then build upward.

---

## Thinking Log (Evolution of the Solution)

### Initial Understanding

To reach step `i`, the last move must be:

- from `i-1` (one step jump)
- from `i-2` (two step jump)

So total ways are the sum of both.

---

### Dynamic Programming Idea

Store previously computed values so we do not recompute them.

This avoids exponential recursion.

---

## Algorithm (High Level)

1. Handle small cases (`n ≤ 2`)
2. Create DP array of size `n+1`
3. Initialize base values
4. Fill DP using recurrence
5. Return `dp[n]`

Time: `O(n)`  
Space: `O(n)`

---

## Code (Reference Only)

```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 2) {
            return n;
        }

        int[] dp = new int[n + 1];
        dp[1] = 1;
        dp[2] = 2;

        for (int i = 3; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }

        return dp[n];
    }
}
```

## LC 229. Majority Element II

### Problem (Statement)

Given an integer array `nums`, return all elements that appear **more than ⌊ n / 3 ⌋ times**.

Constraints:
- Must run in `O(n)` time
- Must use `O(1)` extra space (excluding output)
- Result can contain **at most 2 elements**

---

### Key Observation

> **There can be at most `k − 1` elements that appear more than `n / k` times.**

For `n / 3`:
- At most **2** such elements exist

This makes it possible to track only **two candidates**.

---

### Core Idea (Cancellation Invariant)

> Removing `k` distinct elements does **not** affect which elements occur more than `n / k` times.

So:
- Wrong candidates cancel each other
- True frequent elements survive

This is an extension of **LC 169 (n / 2)** to **two candidates**.

---

### Algorithm Overview

#### Pass 1 — Candidate Selection (Filtering)

Maintain:
- `candidate1`, `count1`
- `candidate2`, `count2`

For each number:
1. If it matches a candidate → increment count
2. Else if a count is zero → replace that candidate
3. Else → decrement both counts (cancellation)

This pass only finds **possible survivors**.

---

#### Pass 2 — Verification (Mandatory)

- Reset counts
- Count actual occurrences of both candidates
- Add to result only if count > `n / 3`

This pass ensures correctness.

---

### Final Code (Java)

```java
class Solution {
    public List<Integer> majorityElement(int[] nums) {
        int candidate1 = 0, candidate2 = 0;
        int count1 = 0, count2 = 0;

        // First pass: find potential candidates
        for (int x : nums) {
            if (x == candidate1) {
                count1++;
            } else if (x == candidate2) {
                count2++;
            } else if (count1 == 0) {
                candidate1 = x;
                count1 = 1;
            } else if (count2 == 0) {
                candidate2 = x;
                count2 = 1;
            } else {
                count1--;
                count2--;
            }
        }

        // Second pass: verify actual counts
        count1 = 0;
        count2 = 0;
        for (int x : nums) {
            if (x == candidate1) count1++;
            else if (x == candidate2) count2++;
        }

        List<Integer> result = new ArrayList<>();
        int n = nums.length;

        if (count1 > n / 3) result.add(candidate1);
        if (count2 > n / 3) result.add(candidate2);

        return result;
    }
}
```

---

### Generalization Insight (Important)

- For threshold `> n / k`:
  - Track at most `k − 1` candidates
  - Use the same cancellation logic
- This works only when `k` is **small and fixed**
- For large `k`, hashmap is more practical

---

### Common Mistakes

- Forgetting the second verification pass
- Trying to dynamically store candidates in a list
- Assuming first pass guarantees correctness
- Overgeneralizing to arbitrary `k` without space limits

---

### One-Sentence Recall

> LC 229 works by canceling out groups of three distinct elements, leaving at most two possible majority candidates that must be verified.

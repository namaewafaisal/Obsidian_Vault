## LC 167. Two Sum II — Input Array Is Sorted

### Problem (Statement)

Given a **sorted** integer array `numbers` and an integer `target`, find **two distinct indices** such that:

```
numbers[i] + numbers[j] == target
```

Constraints:
- Array is sorted in **non-decreasing order**
- Exactly **one valid solution exists**
- Indices are **1-based**
- Same element cannot be used twice

---

### Key Observation

> **Sorted order allows directional elimination of impossible pairs.**

Unlike LC 1:
- No hashmap needed
- Order itself encodes comparison information

---

### Core Idea (Two-Pointer Invariant)

Maintain two pointers:
- `left` → smallest remaining value
- `right` → largest remaining value

Invariant:
> At every step, the solution (if not found yet) lies **between `left` and `right`**.

Pointer movement is **logically forced**, not heuristic.

---

### Decision Logic (Why Pointer Moves Are Correct)

Let:
```
sum = numbers[left] + numbers[right]
```

- If `sum > target`  
  → `right--`  
  (largest value is too large; decreasing it is the only way to reduce sum)

- If `sum < target`  
  → `left++`  
  (smallest value is too small; increasing it is the only way to increase sum)

- If `sum == target`  
  → answer found

No valid pair is skipped because:
- Moving the *wrong* pointer cannot fix the inequality
- Sorted order guarantees monotonic change in sum

---

### Algorithm Overview

1. Initialize:
   - `left = 0`
   - `right = n - 1`
2. While `left < right`:
   - Compare `numbers[left] + numbers[right]` with `target`
   - Move exactly **one pointer** based on comparison
3. Return indices when equality is found

Time: `O(n)`  
Space: `O(1)`

---

### Final Code (Java)

```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        int left = 0;
        int right = numbers.length - 1;

        while (left < right) {
            int sum = numbers[left] + numbers[right];

            if (sum > target) {
                right--;
            } else if (sum < target) {
                left++;
            } else {
                return new int[] { left + 1, right + 1 };
            }
        }
        return null;
    }
}
```

---

### Why This Is Marked Medium (Despite Feeling Easy)

- Requires recognizing **forced pointer movement**
- Many fail by:
  - Using hashmap out of habit
  - Moving both pointers
  - Not proving why skipping is safe

The difficulty is **conceptual**, not implementation.

---

### Common Mistakes

- Forgetting indices are **1-based**
- Using hashmap and wasting space
- Using `<=` instead of `<` in loop condition
- Not trusting sorted-order invariant

### One-Sentence Recall

> In a sorted array, two pointers work because increasing the left pointer strictly increases the sum, and decreasing the right pointer strictly decreases it—making every move logically forced.

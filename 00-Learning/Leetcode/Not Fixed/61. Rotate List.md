## LC 61. Rotate List

### Problem (Statement)

Given the `head` of a **singly linked list**, rotate the list to the **right by `k` places**.

Constraints:
- List is singly linked
- Cannot index into nodes
- Must preserve node order except for rotation

---

### Input / Output

**Input**
```
1 -> 2 -> 3 -> 4 -> 5
k = 2
```

**Output**
```
4 -> 5 -> 1 -> 2 -> 3
```

---

### Key Invariant

> **Rotating a list = make it circular, then break it at the correct position.**

Rotation does **not** mean shifting one-by-one.

---

### Thinking Log (Actual Evolution, Mistakes Included)

#### Initial Intuition (Rejected Correctly)

> *“Rotate the list one step at a time, `k` times.”*

Why this was rejected:
- Each rotation is O(n)
- Total time becomes O(n²)
- Clearly inefficient

---

#### Correct High-Level Idea

> *“If I know the size, I can jump directly to the cut point.”*

This led to:
- Compute list size `n`
- Reduce rotations using `k = k % n`
- Find the new head at position `n - k`

---

#### ❌ Mistake #1 — Forgetting modulo reduction

> *“Just rotate by `k`.”*

Why this failed:
- Rotating by `n` or multiples of `n` does nothing
- Large `k` causes unnecessary traversal

**Correction:**  
Always reduce `k` using modulo.

---

#### ❌ Mistake #2 — Losing track of where to break

> *“I know the new head, but where do I cut?”*

Why this was confusing:
- Singly linked list → no backward movement
- Need both:
  - node before new head
  - tail node

**Correction:**  
Use **two pointers** with a fixed gap of `k`.

---

### Key Breakthrough

> *“If one pointer is `k` ahead, when it reaches the tail, the other is at the cut point.”*

This immediately solved:
- Where to reconnect
- Where to break

---

### Correct Mental Model (Must Lock In)

1. Handle edge cases (`null`, single node, `k == 0`)
2. Compute size `n`
3. Reduce `k = k % n`
4. Move `ahead` pointer `k` steps forward
5. Move `ahead` and `behind` together until `ahead` is at tail
6. Make the list circular
7. Break the circle to form the rotated list

---

### Final Correct Code (Java)

```java
class Solution {
    public ListNode rotateRight(ListNode head, int k) {
        if (head == null || head.next == null || k == 0) {
            return head;
        }

        int size = 0;
        ListNode curr = head;
        while (curr != null) {
            size++;
            curr = curr.next;
        }

        k = k % size;
        if (k == 0) return head;

        ListNode ahead = head;
        ListNode behind = head;

        for (int i = 0; i < k; i++) {
            ahead = ahead.next;
        }

        while (ahead.next != null) {
            ahead = ahead.next;
            behind = behind.next;
        }

        ahead.next = head;      // form cycle
        head = behind.next;     // new head
        behind.next = null;     // break cycle

        return head;
    }
}
```

---

### Why This Works

- `ahead` reaching tail guarantees correct offset
- `behind` lands exactly before new head
- Circular connection preserves order
- One clean break finalizes rotation

---

### Common Mistakes (Explicit)

- Rotating one step at a time
- Forgetting `k % n`
- Breaking the list at the wrong node
- Using extra memory

---

### One-Sentence Recall

> LC 61 works by turning the list into a temporary cycle and breaking it exactly `k` nodes from the end.

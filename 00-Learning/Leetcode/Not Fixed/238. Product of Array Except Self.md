## LC 238 — Product of Array Except Self

### Problem (summary)

Given an integer array `nums`, return an array `answer` such that `answer[i]` is equal to the product of all the elements of `nums` except `nums[i]`. You must write an algorithm that runs in **O(n)** time and **without using the division operator**.

---

### Example

Input: `nums = [1, 2, 3, 4]`

Output: `[24, 12, 8, 6]`

Explanation:

* `answer[0] = 2 * 3 * 4 = 24`
* `answer[1] = 1 * 3 * 4 = 12`
* `answer[2] = 1 * 2 * 4 = 8`
* `answer[3] = 1 * 2 * 3 = 6`

---

### Pattern Classification

* Prefix and Suffix Products
* Space-Time Tradeoff (Precomputation)
* Non-divisive exclusion

---

### Key Invariant

* Each index `i` in the output is the product of:
`Prefix (all elements to the left of i)`  `Suffix (all elements to the right of i)`
* By definition:
* `Prefix[0] = 1` (nothing to the left)
* `Suffix[n-1] = 1` (nothing to the right)



---

### Thinking Log (Evolution of the Solution)

* **Initial Thought:** Use total product and divide by `nums[i]`.
* *Correction:* Forbidden by problem constraints; also fails if `nums[i]` is 0.


* **Brute Force:** Nested loops calculating product for every `i`.
* *Correction:* **O(n²)** is too slow for large arrays.


* **The Insight:** Realized that as we move from left to right, we can "carry over" the product from the previous step. The same logic applies moving from right to left.
* **Constraint Handling:** By building products *excluding* the current element by construction (using values from `i-1` or `i+1`), we never need to "remove" an element via division.

---

### Implementation Strategy

1. **Right Pass (Suffix):** Build an array where `rightArray[i]` stores the product of all elements to the right of `i`.
2. **Left Pass (Prefix):** Use a running variable `leftProd` to track the product of all elements to the left of `i`.
3. **Combine:** `output[i] = leftProd * rightArray[i]`.

---

### Code

```java
class SolutionProd {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] rightArray = new int[n];
        int[] output = new int[n];
        
        int rightProd = 1;
        // Step 1: Precompute Suffix Products (Right to Left)
        for(int i = n - 1; i >= 0; i--) {
            rightArray[i] = rightProd;
            rightProd *= nums[i];
        }

        int leftProd = 1;
        // Step 2: Compute Prefix Products and Final Result (Left to Right)
        for(int i = 0; i < n; i++) {
            output[i] = leftProd * rightArray[i];
            leftProd *= nums[i];
        }
        
        return output;
    }
}

```

---

### Complexity Analysis

| Metric    | Complexity | Note                                                   |
| --------- | ---------- | ------------------------------------------------------ |
| **Time**  | $O(n)$     | Two linear passes through the array.                   |
| **Space** | $O(n)$     | Using an extra array `rightArray` for suffix products. |

> **Optimization Tip:** You can achieve  extra space (excluding the output array) by storing the suffix products in the `output` array first, then multiplying by the prefix product on the fly during the second pass.

# 🎨 Japanese Colours — Grammar & Usage

Japanese basic **colours** fall into **two grammatical categories**:

1. **い-adjectives (i-adjectives)**  
2. **Nouns**

This distinction determines:
- how colours modify nouns  
- how they appear in sentences  
- whether they **conjugate**

---

## 🔴 Primary Colour Adjectives (い-Adjectives)

Some core colours behave like **verbs** and end in **〜い** when used adjectivally.

### Red
- **赤**（あか / *aka*）— red (noun)
- **赤い**（あかい / *akai*）— red (adjective)

### Blue
- **青**（あお / *ao*）— blue (noun)
- **青い**（あおい / *aoi*）— blue (adjective)

> These colours can directly modify nouns and conjugate for tense and negation.

---

## 🧩 Grammatical Usage

### ① Direct Modification (before a noun)

Use the **い-adjective form** directly before the noun.

- **赤い靴**  
  あかい くつ  
  *akai kutsu*  
  → red shoes

- **青い車**  
  あおい くるま  
  *aoi kuruma*  
  → a blue car

---

### ② Predicate Usage (end of sentence)

Colours can appear as the **predicate**, following SOV structure.

- **車は赤いです**  
  くるま は あかい です  
  *kuruma wa akai desu*  
  → The car is red.

---

### ③ Noun-Based Colours（の-linking）

Some colours function **only as nouns**, not adjectives.

Example:

- **茶色**（ちゃいろ / *chairo*）— brown

To modify a noun, use **の**.

- **茶色の靴**  
  ちゃいろ の くつ  
  *chairo no kutsu*  
  → brown shoes

---

## 🔄 Conjugation & Transformation (い-Adjectives)

Because i-adjectives behave like verbs, they conjugate.

### Past Tense
- **赤い → 赤かった**  
  あかい → あかかった  
  *akai → akakatta*  
  → was red

### Negation
- **赤い → 赤くない**  
  あかい → あかくない  
  *akai → akakunai*  
  → is not red

---

### Adverbial Form（〜く）

Change **〜い → 〜く** to modify a **verb**.

- **赤い → 赤く**（あかく / *akaku*）
- **青い → 青く**（あおく / *aoku*）

This allows colours to describe **how** something is done.

---

## 💬 Sentence-Final Nuance

Sentence-final particles adjust **tone**, not meaning.

### ね (ね / *ne*)
- Seeks agreement or confirmation  
- “It’s red, isn’t it?”

### よ (よ / *yo*)
- Adds emphasis or new information  
- “It *is* red.”

---

## 🎨 Common Japanese Colours

### い-Adjective Colours
(these conjugate)

- **赤い**（あかい / *akai*）— red  
- **青い**（あおい / *aoi*）— blue  
- **白い**（しろい / *shiroi*）— white  
- **黒い**（くろい / *kuroi*）— black  
- **黄色い**（きいろい / *kiiroi*）— yellow  

---

### Noun-Based Colours
(use **の**)

- **茶色**（ちゃいろ / *chairo*）— brown  
- **緑**（みどり / *midori*）— green  
- **紫**（むらさき / *murasaki*）— purple  
- **ピンク**（*pinku*）— pink  
- **オレンジ**（*orenji*）— orange  
- **灰色**（はいいろ / *haiiro*）— gray  

Example:
- **緑の服**  
  みどり の ふく  
  *midori no fuku*  
  → green clothes

---

## 🧠 Key Takeaways

- Colours are either **い-adjectives** or **nouns**
- い-adjectives:
  - modify nouns directly
  - conjugate (past, negative, adverbial)
- Noun colours require **の**
- Sentence-final particles adjust **tone**
